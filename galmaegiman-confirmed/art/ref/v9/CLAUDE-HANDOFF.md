# 시작 및 로딩 화면 디자인 적용 지시문

제공된 파일은 디자인 소스입니다. 아직 앱 코드에 반영하지 않았습니다.
기존 시작 버튼, 계정 버튼, 설정 버튼, 실제 로딩 절차의 동작을 유지하며 디자인을 적용하세요.

## 배치

- 기준 캔버스는 2640×1080입니다.
- `layout.json`의 `screens.title`과 `screens.loading` 배열 순서가 겹치는 순서입니다.
- `title/`과 `loading/`에는 위치를 이미 맞춘 전체 캔버스 PNG가 있습니다. 같은 원점에서 겹칩니다.
- `objects/`에는 개체 크기로 잘라 둔 PNG가 있습니다. `layout.json`의 x/y/width/height를 사용하세요.
- 두 방식 중 하나만 사용하세요. 개체와 전체 캔버스 레이어를 중복해서 그리지 마세요.
- 화면 크기가 달라지면 하나의 동일한 배율과 원점 이동을 모든 레이어에 적용하세요.
- 화면의 실제 가용 영역을 확인하고, 버튼을 누를 수 있는 영역과 노치 영역을 확인하세요.

## 시작 화면

- 항구 풍경과 앞쪽 목재 부두는 별도 레이어입니다.
- 갈매미맨, 랍스터, 문어, 끼룩단, 각각의 바닥 그림자가 별도로 있습니다.
- 로고와 부제는 별도 투명 PNG입니다.
- 시작 버튼 바탕, 재생 삼각형, 게임 시작 문구를 각각 제공합니다.
- 계정 버튼 바탕과 닉네임은 별도입니다. 와로두는 제공된 화면을 참고한 시안용 표시입니다.
- 실제 닉네임은 앱 데이터로 출력하세요.
- 설정 버튼 바탕과 톱니바퀴는 별도 레이어입니다.

## 로딩 화면

- 배경, 부두, 반투명 패널, 제목, 시험판 배지 바탕, 배지 글자, 마스코트, 상태 문구, 바 트랙, 바 채움, 부제를 각각 제공합니다.
- `loading_fill_example_50pct`는 디자인 확인용입니다. 실제 로딩 진행률은 아닙니다.
- 실제 진행률을 측정할 수 있으면 채움 폭을 그 값에 맞추세요.
- 진행률을 측정할 수 없으면 수치 진행률 대신 움직이는 불확정 로딩 표시를 사용하세요.
- 로딩이 완료되었을 때 기존 앱의 다음 화면으로 이동하세요.
- 수비대 대결/시험판 문구는 제공된 기존 화면을 기준으로 유지했습니다.

## 텍스트와 확인

- 글꼴은 `fonts/Jua-Regular.ttf`입니다. 원문 라이선스 `fonts/OFL.txt`를 함께 보관하세요.
- 동적 문구는 텍스트 이미지 대신 앱 텍스트로 렌더링할 수 있습니다.
- 그림과 문구가 합쳐져 있지 않으므로 문구를 이중으로 출력하지 마세요.
- 적용 후 시작·계정·설정 버튼 동작, 로딩 완료 이동, 한글 표시, 화면 가장자리의 버튼 잘림을 확인하세요.

배경의 건물·구름·바다 등 원경은 하나의 환경 이미지에 포함됩니다. 캐릭터의 장비와 의상은 캐릭터 단위 이미지에 포함됩니다.
