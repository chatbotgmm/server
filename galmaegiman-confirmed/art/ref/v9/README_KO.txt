갈매미맨 수비대 시작·로딩 화면 디자인 소스

기준 캔버스: 2640 × 1080 px (가로)

title/: 시작 화면의 개별 레이어 PNG
loading/: 로딩 화면의 개별 레이어 PNG
objects/: 투명 여백을 줄인 개별 개체 PNG
title_preview.jpg / loading_preview.jpg: 합성된 디자인 시안
layout.json: 개체의 좌표·크기 및 겹치는 순서
fonts/: 한글 글꼴 Jua와 원문 라이선스

전체 캔버스 레이어는 파일 번호 순서대로 같은 (0,0)에 겹칩니다.
objects/ 이미지는 layout.json의 x,y,width,height 값에 맞춰 배치합니다.
전체 화면의 비율을 유지하며 한꺼번에 확대/축소하세요.

글자와 버튼 바탕, 설정 버튼 바탕과 톱니바퀴를 각각 분리했습니다.
와로두는 제공된 화면의 닉네임을 사용한 미리보기입니다.
실제 앱에서는 닉네임과 불러오는 중 문구를 동적 텍스트로 출력하세요.

로딩 바의 채움은 시안용 50% 예시이며 실제 진행률을 뜻하지 않습니다.
진행률을 측정할 수 있는 경우에만 실제 값으로 채움 폭을 변경하세요.
측정할 수 없는 경우 움직이는 표시로 사용하세요.

로딩 화면의 수비대 대결/시험판 표시는 제공된 화면을 참고했습니다.
배경의 건물·구름·바다·원경 소품은 하나의 환경 레이어에 포함됩니다.
앞쪽 부두, 메인 캐릭터, UI 요소는 별도 레이어입니다.
캐릭터의 의상과 장비는 각 캐릭터 이미지에 포함됩니다.

AI 이미지 생성으로 기존 화면의 캐릭터와 항구를 새 스타일로 재구성했습니다.
한글 글자 및 단순 UI 도형은 별도로 렌더링했습니다.
앱 코드 반영과 앱 내 동작 검증은 포함되지 않았습니다.
