# 방범대 등록증 v10 — 60종 아트 인계

승인된 header-v8 디자인을 전체 60종에 확장하고 등급색 누락을 정정한 최종 PNG입니다.

- cards/u01.png~u60.png: 각 900×1200, 기존 캐릭터 정면과 종족 배경 유지.
- manifest.json: ID·이름·등급·종족·번호·경로·SHA-256 및 Git blob SHA.
- frame-map.json: 등급 대표, 캔버스와 텍스트 영역.
- 커먼/에픽/전설/히든/제한/초월/불멸 40장 색상 정합 수정, 나머지 20장 보존.
- 제목: 방범대 등록증. 종족명만 표기. 헤더·등급명판·우측 인증도장·등급색 테두리 정합. 중립 은세공과 양피지는 유지.
- 종족 구성은 기존 검토안이며 전투 시너지 최종 확정이 아닙니다.
- 이름/번호의 남색 잉크와 캐릭터·하늘의 본래 파랑은 의도적으로 보존했습니다.

## 통합 범위
이 커밋은 아트 및 매핑 자료 업로드만 수행합니다. 앱 런타임 코드, 기존 전투용 앞뒤 아트, 운영 서버/DB는 변경하지 않습니다. 런타임 연결·리사이즈/포맷 최적화·실기기 검수는 별도 개발 작업입니다. 기존 registration-v1과 원본 아트는 삭제하지 않습니다. PDF/ZIP은 저장소에 중복 포함하지 않습니다.
