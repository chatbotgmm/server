# 상위 33종 캐릭터 애니메이션 에셋

기본 단계(s0) 캐릭터 33종(D1–D8, T1–T8, E1–E8, I1–I9)의 정면·후면 애니메이션입니다. 승급 디자인은 포함하지 않습니다.

- 총 264개 PNG 시트: 33종 × 2방향(`front`, `back`) × 4동작(`idle`, `attack`, `hit-defend`, `entry`)
- 시트당 3열 × 2행, 총 6프레임. 각 셀은 512 × 512px이며 좌→우, 위→아래 순서입니다.
- 파일 위치: `<캐릭터 ID>/<방향>/<동작>.png`

## 미리보기와 경로

이 폴더 전체를 `galmaegiman-confirmed/art/gpt/` 아래에 같은 구조로 유지하세요. [미리보기](preview/index.html)는 `preview/catalog.js`, `preview/app.js`와 형제 캐릭터 폴더의 PNG를 사용합니다. 카탈로그의 `../D1/back/attack.png` 같은 경로는 미리보기 HTML 기준이며, 저장소 하위 경로가 바뀌어도 내부 구조를 유지하면 그대로 동작합니다. HTML의 세 파일 참조와 카탈로그의 264개 PNG 참조가 패키지 안에서 모두 존재함을 확인했습니다.

GitHub 파일 화면은 HTML 미리보기를 실행하지 않습니다. 폴더를 내려받아 `preview/index.html`을 브라우저로 여세요. 로컬 파일 로딩이 차단되면 이 폴더에서 `python -m http.server 8765 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:8765/preview/`로 접속하세요. 세부 조작법은 [미리보기 설명](preview/README.md)에 있습니다.

## 메타데이터 적용

루트 `manifest.json`은 캐릭터와 원본 참조 목록입니다. 각 캐릭터의 매니페스트와 `*.measured-anchors.json` 등 부속 파일에서 프레임·앵커·스케일 정보를 확인하세요. 스키마가 서로 다르므로 [카탈로그 생성기](preview/build_catalog.py)의 변환 방식과 `preview/catalog.js`의 통합 데이터를 함께 참고하세요.

- `rect`: 시트에서 잘라낼 프레임 영역. `anchor`: 해당 셀 내부의 발 기준점. `anchorSource`: 근거 파일의 패키지 루트 기준 위치입니다.
- 검토된 측정 앵커를 우선 사용하고, 시트 전체에 같은 스케일을 적용합니다. 포즈마다 크기를 따로 보정하지 마세요. 스케일은 적용 제안값입니다.
- 미리보기는 `위치 = 고정 원점 − 앵커 × 스케일`로 정렬하고, 제공된 `offsetY × 스케일`을 Y축에 더합니다. `offsetY`는 원본 픽셀 단위이며 프레임 시간은 `duration`(ms), 반복 여부는 `loop`를 참고합니다.
- PNG나 메타데이터를 바꾸면 이 폴더에서 `python preview/build_catalog.py`로 카탈로그를 다시 생성하고 해시·앵커 정합성을 확인하세요. 일부 원본 기록의 절대 경로는 제작 당시 위치이며 배포용 URL이 아닙니다.

## 남은 통합·검증

[메타데이터 누락 집계](preview/metadata-gaps.json)상 앵커·제안 스케일 누락과 해시 불일치는 0건입니다. 그러나 **67개 시트의 등장 또는 검토된 공중 동작에 필요한 수직 이동 궤적이 제공되지 않았습니다.** 게임 통합 시 의도한 모션 오프셋을 정의·적용해야 합니다. 미리보기의 누락 오프셋 0 처리는 앵커 진단용이며 완성된 등장·점프 동작을 의미하지 않습니다.

**실제 게임 런타임의 재생·전환·타이밍 검증은 아직 완료되지 않았습니다.** 기존 제어 테스트와 정적 에셋 검토는 런타임 검증을 대신하지 않습니다. 실제 브라우저 시각 검증 역시 미완료 상태입니다. 이번 인계 경로 점검과 설명서 추가는 PNG 또는 기존 메타데이터를 변경하지 않습니다.
