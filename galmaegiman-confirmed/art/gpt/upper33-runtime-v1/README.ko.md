# 상위 33종 Android 전투 애니메이션 — 검토용 초안

**화면·앱 빌드·기기 미검증. 운영 병합·배포하지 않음.** 사용자 2026-10-21 승인으로 화면 캡처 선행 규칙의 예외를 적용한 검토용 소스다.

## 기준과 범위
- 최신 소스 후보: `ea8ccd18cd77e92e1c6092eb1064c17ddde3fb9f` (manual/home-assembly-20261019). v81 사용자 보고 기능을 보존하되, 설치된 v81 APK와 정확히 일치하는 SHA는 확인하지 못했다.
- `gmmVersionCode`/`gmmApplicationId` 오버라이드와 기본값은 변경하지 않는다. 시험판은 preview variant로 분리하고 정식 업데이트는 설치 버전 81보다 높은 번호가 필요하다. 기본값 78로 업데이트 APK를 배포하면 안 된다.
- 원본: `43cae59c50b03ca4f52ab039317e55d8dcf06a70`의 `upper33-animation-v1`, Git subtree `07bbf02e76b35fbd56b4a2bb809d3d59708b9182` 그대로 재사용한다.
- D1–D8/T1–T8/E1–E8/I1–I9 기본 단계(s0), 앞/뒤 × idle/entry/attack/hit-defend = 264시트.
- 내 캐릭터는 뒤, 상대는 앞. 소유 캐릭터 id와 실제 s0 이미지 경로를 모두 검사하므로 환생 전투 정의나 승급 이미지를 잘못 덮지 않는다. 대상 외·파일 실패·모션 끄기에서는 기존 정지 그림으로 돌아간다.

## 데이터와 재생
- 6프레임별 duration, anchor, scale, offsetY를 적용한다. idle은 반복, 나머지는 마지막 프레임에서 멈춘다. 이벤트 재생 길이는 기존 이벤트 시간과 시트 총시간 중 큰 값이며 프레임 시간 비율을 유지한다.
- 원본에서 궤적이 누락된 **67시트**는 `runtimeTrajectory: conservative-v1`로 표시한 보수적 대체값이다. 원본 작가 궤적 완성으로 주장하지 않는다. entry는 짧은 낙하/착지, 나머지는 airborne 메타데이터가 있는 프레임만 작은 상하 이동.
- 원본 bounds 누락 **288프레임**은 `runtimeBounds: full-cell-conservative`로 전체 셀을 사용한다. 실제 알파 경계 측정값이 아니므로 해당 캐릭터는 조금 작아질 수 있다. 원본 파일/메타데이터는 수정하지 않는다.
- 캐릭터 전체 동작의 경계 합집합으로 고정 배율을 산출해 프레임별 크기 출렁임을 막는다. 기존 전투 이동/타격 섬광/기절 알파는 유지한다.
- 단일 백그라운드 디코더, 대기 최대 16개, Bitmap LRU **24 MiB**. 현재 양측 캐릭터의 4동작만 예열한다. 768×512 ARGB 시트 하나의 픽셀 데이터는 1.5 MiB다. LRU 용량은 전체 프로세스 메모리 상한이 아니다. 화면 분리 시 작업 취소·콜백 제거·캐시 해제. 모션 설정/일시정지/포커스/가림 상태를 존중한다.

## 패키징
- 원본 PNG 264개의 합계는 Git 트리 기준 **594,763,701 bytes**. 이 원본을 assets에 넣지 않는다.
- `prepareUpper33Art`가 Gradle 실행 JDK(17 이상)의 headless ImageIO로 SHA-256/원본1536×1024를 확인하고 셀별로 독립 축소하여 인접 프레임 보간 누출 없이 768×512 PNG를 생성한다. `bundleGameArt`는 파생 시트와 카탈로그만 `native/upper33-v1`로 묶는다. 원본 픽셀 좌표는 유지하고 crop만 1/2로 바꾼다.
- 비공개 GitHub URL 런타임 요청, 앱 내 인증키, 서버 배포는 필요 없다. 체크아웃에 재사용된 원본 Git subtree가 있어야 한다.
- **실제 264종 전체 파생 PNG 용량과 APK/AAB 크기는 미측정**이다. 빌드 로그가 실제 합계를 출력한다. 합성 테스트 출력 용량은 실제 캐릭터 용량 예측값이 아니다.

## 수행한 검증
- Java 21 컴파일러 모듈로 실제 `UpperAnimationCatalog` 컴파일/실행: 33종 매핑, 264시트, 1,584프레임의 시간 경계·루프/종료·원점/스케일/오프셋/절반 crop, 대상 외/승급 fallback 통과. 테스트 전용 JSON-java를 사용했으며 앱 의존성은 추가하지 않는다.
- 실제 `PrepareUpper33Art.java` headless 실행: 합성 264 PNG → 264 결과, 1,584 색상 셀 위치/접합부 경계색, 투명도, 카탈로그 동일성, 해시 오류 거부 통과.
- 변경 Java 7파일 구문 파싱 통과. 이는 Android 타입 검사/앱 컴파일이 아니다.
- 앱 Gradle/Robolectric/실제 원본 전체 변환/실기기/실제 글꼴 915×412 및 1280×720 화면 겹침 검증은 아직 미실행.
