# 갈매미맨 방범대 입사 등록증 · 미술 자산 전달본

이 묶음은 `gpt-art` 브랜치의 `galmaegiman-confirmed/art/gpt/registration-v1`에 추가하는 **자산·배치 메타데이터·설명서만의 전달본**입니다. 실행 가능한 JavaScript 도구나 HTML 미리보기는 포함하지 않습니다. 기존 앱 코드, API, 화면, 설정, 게임 규칙 및 `public/images`는 변경하지 않습니다.

## 포함 범위

- `resources/cards/{ID}.webp`: 기존 명단 145명의 입사 등록증. 각 768×1024, WebP 품질 88
- `manifest.json`: 정확한 ID·이름·등급, 카드 경로·크기·SHA-256, 원본 SHA-256, 인물별 장면 표시 영역
- `component/roster.json`: 기준 145명 ID·이름·등급
- `component/registration-card.svg`: 레이어와 문자 자리표시자가 있는 편집 가능한 SVG 이미지 템플릿
- `component/layout.json`: 1086×1448 마스터 기준 영역, 발 기준점, 문자 배치 및 최소 여백
- `component/source-viewports.json`: 인물별 검수된 원본 표시 영역과 주의 상태
- `component/application-animation.json`: 봉투 아틀라스의 정확한 정수 소스 사각형, 타이밍 및 결과 대기 상태에 관한 메타데이터
- `resources/registration-frame.png`: 공통 프레임 마스터, 1086×1448
- `resources/harbor-background.png`: 기존 항구 배경 자산
- `resources/application-envelope-atlas.png`: 봉투 애니메이션 시각 자산
- `resources/navy-registration-seal.svg`: 별도 벡터 닻 인장
- `resources/fonts/registration-serif-bold.woff`: 실제 한국어 글꼴
- `resources/fonts/Noto-CJK-LICENSE.txt`: 글꼴 저작권 고지와 라이선스

## 개발자 적용 방법

가장 간단한 사용법은 `manifest.json`의 경로에 있는 완성 WebP 카드를 정적 이미지로 표시하는 것입니다. 파일을 실제 앱 자산 위치로 복사하거나 경로를 연결하는 작업은 이 전달본에 포함하지 않습니다.

레이어별 조립이 필요한 경우 개발자가 SVG 템플릿의 자리표시자에 해당 ID의 원본 장면·이름·등급·ID와 공통 리소스를 연결하세요. 템플릿, `layout.json`, `source-viewports.json` 및 동봉 글꼴을 기준으로 실제 앱용 표시 구성 요소를 구현해야 합니다. SVG 템플릿은 동적 값이 채워지기 전에는 완성 카드 이미지가 아닙니다.

프레임, 배경, 인물/장면, 바닥 그림자와 문자는 서로 다른 계층입니다. 새 표제는 `입사 등록증`, 부제는 `갈매미맨 방범대`입니다. 새 이름·등급·ID는 기준 명단에서 가져오며 기존 PNG에 문자를 새로 구워 넣지 않습니다. 이미 원본 장면에 포함된 대사는 그대로 남깁니다.

장면 표시는 해당 ID의 `sourceViewport`를 전부 보존하고 명시적인 클립을 함께 적용하세요. 가로세로 비율을 유지한 contain/meet 방식이 필요하며, 추가적인 cover 확대나 임의의 공통 자르기를 적용하면 안 됩니다. 일부 항목의 `sourceClipPath`는 기존 장식 모서리만 가리기 위한 별도 경로입니다. SVG viewBox의 meet 설정만으로는 여백에 표시 범위 바깥 픽셀이 나타날 수 있으므로 클립 영역도 적용해야 합니다.

투명 인물 모드를 별도로 구현할 때에는 실제 알파 경계 전체를 안전 영역 안에 넣고 발 기준점을 맞추세요. 길어진 이름은 두 줄로 배치하고 작은 글씨로 무리하게 줄이지 않습니다. 제공된 카드 145장은 원본 장면 보존 방식으로 만들어졌으며 생성형 인물 누끼를 사용하지 않았습니다.

## 원본 보존과 검수 한계

145장의 출력이 있으며, 131장은 검수한 장면 영역을 사용하고 14장은 인물 보존을 위한 전체 원본 예외입니다. 원본 PNG 자체는 변경하지 않았습니다. 원본 장면의 얼굴·색·날개·소품·인원수를 AI로 다시 그리지 않았고, 가려진 몸이나 다리를 새로 만들지 않았습니다.

전체 800×800 원본을 쓰는 14개 `needsattention` 항목은 기존 외곽 프레임과 하단 명패가 카드 안에 의도적으로 남아 있습니다. 일부 일반 장면에도 작은 기존 장식 모서리 조각이 남을 수 있습니다. 전체 출력을 만들었다는 사실이 이 예외들의 최종 디자인 승인이나 실제 앱의 제작 검수 완료를 뜻하지 않습니다.

145개 ID·이름·등급, 파일 수, WebP 형식/768×1024 크기/알파, 출력 SHA-256 및 변경되지 않은 원본 SHA-256을 확인했습니다. 모든 최종 카드의 8개 검수 모음 이미지를 확인하여 빈 그림이나 새 표제·이름·ID 영역의 넘침이 없음을 확인했습니다. 14개 전체 원본 예외는 최종 WebP도 개별적으로 열어 보이는 인물·그룹·주요 소품이 추가로 잘리지 않았음을 확인했습니다.

이 검증은 미술 전달본 검증입니다. 실제 앱·브라우저 엔진, 축소 화면 가독성, CORS/CSP, 로딩 방식 및 성능은 개발자가 연결 후 별도로 검수해야 합니다. 앱 배포나 API 연결은 이루어지지 않았습니다.

## 글꼴

Noto Serif CJK KR Bold를 `Registration Serif`라는 이름의 WOFF 부분집합으로 포함했습니다. 기존 145명과 고정 표제에 필요한 모든 글자가 들어 있으며 필수 문자 누락은 없습니다. 새 이름이나 다른 문자를 추가하면 글꼴 부분집합을 갱신해야 합니다.

SIL Open Font License 1.1 적용. `resources/fonts/Noto-CJK-LICENSE.txt`의 저작권 고지와 라이선스를 유지하세요. 상업 앱에 포함·재배포할 수 있지만 글꼴 자체를 단독 판매하거나 수정한 글꼴을 예약된 원래 이름으로 배포하지 않아야 합니다. 외부 Google Fonts 요청은 필요 없습니다.

## 봉투 애니메이션 적용 참고

아틀라스는 1774×887이며 4×2 셀 너비와 높이가 443/444 픽셀로 다릅니다. JSON의 실제 정수 소스 사각형을 사용하세요. 프레임별 표시 시간과 발 기준점도 메타데이터에 있습니다. 그림자, 인장, 결과 캐릭터와 결과 문자는 분리해서 표시해야 합니다.

마지막 프레임은 실제 결과를 받기 전까지 유지하도록 정의되어 있습니다. 이를 구현할 재생 코드, 실제 뽑기 결과, 결제, 서버 API 및 중복 요청 방지는 포함하지 않습니다. 해당 동작은 실제 앱 개발자가 구현해야 합니다.
