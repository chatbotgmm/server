# 갈매미 60종 앞·뒷면 아트 보관본

2026-10-24 사용자 요청으로 gpt-art에 정리한 **검토용 원본 아카이브**입니다. 게임/Android 코드에 적용하거나 운영 브랜치로 병합하지 않았습니다.

## 구성
- 60종 × 정면·후면 = 활성 120뷰, 원본 PNG 72개(기존68개 + 드워프 후면 v4 + 노움·인어기사 후면 v3 + 듀라한 앞뒤 v5(다리 수정)).
- `u01`~`u60`: 캐릭터별 이미지와 `views.json`.
- `manifest.json`: 이름·등급·원본 해시·정면/후면 영역·검토 상태의 통합 목록.
- `roster.csv`: 엑셀에서 확인할 수 있는 전체 목록.
- `validation.json`, `original-source-hashes.json`, `SHA256SUMS`: 파일/영역 무결성 검증 자료.

## 앞뒤 이미지 읽는 법
- 커먼8종은 `front.png`와 `rear.png`로 분리되어 있습니다.
- 나머지52종은 `turnaround-original.png`의 정면/후면 영역을 각각 사용합니다. 원본을 재압축하거나 픽셀을 편집하지 않았습니다.
- **시트를 가로50%로 자르면 안 됩니다.** 27개 원본 시트에서 중앙 분할은 실루엣을 침범합니다. `active_views`의 `source_rect_ltrb_exclusive`를 사용하세요. `[left,top,right,bottom]`에서 오른쪽/아래는 제외 경계입니다.
- 드워프(u17)는 후면 `rear-v4.png`, 노움(u09)·인어기사(u28)는 후면 `rear-v3.png`를 사용합니다. 이3개체의 정면은 원본 시트 그대로이며 옛 후면은 이력입니다.
- 듀라한(u31)은 사용자 요청으로 **목에는 연기만, 왼손에 분리된 머리, 오른손에 검**을 든 정면·후면 `turnaround-v5-legs.png`로 교체했습니다. 옛 정면·후면 모두 `superseded_views`로 보존하며 활성화하지 않습니다. 중간 후면 단독v3는 포함하지 않습니다.
- u01의 표시 이름은 사용자 요청에 따라 **갈매미맨**으로 변경했습니다. ID는 u01 그대로이며 다른 개체의 이름에는 접미사를 붙이지 않습니다.

## 검토 상태와 제한
- 업로드는 최종 아트 승인이나 게임 적용 승인을 뜻하지 않습니다. 전체 파일은 검토용이며, 기술적 해시/영역 검사 통과와 디자인 승인 상태를 구분합니다.
- 노움(u09)·인어기사(u28)의 후면 몸통/앞치마/갑옷 구조를 수정하고, 듀라한(u31)은 손에 머리를 든 새 앞뒤 디자인으로 바꿔 별도 구조·가림 검토를 통과했습니다. 이는 보관본 교체를 위한 검토이며 사용자 최종 아트 승인이나 실기기 검증 완료를 뜻하지 않습니다.
- 인어기사 창은 불투명 실루엣 잘림이 없으나 상단 여백이7px로 작아 게임 렌더링 시 여백을 확인해야 합니다.
- 드워프(u17) 후면 v4는 가림 순서에 뚜렷한 역전이 없다는 검토를 거쳤습니다. 날개 하단/팔/망치 자루 접점의 소형 가독성과 사용자 최종 승인은 남아 있습니다.
- 다른 후면 국소 보완·구조 확인 및 정면 방향/그림체 문제는 각 캐릭터 `known_issues`를 확인하세요. 문제가 기재되지 않은 개체도 최종 승인 완료로 간주하지 마세요.
- 거절된 후면v2 시안은 포함하지 않았습니다. 이번 갱신에서는 후면2개와 듀라한 앞뒤 시트1개를 추가했습니다. 기존 원본 파일68개는 변경하지 않았으며, 활성 정면 매핑은 듀라한을 제외한59개가 동일합니다.
- 피벗·발 기준점·화면상 상대 크기·안드로이드 실기기 검증은 미완료입니다. 미니는 기본 높이의60% 표시 규칙을 유지해야 합니다.
- 기존 `../common8/` 애니메이션 파일, 게임 코드, 운영 데이터는 변경하지 않았습니다. 상위 애니메이션은 이 아카이브에 없습니다.
