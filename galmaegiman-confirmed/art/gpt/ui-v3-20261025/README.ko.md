# UI v3 검토·개발 리소스

이 폴더는 사용자가 승인한 작업 브랜치 업로드용 디자인 전달본입니다. 실제 앱 코드·서버·워크플로는 이 커밋에서 수정하지 않습니다. 통이미지 화면을 앱에 붙이는 용도가 아닙니다.

- `handoff/reference/`: 최종 S05 전투 편성 / S06 B 항구 전투 / S12 조합 PNG.
- `reference/battle-states/`: 기술 6칸, 누르는 동안 설명, 교체 상태 PNG 3장. 나머지 아이템·도망·항복 상태는 소스·50상태 매핑·전체 PDF에 보존.
- `handoff/mapping/`, `layout/`, `theme/`: 36개 화면·50개 상태·95개 경로, 네이티브 컴포넌트·가드·실제 기준 좌표.
- `handoff/editable/`: 최종 시안 생성 소스. 별도 원본으로 재렌더하여 50/50 최종 PNG SHA 일치 확인. Android 앱 코드가 아님.
- `runtime/`: 검증된 전투 런타임 최소 리소스팩. 투명 상태·버튼·패널·9-patch·좌표. 원본 전체 이미지와 TTF 중복 없음. 자체 manifest/사용법을 먼저 확인.
- `faces/`: 새 60종의 정면 원본과 정확한 sourceRect에서 만든 128/256px 투명 얼굴 PNG 각60장. focus 좌표·원본 고정커밋·해시를 포함. 전투 전신 아트의 대체물이 아님.

## 정본·검증 범위

전체 PDF는 Library `libfile_3100600207c881919eb4d74ca7c52445`, version1, 50페이지입니다. 파일 크기·SHA는 `handoff/reference/authoritative-delivery.json`을 보세요. 전체 PDF/50장 PNG/ZIP은 중복 커밋하지 않습니다.

배경은 사용자 선택 **B 항구**, 조합 왼쪽은 **전체 등록증 유지**입니다. 현재 종족명 ‘태초’는 맞는 명칭입니다. 제외 대상은 구형 D1/태초갈매미맨 캐릭터와 폐기된 보상이지 현재 종족명이 아닙니다.

1920×800은 reference px이며 dp가 아닙니다. 이미지 하단 100px 검토 footer는 런타임에서 제외합니다. 실기기 터치·인셋·앱 화면 픽셀 비교는 앱 담당이 수행합니다. 수치·잔액·미연결 정책은 예시/미정이며 서버 데이터로 하드코딩하지 않습니다.

이 업로드는 디자인 보관·전달만입니다. 운영 브랜치 병합, EC2 배포, DB 변경을 하지 않습니다. 기존 브랜치의 자동 CI/preview 동작은 변경하지 않습니다.
