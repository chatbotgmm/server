# 동료의 거리 원화 재구성 후보

2026-10-27 사용자 제공 마을 그림을 기준으로 제작한 첫 구역 후보입니다. 다른 세 구역까지 완료했거나 사용자의 최종 미술 승인을 받은 상태로 간주하지 않습니다.

## 목표
- 붉은 기와, 목재 처마, 밝은 석재, 파란 천과 깃발의 생활 건축.
- 평면 일렬 진열 대신 계단과 화단으로 이어지는 앞뒤·높낮이 구성.
- 순찰대원은 지도 책상에서 일하는 모습으로 표현.

## 분리된 리소스
- `background.png`: 먼 절벽 마을과 산 원경. 불투명.
- `terrace.png`: 계단, 보행면, 화단. 투명 배경.
- `recruit.png`: 지원소. 투명 배경.
- `hideout.png`: 아지트와 기와 망루. 투명 배경.
- `patrol.png`: 순찰대원과 지도 책상. 투명 배경.
- `shadows.png`: 지원소·아지트·순찰 책상의 분리된 평면 접지/짧은 투영 그림자 3행 atlas. 1536×1024 원본을 보존하며, 발 기준점에 연결하고 배우보다 먼저 낮은 불투명도로 그립니다. 최종 사용자 검토 대기.

모두 내장 이미지 생성 도구로 제작한 PNG 원본입니다. 건물·주민을 배경 한 장에 합치지 않습니다. 런타임 manifest의 crop과 테라스 바닥 좌표를 이용해 원본 비율을 유지합니다.

## 보존할 기능
8U 좌우 순환, 개별 건물 메뉴, 주민 퀘스트, 그림 아래 이미지 명패, 계정별 서버 석상 단계는 유지합니다. 이 후보 자체는 새 APK의 설치나 서버 배포를 의미하지 않습니다.
