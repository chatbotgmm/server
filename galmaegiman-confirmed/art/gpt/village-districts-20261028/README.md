# 네 구역 연결용 분리 원화

기존 첫 구역과 같은 따뜻한 붉은 기와·목재·크림색 석재·파란 천의 그림체를 나머지 세 구역에 적용하는 후보입니다. 사용자의 최종 미술 승인이나 실기기 성능 검증을 의미하지 않습니다.

- records: 산과 마을 원경, 독립 계단·원형 석상 광장 바닥, 기록소 건물.
- harbor: 만과 먼 해안 원경, 투명 중앙 정박 공간을 둔 부두, 플레이 메뉴를 담당하는 배.
- market: 산과 생활 마을 원경, 시장·공방의 서로 다른 높이 바닥, 시장, 대장간.

모든 PNG는 내장 이미지 생성 도구가 생성한 원본 바이트 그대로입니다. 인물·건물·배를 배경 한 장에 합치지 않습니다. 건물 명패는 기존 PNG atlas, 주민과 석상은 기존 별도 원화를 유지합니다. 대장간은 장식 건물이며 대장장이 주민의 기존 퀘스트가 별도 입력 대상입니다.

배경과 바닥은 원본 종횡비와 중앙 크기를 유지한 채 외곽 타일을 동일 방향으로 반복하고 0.12U 겹침을 부드럽게 전환해 2U 구역 범위를 덮습니다. 중앙 배치 좌표는 유지하고 대칭으로 붙는 건물을 피합니다. 확대된 별도 배경을 겹치지 않습니다. 경계는 화면상 왼쪽부터 불투명한 타일 위에 다음 타일을 단방향으로 섞어 옛 배경이 비치는 틈을 막습니다. 배는 부두보다 먼저 그려 선체 하부가 부두에 가려지며, 동일한 바닥 알파·반복·클립 마스크로 가려진 선체의 클릭도 막습니다. 명패는 계속 별도로 누를 수 있습니다. 석상은 인증된 서버 단계만 표시하고 모든 단계에 동일한 캔버스·발 기준점을 사용합니다.

마을은 8U 연속 순환, 6개 건물 메뉴, 4개 주민 퀘스트, 이미지 아래 명패를 유지합니다. 현재 화면과 인접 구역만 디코딩하고 공유 RAM 캐시 크기는 늘리지 않습니다. 프리페치와 실기기 프레임 속도 개선은 별도 검증 대상입니다.
