# 갈매미 섬 이야기

> 갈매미는 존재한다. 다만 늘 조금씩 허술하다.

돌로 된 갈매미들이 **갈매미 섬 항구 수비대**에 출근해서 항구를 지켜요. 몸이 돌이라 날지는 못해요. 새우깡 봉지 소리에는 약해요.

## 갈매미는 이런 친구들이에요

| | |
|---|---|
| **몸** | 돌 석상이에요. 날개는 있지만 무거워서 못 날아요. |
| **직업** | 항구 수비대 직원이에요. 출근, 퇴근, 회의, 야근이 있어요. |
| **약점** | 새우깡 봉지가 바스락하면 모든 게 무너져요. |
| **세는 법** | 꼭 "갈매미 한 마리, 갈매미 두 마리…"라고 세요. 세다가 잠드는 갈매미도 있어요. |
| **합체** | 서로 꼭 끌어안으면 하나가 돼요. 왜 되는지는 아무도 몰라요. |
| **히든** | 정식 서류에 없는 갈매미예요. 소문으로만 돌아요. |
| **땅콩** | 갈매미맨에게만 있는 무언가예요. 떼면 마음이 평온해져요. |

## 섬의 동네 7곳

| 동네 | 이런 곳이에요 |
|---|---|
| **정문 부두** | 수비대 본부가 있는 섬에서 제일 바쁜 곳. 방패와 출근 도장, 그리고 따개비. |
| **금빛 시장** | 돈 냄새 나는 시장 거리. 금고, 잔돈, 집값, 그리고 끝없는 도금 논란. |
| **그늘 골목** | 밤 근무조 구역. 너무 잘 숨어서 무단결근 오해를 받는 갈매미가 많아요. |
| **해저 2층** | 바닷속 근무지. 다들 물에 안 떠서 바닥을 걸어서 출근해요. |
| **벚꽃 언덕** | 섬 최고의 낮잠 명소. 꽃잎도 돌이라 질 때마다 바닥에 구멍이 나요. |
| **별 관측대** | 야간 천문 근무. 운석을 타고 출근하는 갈매미가 있어요. |
| **빨래터** | 섬에서 가장 펄럭이는 곳. 리본, 재봉, 그리고 튼튼한 빤스. |

같은 동네 출신끼리 탐험을 가면 손발이 척척 맞아요.

## 갈매미 섬 마을

항구 뒤쪽의 작은 마을이에요. 사람 주민과 돌 갈매미가 함께 살아요. 주민들은 갈매미를 '우리 돌들'이라고 불러요.

- **바스락상회**: 섬 유일의 새우깡 가게. 봉지 여는 소리가 섬 전체에 들려요.
- **마을 회관**: 매일 회의가 열려요. 안건 1번은 늘 "땅콩 어디에 쓰지?"예요.
- **항구 예식장**: 걸어 다니는 예식장에서 결혼식이 열려요. 부케는 돌이라 받지 말고 피하세요.
- **마을 행사**: 벚꽃 축제, 갈매미 대가족이 모이는 명절, 정각마다 터지는 해일 알람, 밤 꽃구경.

## 섬을 노리는 녀석들

| 누구 | 정체 | 허술한 점 |
|---|---|---|
| **끼룩단** | 날 수 있는 진짜 갈매기 깡패들. 섬의 새우깡을 노려요. | 가만히 서 있는 갈매미를 석상인 줄 알고 그 위에 앉아 쉬다가 잡혀요. |
| **갈노스** | 금빛 시장 출신 욕심쟁이. 끼룩단과 손을 잡았어요. | 모든 보물을 갖겠다는데, 금고 용량이 새우깡 세 봉지예요. |
| **따개비** | 바위에 붙는 작은 골칫거리. | 붙으면 갈매미가 한동안 못 일어나요. |
| **이끼** | 돌에게 최악의 적. | 간지러워서 근무 중에 웃음이 터져요. |

끼룩단과 갈매미는 이름이 비슷해서 마을 사람들이 자꾸 헷갈려요. 갈매미들은 이걸 제일 싫어해요.

## 이야기

1. **출근 첫날**: 항구에 돌 갈매미들이 하나둘 출근해요. 갈매미 한 마리, 갈매미 두 마리…
2. **첫 합체**: 추운 밤, 두 갈매미가 끌어안았더니 하나가 됐어요. 수비대가 술렁여요.
3. **끼룩단 등장**: 바스락상회의 새우깡이 사라지기 시작해요. 수비대는 끼룩단 섬으로 첫 출장을 떠나요.
4. **섬의 전설**: 바다를 들고 해를 가리는 갈매미들이 나타나요. 그 사이 갈노스는 끼룩단과 손을 잡아요.
5. **서류에 없는 갈매미**: 인사기록에 없는 갈매미들이 소문처럼 나타나요. 욕심을 부리던 갈노스는 금고에 갇혀 꽁꽁 얼어요.
6. **원형의 귀환**: 각 동네의 원형들이 깨어나요. 얼어 있던 누군가도 반짝이며 다시 태어나요.
7. **큰 태풍**: 끼룩단이 부른 큰 태풍에 수비대가 모두 부서져요. 그런데 딱 하나, 찢어지지 않은 것이 있었어요. 갈매미 하나, 둘, 셋, 넷… 다섯 번째에 그 목소리가 들려요.
