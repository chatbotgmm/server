<h2 id="p1">1. 개인정보의 처리 목적과 처리하는 항목</h2>

갈매미맨은 게임 서비스를 제공하는 데 꼭 필요한 최소한의 개인정보만 처리해요. 아래 목적 밖으로는 쓰지 않고, 목적이 바뀌면 「개인정보 보호법」 제18조에 따라 따로 동의를 받는 등 필요한 조치를 해요.

이름, 전화번호, 이메일, 주소, 생년월일, 결제 정보, 카카오 프로필(닉네임·사진)과 친구 목록은 **받지 않아요.**

**① 정보주체의 동의 없이 처리하는 개인정보** — 법적 근거: 「개인정보 보호법」 제15조제1항제4호(계약 체결·이행: 이용자가 요청한 게임 서비스 제공)

| 처리 목적 | 처리하는 항목 | 언제 생기나요 |
|---|---|---|
| 게임 계정 구분 | 카카오톡 채널 챗봇 이용자 구분값(카카오가 챗봇 요청에 넣어 보내는 값)과 챗봇 구분값 | 챗봇에 처음 말을 걸 때 |
| 홈페이지·앱 카카오 로그인 | 카카오 로그인 회원번호 | 「카카오로 로그인」을 연결한 경우만 |
| 카카오 로그인 자동 연결 | 카카오 앱 회원번호(appUserId) | 카카오가 챗봇 요청에 함께 보내 주는 경우만 |
| 게임 진행 | 가진 갈매미, 도감, 뽑기권·새우gang·땅콩 수량, 아이템, 편성, 스토리 진행, 튜토리얼 단계, 미션·출석 진행 | 게임을 하는 동안 |
| 대전(실시간·랭크) | 대전 기록(상대, 결과, 시각), 랭크 점수·전적 | 대전을 한 경우만 |
| 친구 초대 | 내 초대 코드, 나를 초대한 사람 | 초대 코드를 쓴 경우만 |
| 랭킹·댓글 표시 | 닉네임, 닉네임 장식 | 직접 정한 경우만 |
| 댓글(한마디) | 댓글 내용, 쓴 시각, 받은 좋아요 수 | 댓글을 쓴 경우만 |
| 부정 이용 확인·고객 문의 확인 | 뽑기·조합·상점·탐험·쿠폰 기록(시각 포함) | 게임을 하는 동안 |
| 홈페이지 로그인 | 6자리 로그인 코드(10분 동안만 유효), 로그인 쿠키 | 「웹 로그인」 코드를 받거나 홈페이지에 로그인한 경우 |
| 좋아요 중복 방지 | 좋아요 확인값: 접속 IP를 비밀값과 섞어 되돌릴 수 없게 바꾼 값(IP 자체는 저장하지 않아요). 로그인해서 누른 경우는 계정 구분값 | 홈페이지에서 좋아요를 누른 경우 |

**② 정보주체의 동의를 받아 처리하는 개인정보** — 없어요.

**③ 정보주체 이외로부터 제공받는 개인정보** — 위 표의 카카오톡 채널 챗봇 이용자 구분값, 카카오 로그인 회원번호, 카카오 앱 회원번호는 주식회사 카카오가 보내 주는 값이에요(법적 근거는 위와 같은 제15조제1항제4호).

**④ 이용자의 기기 안에서만 처리하는 정보** — 웹 게임의 「화면 효과 줄이기」 설정과 로그인 뒤 돌아갈 페이지는 이용자의 브라우저 저장소(localStorage, sessionStorage)에만 저장되고 서버로 보내지 않아요. 브라우저의 사이트 데이터를 지우면 함께 지워져요.

**민감정보·고유식별정보(주민등록번호 등)·가명정보는 처리하지 않아요.** 다른 사람에게 보이는 정보(닉네임, 댓글)에 민감정보를 적지 않도록 주의해 주세요.

<h2 id="p2">2. 개인정보의 처리 및 보유 기간</h2>

| 항목 | 보유 기간 |
|---|---|
| 1절의 계정·게임 기록·닉네임·댓글 | **계정을 삭제(탈퇴)할 때까지.** 오래 이용하지 않아도 자동으로 지우지는 않아요. |
| 홈페이지 로그인 코드 | 10분 동안만 쓸 수 있어요. 기간이 지난 코드는 다음에 로그인 코드를 만들 때 지워져요. |
| 로그인 쿠키 | 30일(로그아웃하면 바로 지워져요). 카카오 로그인 중에 잠깐 쓰는 쿠키는 10분. |
| 좋아요 확인값 | 그 댓글이 지워질 때까지 |
| 서버 백업 | 하루 한 번(새벽 4시 30분) 만들고, 최근 7개만 남겨요. 그래서 지운 정보도 백업에는 최대 약 7일 남아 있다가 자동으로 사라져요. |

다만 관계 법령 위반으로 수사·조사가 진행 중이면 그 수사·조사가 끝날 때까지 보관할 수 있어요.

<h2 id="p3">3. 개인정보의 파기 절차 및 방법</h2>

- 보유 기간이 끝났거나 처리 목적을 이뤄서 필요 없게 된 개인정보는 지체 없이 파기해요.
- **파기 절차:** 계정을 삭제하면 그 계정의 정보를 한 번의 처리로 데이터베이스에서 지워요. 이후 카카오톡 채널에 다시 말을 걸면 새 계정으로 시작해요.
- 다른 사람의 기록에 함께 남는 실시간 대전 기록에서는 이름을 「탈퇴한 사용자」로 바꾸고, 지운 계정과 다시 연결할 수 없게 해요.
- **파기 방법:** 전자 파일 형태의 개인정보는 다시 살릴 수 없게 데이터베이스에서 삭제해요. 백업 파일은 2절의 기간이 지나면 파일째 삭제해요. 종이 문서로는 개인정보를 처리하지 않아요.
- 다른 법령에 따라 따로 보존하는 개인정보는 없어요.

<h2 id="p4">4. 14세 미만 아동의 개인정보 처리</h2>

- 갈매미맨은 나이를 묻거나 저장하지 않아요. 1절의 개인정보는 동의가 아니라 이용자가 요청한 서비스 제공(계약 이행)을 근거로 처리해요.
- 앞으로 14세 미만 아동의 개인정보를 동의를 받아 처리해야 하는 경우가 생기면, 그 아동의 법정대리인에게 동의를 받고 그 방법을 이 방침에 적을게요.
- 14세 미만 아동의 권리 행사는 법정대리인이 할 수 있어요(10절).

<h2 id="p5">5. 개인정보의 제3자 제공</h2>

갈매미맨은 개인정보를 다른 회사나 사람에게 팔거나 제공하지 않아요. 다만 법률에 특별한 규정이 있는 경우(예: 수사기관이 법에 따른 절차로 요청하는 경우)에는 「개인정보 보호법」 제17조·제18조에 따라 제공할 수 있어요.

닉네임, 닉네임 장식, 랭킹, 댓글은 이용자가 정한 대로 홈페이지·게임에서 **누구나 볼 수 있게 공개**돼요.

<h2 id="p6">6. 개인정보 처리업무의 위탁</h2>

서비스를 운영하려고 아래와 같이 개인정보 처리업무를 맡기고 있어요.

| 위탁받는 자(수탁자) | 위탁하는 업무 |
|---|---|
| Amazon Web Services, Inc. | 게임 서버와 데이터베이스·백업 보관(서울 리전) |
| Cloudflare, Inc. | 홈페이지·웹 게임·앱 접속 연결(보안 연결, 서버 주소 숨김), 방문 통계(9절) |

위탁업무 내용이나 수탁자가 바뀌면 지체 없이 이 방침에 공개할게요.

참고로, **주식회사 카카오**(카카오톡 채널 챗봇, 카카오 로그인)는 카카오의 서비스로 이용자와 갈매미맨 사이 메시지·로그인을 처리하고, 갈매미맨은 1절의 구분값만 전달받아요.

<h2 id="p7">7. 개인정보의 국외 이전</h2>

게임 서버와 데이터베이스는 국내(Amazon Web Services 서울 리전)에 있어요. 다만 아래 경우에는 개인정보가 국외 회사의 시스템을 거쳐요.

**① Cloudflare (처리위탁)**

- **법적 근거:** 「개인정보 보호법」 제28조의8제1항제3호(계약 이행을 위한 처리위탁·보관, 이 방침으로 공개)
- **이전하는 항목:** 접속 IP, 브라우저 정보, 요청한 주소와 그 안의 내용(로그인 쿠키·게임 요청 포함)
- **이전 국가:** 미국 회사가 운영하는 전 세계 네트워크(접속한 곳에서 가까운 데이터센터를 거침)
- **이전 시기·방법:** 홈페이지·웹 게임·앱에 접속할 때마다, 암호화된 연결(HTTPS)로 전송
- **이전받는 자:** Cloudflare, Inc. — 개인정보 문의 `privacyquestions@cloudflare.com`, [Cloudflare 개인정보처리방침](https://www.cloudflare.com/privacypolicy/)
- **이용 목적:** 접속 연결, 보안, 방문 통계(9절)
- **보유·이용 기간:** 연결 처리에 필요한 동안(Cloudflare의 방침에 따름)
- **거부 방법과 효과:** Cloudflare를 거치지 않고는 홈페이지·웹 게임·앱에 접속할 수 없어요. 원하지 않으면 홈페이지·웹 게임·앱을 쓰지 않고 카카오톡 채널 챗봇으로만 이용하거나, 계정을 삭제해 주세요.

**② Google Fonts (일부 예전 화면의 글꼴)**

- **법적 근거:** 「개인정보 보호법」 제28조의8제1항제3호
- **이전하는 항목:** 접속 IP, 브라우저 정보
- **이전 국가:** 미국 회사가 운영하는 전 세계 네트워크
- **이전 시기·방법:** 예전 화면(`/my?g=1`, `/play`, `/duel`, `/battle`)을 열 때, 암호화된 연결(HTTPS)로 전송
- **이전받는 자:** Google LLC — [Google 개인정보처리방침](https://policies.google.com/privacy)
- **이용 목적:** 글꼴 파일 전송과 그 요청의 보안. Google은 이 기능에서 쿠키를 쓰지 않고, 이용자 프로필이나 광고에 쓰지 않는다고 안내해요([Google Fonts 안내](https://developers.google.com/fonts/faq)).
- **보유·이용 기간:** Google의 방침에 따름
- **거부 방법과 효과:** 위 예전 화면을 열지 않으면 전송되지 않아요. 새 홈페이지와 웹 게임(`/game`)은 글꼴을 갈매미맨 서버에서 받아요.

<h2 id="p8">8. 개인정보의 안전성 확보조치</h2>

갈매미맨이 실제로 하고 있는 조치예요.

- **암호화된 연결:** 홈페이지·웹 게임·앱 접속은 모두 HTTPS로 암호화해요.
- **접근 통제:** 게임 서버는 외부에 직접 열려 있지 않고, Cloudflare 연결을 통해서만 접속돼요. 카카오 챗봇 요청은 비밀 키가 맞는 요청만 처리해요.
- **로그인 보호:** 로그인 쿠키는 브라우저 스크립트가 읽을 수 없게(HttpOnly) 하고, 로그인 코드는 10분만 유효해요. 짧은 시간에 너무 많이 보내는 요청은 막아요.
- **최소 저장:** 좋아요 중복 확인에 쓰는 IP는 되돌릴 수 없는 값으로 바꿔서만 저장해요. 서버 작동 기록에는 카카오 이용자 구분값, 대화 내용, 비밀 키를 남기지 않아요.
- **백업:** 백업 파일은 서버 관리자만 읽을 수 있는 권한으로 만들고, 무결성을 확인한 뒤 최근 7개만 남겨요.
- **비밀 정보 관리:** 비밀 키와 비밀번호는 서버 설정 파일에만 두고 소스 코드 저장소에 넣지 않아요.

<h2 id="p9">9. 개인정보 자동 수집 장치(쿠키 등)의 설치·운영 및 거부</h2>

**① 쿠키** — 쿠키는 웹사이트 서버가 브라우저에 보내는 작은 정보로, 이용자의 기기에 저장됐다가 다시 접속할 때 서버로 자동 전송돼요. 갈매미맨은 **로그인을 유지하는 데에만** 쿠키를 써요.

| 쿠키 | 목적 | 보관 기간 |
|---|---|---|
| 로그인 쿠키 | 홈페이지·웹 게임 로그인 유지 | 30일 |
| 카카오 로그인 임시 쿠키 | 카카오 로그인 중 위조 요청 방지, 로그인 뒤 돌아갈 곳 기억 | 10분 |

광고나 맞춤형 서비스를 위해 이용자를 알아보는 행태정보는 수집하지 않아요.

**② Cloudflare 방문 통계(Web Analytics)** — 홈페이지에는 Cloudflare, Inc.의 방문 통계 스크립트(`static.cloudflareinsights.com`)가 붙어 있어요. 이 스크립트는 페이지 주소, 이전 페이지(referrer), 페이지 표시 속도 같은 정보를 Cloudflare로 보내 방문 수와 속도 통계를 만들어요. Cloudflare는 이 기능이 쿠키나 브라우저 저장소를 쓰지 않고, 개인을 알아보는 방식으로 쓰지 않는다고 안내하고 있어요([Cloudflare 안내](https://developers.cloudflare.com/speed/observatory/rum-beacon/)).

**③ 거부 방법** — 브라우저 설정으로 쿠키를 막거나 지울 수 있어요. 다만 로그인 쿠키를 막으면 홈페이지·웹 게임에 로그인할 수 없어요(카카오톡 챗봇은 그대로 쓸 수 있어요). 방문 통계는 브라우저의 추적 방지·광고 차단 기능으로 막을 수 있어요.

- 크롬(PC): 오른쪽 위 ⋮ → 설정 → 개인정보 보호 및 보안 → 서드파티 쿠키 / 인터넷 사용 기록 삭제
- 엣지(PC): 오른쪽 위 ··· → 설정 → 개인 정보, 검색 및 서비스 → 추적 방지 / 쿠키
- 크롬(휴대폰): 오른쪽 위 ⋮ → 설정 → 사이트 설정 → 서드파티 쿠키
- 사파리(아이폰): 설정 → 앱 → Safari → 고급 → 모든 쿠키 차단
- 삼성 인터넷: 아래쪽 ≡ → 개인정보 → 스마트 추적 방지
