## 1. 저장하는 정보와 쓰는 곳

| 정보 | 언제 | 쓰는 곳 |
|---|---|---|
| 카카오톡 채널 챗봇 이용자 구분값 (카카오가 챗봇에 보내 주는 값) | 챗봇에 처음 말을 걸 때 | 게임 계정 구분 |
| 카카오 로그인 회원번호 | 홈페이지에서 「카카오로 로그인」을 연결한 경우만 | 홈페이지 로그인 |
| 카카오 앱 회원번호(appUserId) | 카카오가 챗봇 요청에 함께 보내 주는 경우만 | 홈페이지 카카오 로그인 자동 연결 |
| 닉네임 · 칭호 | 직접 정한 경우만 | 랭킹·댓글에 표시 |
| 댓글 내용 | 댓글을 쓴 경우만 | 도감·수다방에 표시 |
| 게임 기록: 가진 갈매미, 도감, 뽑기권·새우gang·땅콩, 뽑기·조합·상점·탐험 기록(시각 포함), 미션, 아이템, 편성, 스토리 진행 | 게임을 하는 동안 | 게임 진행, 부정 이용 확인, 고객 문의 확인 |
| 로그인 쿠키 | 홈페이지에 로그인한 경우 | 로그인 유지(30일) |
| 좋아요 중복 확인값 | 홈페이지에서 좋아요를 누른 경우 | 같은 댓글에 여러 번 누르지 않게. 접속 IP를 비밀값과 섞어 되돌릴 수 없게 바꾼 값만 저장해요 |

**저장하지 않는 것:** 이름, 전화번호, 이메일, 주소, 결제 정보, 카카오 프로필(닉네임·사진)과 친구 목록.

## 2. 보관 기간

- 계정을 삭제하면 위 정보를 바로 지워요.
- 서버 백업(하루 1개, 최근 7개 보관)에는 최대 7일 동안 남아 있다가 자동으로 사라져요.
- 홈페이지 로그인 코드는 10분만 쓸 수 있고, 다음에 코드를 받을 때 지난 코드를 지워요.

## 3. 다른 곳에 주는 정보

다른 회사나 사람에게 팔거나 넘기지 않아요. 게임을 운영하려고 아래 서비스를 이용해요.

- **카카오:** 카카오톡 채널 챗봇, 카카오 로그인
- **Amazon Web Services:** 게임 서버
- **Cloudflare:** 홈페이지 접속 연결
- **Google Fonts:** 홈페이지 글꼴 (글꼴을 받을 때 브라우저가 구글 서버에 접속해요)

## 4. 내 정보 보기 · 지우기

- **보기:** 홈페이지 「내 갈매미」에서 로그인하면 볼 수 있어요.
- **지우기(탈퇴):** 「내 갈매미」 → ⚙️ 계정 → 계정 삭제. 앱이 없어도 [계정 삭제 안내](/account/delete) 페이지를 따라 하면 돼요.
- 카톡 채널에 「탈퇴」를 보내도 방법을 알려 드려요.
