# 네이티브 UI 모션 리소스 v1

## 사용 권장
실제 앱은 `buttons/*_normal.png` 6종과 `icons/*.png` 6종을 우선 사용합니다. `_pressed.png`, `_disabled.png` 12개는 디자인 참고용입니다. 생성된 상태별 그림은 윤곽·장식·위치가 조금씩 달라서 빠른 상태 교체에 쓰면 흔들릴 수 있습니다. normal PNG를 유지한 채 코드에서 눌림 축소·이동과 비활성 투명도를 적용하세요.

`runtime.json`의 경로는 이 디렉터리 기준이며 모든 참조 PNG를 함께 제공합니다. 원본 아틀라스나 미포함 파일에 의존하지 않습니다. `assetRoot`는 저장소 경로입니다. Android AssetManager에서는 `native/ui-motion-v1/` 접두어를 사용하세요. 리소스 추가만으로 이벤트·내비게이션·렌더링이 연결되지는 않습니다.

## 버튼 매핑
- blue_banner: 파란 가로 버튼
- sealed_banner: 붉은 봉인 편지 가로 버튼
- blue_round: 파란 원형 버튼
- split_pill: 양피지·파란 캡슐 버튼
- parchment_square: 양피지 사각 버튼
- parchment_panel: 양피지 가로 패널

각 종류는 세 상태의 캔버스 크기를 일치시켰습니다. 362px 전체 너비에는 투명 여백이 있으며 높이는 종류마다 다릅니다. 비율을 보존해서 표시하세요. 텍스트와 아이콘은 별도 레이어로 올리는 구성을 권장합니다.

`contentInsets`는 전체 PNG 캔버스 기준 0~1 비율이며 순서는 left/top/right/bottom입니다. normal 그림을 보고 보수적으로 정한 텍스트 영역 초안입니다. sealed_banner는 왼쪽 봉인을, split_pill은 오른쪽 파란 부분을 피합니다. blue_round와 parchment_square는 넓은 투명 여백을 포함해 중앙만 사용합니다. 9-slice 경계나 실제 글꼴의 안전 영역을 측정한 값이 아니므로 한글 문구 길이·폰트·터치 영역은 구현 시 검수하세요.

## 아이콘 매핑
close=닫기, settings=설정, info=정보, book=책/도감, gem=보석, mail=우편입니다. JSON의 suggestedAction은 의미 제안이고 실제 앱의 동작 연결은 별도입니다. 원본 셀 간격이 달라 개별 캔버스 크기가 다릅니다. `visibleBoundsAlpha128`은 알파 128 이상 픽셀의 실제 경계(x,y,width,height)로, 배치 기준을 잡을 때 참고할 수 있습니다. 약한 그림자/발광은 이 경계 밖에도 있으니 해당 범위로 이미지를 잘라내지는 마세요.

## 코드 애니메이션 제안
- 눌림: 약 100ms, scale 0.97, translationY 1dp. 해제: 120ms에 원래 값 복귀.
- 비활성: 이벤트를 막고 정적 alpha 약 0.55. 접근성 상태도 함께 반영.
- 힌트: 단일 안정적 에셋에 2초 주기로 scale 1 → 1.03 → 1, opacity 0.8 → 1 → 0.8. 새로 그린 프레임을 교체하는 방식은 사용하지 않음.
- 모션 줄이기 설정에서는 확대·이동·반복 맥동을 끄고 정적 피드백 유지.

## 힌트 시트 검토 기록
생성된 8프레임 힌트 테두리는 프레임 사이의 모서리 장식과 윤곽이 조금씩 달라 프로덕션 앱 리소스에서 제외했습니다. 8 × 250ms의 2초 반복 검토를 수행했지만 안정된 최종 애니메이션으로 취급하지 않습니다. 이 저장소 업로드에는 힌트 PNG/GIF/원본 아틀라스를 포함하지 않습니다.

## 투명도와 검수
RGBA 원본을 크롭했으며 색상·알파 수정, 배경 제거 또는 재작화를 하지 않았습니다. 밝은 회색 배경 합성에서 투명도를 확인했습니다. 알파를 무시한 뷰어에서는 투명 픽셀의 RGB 때문에 갈색 배경이나 색 외곽이 보일 수 있습니다. 실제 앱의 premultiplied alpha, 축소 필터링, 밝고 어두운 게임 배경에서 최종 확인하세요.

기준 커밋: d9f2375. 이 문서는 리소스 통합 안내이며 구현 완료나 런타임 테스트 성공을 뜻하지 않습니다.
