이 게임에서 추가한 편집
   - MP3를 44.1 kHz stereo 부동소수 PCM으로 디코딩.
   - 파도 2초, 잔물결 1.2초/0.8초 equal-power 순환 겹침.
   - 파도 10 kHz, 물결 8 kHz, 갈매기 5.2 kHz 저역통과 필터.
   - 가까운 잔물결은 주 파도보다 RMS 7 dB 낮게 혼합.
   - 갈매기는 3.2, 17.4, 34.6, 47.8초에 좌우로 낮게 배치.
   - EBU R128 2-pass -21 LUFS 목표, -5.5 dBTP 상한.
   - OGG Vorbis quality 4, 44.1 kHz stereo로 압축.
   - 반복 경계의 불연속, 유한한 PCM, 음량, 길이와 디코딩을 자동 확인.

재현
   원본 배포 파일 5개와 prepare_harbor_ambience.py를 같은 폴더에 두고:
   python3 prepare_harbor_ambience.py
   필요 도구: Python 3, NumPy, SciPy, ffmpeg(libvorbis), ffprobe.
   OGG 컨테이너 식별자는 재인코딩마다 달라질 수 있습니다.

   자연스러운 반복, 갈매기 크기, 조작 효과음과의 균형을 확인해야 합니다.
