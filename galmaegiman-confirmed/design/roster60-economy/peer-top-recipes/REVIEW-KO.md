# 최상위 동급 조합 검토 — 운영 변경 없음

확정 방향: 제한·초월·불멸·영원은 동급 최상위, 수직 진화 아님. 모집 구성은 하급 C/UC/R, 중급 UC/R/낮은 E, 고급 R/E/극소 L 또는 H이며 최상위4종류 제외. 비용·확률·천장·직접 지급 레벨 미정(에픽Lv15만 확정). 이전 고급 UC80% 후보는 최신 모집 구성에 의해 대체된 과거 문서다. 이번에는 모집 수치 계산을 추가하지 않는다.

## 실제 행 점검과 기본 전후안
새60종 catalog의52레시피 중 최상위16개 전부 점검: 최상위 재료 의존0, 불멸/영원에 제한/초월 재료 사용0. 보존된 구 data/units.json 145종의 최상위 레시피에서도 동급 최상위 재료 의존0. 따라서 해당 오류를 수정한다며 실제 없는 행을 만들어 교체하지 않는다. 원본 워크북 검토안과 제품 시험 프로필은 별도 상태이며 이번 검토는 활성 프로필 기준이다.

기본 제안은 아래16개 유지. 모든 재료 최소Lv25,각1개,최저 결과Lv25는 현재 시험값이며 새 승인값이 아니다. 수치는 커먼Lv1부터 모두 조합으로 마련하고 각 단계 최소 요구레벨에서 실행한 조건이다. 조합 누적XP평균내림을 사용하며 이미 소비된 재료 육성까지 합산한 외부XP이다. 모집·시작선물 할인과 플레이 시간 환산 없음.

## 별도 선택안: 영원 일부의 육성 부담 완화 (미승인)
필수 의존 오류 수정이 아니라 같은 최상위 안의 부담 차이를 줄이는 선택안이다. 아래2개 외 레시피·미니 재료 배분은 변경하지 않는다.

|결과|기존|선택 제안|커먼 환산 전→후|XP 전→후|
|---|---|---|---:|---:|

## 비용 편차와 검증
- 기존 등급별 커먼 환산 평균: 제한27.25 / 초월31.75 / 불멸31.25 / 영원36.0.
- 외부XP 평균: 제한143,375 / 초월159,081 / 불멸154,470 / 영원176,071.
- 선택2안 적용 시 영원 평균 커먼34.0, XP162,407. 개별 편차는 남지만 영원을 일괄 다음 단계로 요구하는 경로는 없다. 동급은 개체별 비용 완전 동일을 뜻하지 않으며 수치 평준화를 자동 승인하지 않는다.
- 전체60개가 커먼까지 도달,52개 레시피 순환0/없는ID0. 모든 최상위 최저 결과Lv25. 새 조합은 커먼 공급만 있어도 구조상 도달 가능하나 실제 XP 분배·공급 속도/시간은 검증 불가.
- 미니 병목 분산은 여전히 별도 미승인. 이번 선택안도 미니 병목 해결안이라고 주장하지 않는다.
