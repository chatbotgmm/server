# 조합 중심 모집 경제 검토안

상태: 방향(조합 중심)만 승인. 아래 확률·가격·천장·수급 방침은 전부 검토안이며 런타임 변경 없음. 기준 cefbaf0 및 five-stat-device-test-v1. 원본 레시피는 시험 프로필 자료이며 최종 운영 레시피 확정으로 확대하지 않는다.

## 추천 1개 / 완화 1개
모집은 재료 확보, 에픽 직접 모집은 육성 과정을 건너뛰는 희소 보너스로 둔다. 상위 등급 직접 모집은 제안하지 않는다.

|모집|지원서 가격|커먼|언커먼|레어|에픽|
|하급|3|75%|25%|0|0|
|중급|8|40%|55%|5%|0|
|고급 추천|20|20%|65%|14%|1%|
|고급 완화 대안|20|20%|64%|14%|2%|

각 등급 안에서는 8종 균등을 가정한다. 각 행 100%. 에픽만 직접 지급 Lv15 확정. 언커먼은 현재 하급 Lv1 동작을 변경하지 않지만 신규 등급표의 지급 레벨을 승인한 것으로 해석하지 않는다. 중/고급의 언커먼·레어 지급 레벨은 별도 확인 전 활성화하지 않는다.

추천 천장: 고급에서 에픽 없이 199회면 200번째 에픽 확정, 획득하면 초기화. 완화안은 99회 후100번째. 천장은 고급만 누적, 재접속/기간 경과로 리셋하지 않는 제안. 어느 에픽인지는 등확률이며 특정 종 보장은 아니다. 구 LEGEND 100회 천장을 이식하거나 기존 누적값을 삭제하지 않는다. 구 누적값의 이관/보상은 별도 승인 사항이다. 하/중급 추가 천장은 이번 안에 없음.

추천의 근거: 지원서당 재료 확보는 하급이 가장 유리하고, 중/고급은 레어 직접 획득으로 중간 조합·육성 일부를 건너뛰는 선택지다. 지원서100장당 기대 언커먼은 하8.33/중6.875/고3.25, 레어는 중0.625/고0.7. 따라서 고급만 계속 뽑아야 하는 구조를 지향하지 않는다. 다만 레어 지급 레벨이 미정이라 육성 절약 가치까지 확정 비교할 수 없다. 확률1%/2%와 가격3/8/20은 실측 최적값이 아닌 조합 우선 목표에 맞춘 시험 제안이다.

## 무료 수급: 현행 유지 가정, 일일 상한 신설 아님
근거: data/economy.yaml, src/game.ts claim/attend/player/coupon. 가입200장1회, 수동 무료30장/1시간cooldown, 첫주 출석8/10/12/14/16/18/40 합118. 다음 주부터 출석 하루+2씩 최대+10. 미접속 시간 자동 적립 아님. 광고/새 미션/구 전투 포인트/친구초대는 새 흐름에 연결 확인이 안 되어 제외한다.

- 신규7일: 매일 무료 수령2회 + 7일 연속 출석 + 신규 가입 = 200+420+118=738장.
- 기존500장 쿠폰을 별도로 정상 수령했다면 1,238장. 기존 보유분/쿠폰 몰수·초기화·삭제는 제안하지 않으며 어떤 변경도 별도 승인 필요. 쿠폰을 이미 쓴 계정에 재지급하는 가정도 아님.
- 일반1일 예: 출석 주차 보너스가 최대+10인 계정의 연속출석4일차, 무료2회 = 60+(14+10)=84장. 가입/쿠폰 없음. 하루 출석 보상은 날짜에 따라 달라진다.
- 무료2회는 활동 가정일 뿐 수령 제한이 아니다. 매일4회면 신규7일1,158장. 많이 접속할수록 직접 에픽 획득도 늘어나므로 실제 플레이 측정 후 재평가해야 한다.

## 모집 계획별 직접 에픽 기대값 / 1회 이상 확률
모든 표는 천장 누적0에서 시작. 현재 창의 뽑기 횟수는 천장보다 작아 E=np, P(≥1)=1-(1-p)^n. 천장 직전 기존 계정에는 적용할 수 없다. 표의 기대값은 조합으로 만드는 에픽을 포함하지 않는다.

|활동·지출 가정|고급 횟수|추천1% 기대/최소1회 확률|완화2% 기대/최소1회 확률|
|신규7일 재료 중심: 하179·중20·고2=737장|2|0.02 / 1.99%|0.04 / 3.96%|
|신규7일738장 전부 고급,18장 잔액|36|0.36 / 30.36%|0.72 / 51.68%|
|신규7일+쿠폰1,238장 전부 고급,18장 잔액|61|0.61 / 45.83%|1.22 / 70.84%|
|일반1일84장 전부 고급,4장 잔액|4|0.04 / 3.94%|0.08 / 7.76%|

재료 중심 계획에서 쿠폰500장은 추가 하급166회(498장)로 쓰는 비교안이면 고급 횟수/직접 에픽 확률은 그대로다. 사용 강제가 아니다. 일반1일 재료 계획은 하24+중1=80장,4장 보관: 직접 에픽 기대0,획득확률0. 잔액을 모아 고급을 살 수 있지만 다음날 계산에 임의 포함하지 않는다.

신규 재료 계획의 기대 재료: 커먼142.65, 언커먼57.05, 레어1.28, 직접 에픽0.02(추천). 등급 내 평균일 뿐 특정 재료 보장 없음. 이것을 에픽 조합 완성 개수로 바꾸려면 실제 XP 수급과 선택한 조합·보유 분포가 필요하다.

추천 천장 포함 첫 에픽 기대 고급86.602회=1,732.04장, 최악200회=4,000장에 아무 에픽1개 보장. 완화는43.369회=867.38장, 최악100회=2,000장. 천장 없는 단순기대는 각각2,000/1,000장이다. 이 비용은 즉시Lv15 획득이며 플레이 소요시간 보장 아님.

## 조합 재료 및 육성 비교
모든 커먼을 Lv1에서 시작, 중간 조합은 모든 재료가 각 최소 레벨에 정확히 도달했을 때 실행, 결과 XP는 평균 내림, 결과 레벨은 Lv5→10→15인 시험 프로필 조건. 누적XP Lv5=341,Lv10=2,222,Lv15=6,400. 아래 XP는 최종6,400만이 아니라 소비되는 중간 개체 육성에 외부에서 얻어야 하는 XP 합이다. 파티 XP 분배는 미정이므로 전투횟수·시간으로 환산하지 않는다.

|에픽|커먼 환산 재료 수|총 외부 육성XP|필요 커먼을 하급으로 모을 기대 지원서|
|룬장인|7|18,267|114.79|
|드라이어드|6|22,104|95.74|
|미노타우로스|6|16,045|87.68|
|인어기사|10|23,052|125.01|
|서리마녀|8|24,667|101.77|
|그리핀|8|20,489|111.45|
|듀라한|8|22,370|121.76|
|화룡|8|18,608|101.77|

재료 기대비용은 하급C75%/8종,3장, 목표별 정확한 필요 중복 수를 모으는 흡수상태 DP 계산. 미보유에서 시작하고 시작 u01/튜토 선택권은 주력으로 보존하여 할인하지 않았다. 뽑힌 언커먼과 남는 커먼은 계산에 재사용하지 않는 보수적 커먼 전용 경로다. 이는 6~10번 뽑으면 된다는 뜻이 아니다. 필요한 종류의 중복 때문에 기대29~42회가 필요하며 무작위 획득에 유한 보장은 없다. 여러 에픽을 함께 만들 때 남는 재료를 공유하므로 이 비용을 단순 합산하면 안 된다. 별도 조합 수수료와 레시피 변경은 이 비교에 없으며 신규 경제 전체 승인으로 간주하지 않는다.

조합은 약88~125지원서 + 약1.60만~2.47만 육성XP, 직접은 추천 평균1,732지원서로 Lv15 즉시 획득이라는 역할 분리가 생긴다. XP 획득 효율이 나쁘면 조합이 체감상 더 비쌀 수 있으므로 시간 효율까지 확정하지 않는다.

## 공통 재료 병목
에픽8종 각1개를 커먼부터 만들면 총61개: 미니16(26.23%),갈매미맨12(19.67%),그림자8,꽃6,자이언트6,물방울5,황금4,불씨4. 미니는 모든 에픽의 조합 경로에 포함. 균등 커먼 공급12.5%에 비해 미니 수요는 약2.10배,갈매미맨은1.57배다. 초기엔 다른 재료가 남고 미니를 기다릴 가능성이 높다.
기존 튜토 선택권으로 미니1개를 고를 수 있지만 병목 전체 해결은 아니다. 이번에는 선택권 추가 지급/미니 확률 상향/레시피 치환을 실행하거나 새 기본안에 숨기지 않는다. 먼저 현행 시험 레시피로 플레이 측정 후, 병목이 과하면 '중간 조합의 미니 요구 일부를 다른 커먼으로 분산'을 별도 검토할 것을 권한다.

## 확정이 필요한 최소 묶음
1. 추천1%/200회 또는 완화2%/100회, 가격3/8/20 및 전체 확률표.
2. 중/고급 언커먼·레어 직접 지급 레벨. 에픽15만 확정.
3. 구 천장 누적값 처리. 기존 보유 지원서·쿠폰 권리 보존, 몰수/초기화는 별도 승인 없이는 불가.
4. 미니 병목을 유지하고 시험할지, 레시피 분산안을 먼저 검토할지.

계산은 calculate.py → calculations.json으로 재현. 런타임 파일/DB/운영 가격 변경 없음.
