## 순위권 모바일 게임 참고

`references.json`에 순위의 국가·플랫폼·집계 기간과 공식 출처를 기록합니다. 현재 실시간 순위로 표현하지 않습니다. 포켓몬 카드 게임 Pocket은 수집물의 크기와 획득 흐름, 세븐나이츠 리버스는 성장·편성 정보, 붕괴: 스타레일은 기술·상성·효과의 읽기 순서, 쿠키런: 킹덤은 캐릭터·세계와 고정 탐색을 참고했습니다. 타사 이미지와 UI 자산은 복사하지 않습니다.

실제 구현은 주요 행동을 청록색으로 구분하고 종이 면·얇은 가죽 테두리·작은 금속 장식으로 재질을 정리합니다. 원본 카드·캐릭터의 비중을 키우고 메인 성장 안내, 편성 자리와 후보, 기술의 위력·배율·효과를 명확하게 배치합니다. 기존 기술·가격·확률·전투 규칙은 유지합니다.

UX74 검증은 Android 통합 141항목과 캡처 환경 보완 후 관련 23항목 재검증을 합산해 139개 통과, 선택 실행용 컨셉 렌더러 2개 제외입니다. 실제 View/Skia PNG 160장과 버튼 배치 캡처 122건에서 스크롤로 접근할 수 없는 버튼 잘림은 0건이며, 보호 원본 438개 SHA-256도 불변입니다. 실기기 테스트와 구분되는 렌더·동작 검증입니다.

시안과 실제 배치가 같은 것은 아닙니다. 챕터 지도는 기존 챕터·스테이지 목록, 상성 대형 카드는 실제 팀 요약·필터, 설정 탭은 두 열 스크롤 창으로 구현되어 있습니다. 실제 게임 기능과 정보량을 유지하며 재질·가독성·행동 위계를 먼저 반영했습니다.
