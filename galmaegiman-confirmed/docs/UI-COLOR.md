# 게임 화면 색 규칙 (갈매미맨 수비대)

## 현재 네이티브 테마: C 「선장의 모험일지」 (2026-10-15)

사용자가 승인한 C 시안의 양피지·지도·잉크와 목재·황동을 Java View/Canvas로 적용해요. 아래의 이전 도감·웹·파스텔 테마 기록보다 이 규칙을 먼저 따라요. CSS·WebView는 사용하지 않아요.

### 플레이 흐름 원칙 (2026-10-15)

- 게임은 직관적이고 가볍게 진행해요. 플레이어는 보고 바로 고르고, 결과로 규칙을 이해할 수 있어야 해요.
- 전투 기술 카드는 기술명·현재 위력/상성·짧은 핵심 효과만 보여 줘요. 기술마다 상세 버튼과 팝업을 반복하지 않아요.
- 조합 가치 계산과 긴 효과 설명은 육성·학습 준비 화면에 두고, 전투 중 계산을 요구하지 않아요.
- 속성마다 공격 방식과 연계는 다르게 하되, 선택·확인 단계나 새 관리 항목을 불필요하게 늘리지 않아요.

- 정보 면은 양피지 `#f5efdc`, 글자는 잉크 `#292d2a`, 보조 글자는 `#58635d`예요. 78판부터 APK의 작은 종이 재질을 늘이지 않고 반복해 미세한 결을 넣어요. 실제 섬유가 있는 종이·선택 면에서도 보조 글자가 대비4.5를 넘도록 이전 보조 잉크보다 조금 진하게 조정했어요. 진한 바랜 자국과 지도 장식은 가장자리 약9dp 안에 두고, 본문 중앙은 밝고 고요하게 유지해요.
- 프레임은 짙은 목재 `#34261f`, 이중 테두리와 작은 리벳은 황동 `#b68b45`예요. `JournalTheme`와 공통 Drawable이 비율에 맞춰 그려요. 봉제 가죽과 늘인 프레임 그림은 사용하지 않아요. 장식은 자신의 bounds 밖이나 터치 영역으로 번지지 않아요.
- 주요 행동은 청록 `#245b61`와 흰 글자 `#ffffff`, 보조 행동은 양피지 면과 잉크 글자예요. 선택은 연한 청록 면과 청록 글자·안쪽 선으로 구분하고, 비활성도 불투명한 밝은 면과 보조 글자로 읽을 수 있게 해요. 눌림은 즉시 짧게 내려가며 표시해요. 기존 버튼 배치와 48dp 기준의 터치 영역은 유지해요.
- 78판은 공통 섹션·설정·입력·목록 선택도 위 재질을 사용해요. `플레이·만들기·저장·보상 받기·합동기`의 실행 버튼은 청록으로 구별하고, 일반 기술은 양피지와 작은 도구/속성 기호를 사용해요. 전투는 일반 기술4개 뒤에 합동기를 배치해요.
- 기본 페이지에는 세로 스크롤을 두지 않아요. 선택한 대상의 정보와 주요 행동은 한 화면에 고정하고, 긴 목록·검색·부가 설정은 명확한 버튼으로 모달에서 열어요. 모달 안의 긴 내용만 세로 스크롤을 허용해요. 글자나 버튼 높이를 압축하거나, 스크롤을 막은 채 내용을 잘라서 해결하지 않아요.
- 제목·버튼은 기존 Jua, 긴 본문은 GowunDodum을 사용해요. 글자가 포함된 이미지 버튼 대신 실제 텍스트를 써요.
- 사용자 선택 G 첫 화면은 황동 테두리·짙은 금갈색 시작 버튼을 사용해요. 다른 메뉴의 청록 주요 행동 규칙은 유지해요. 타이틀의 크림 글자는 시간대와 무관한 어두운 바탕에서 읽히고, UI 밝기와 위치는 고정해요.
- 배경은 APK에 포함한 항구와 기존 장소 이미지를 사용해요. 현지 시각에 따라 배경과 주변 빛만 바뀌고, 위 양피지·글자 밝기·메뉴 위치는 고정해요. 시간에 따른 어둠을 정보 UI 전체에 덮지 않아요. 기존 전투의 장소와 캐릭터 레이어는 보존해요.
- 기능 아이콘은 `JournalIcons`의 일관된 황동·청록·잉크 기호를 사용해요. 화폐·상태·증강체의 의미가 서로 구별되어야 해요.
- 기존 33종 전후 캐릭터, 145종 수집 그림과 카드 원본은 유지해요. 로비 캐릭터도 원본 알파 영역을 그대로 배치해요.
- 체력·상성 유불리·10속성·등급의 의미 색은 유지해요. 카카오 로그인과 계정 삭제의 브랜드·위험 표시도 구별해요.
- UI는 안전 영역 안에 고정하고, 중앙 드래그는 배경·소품·캐릭터만 깊이에 따라 이동해요. 태블릿 전투에서 남는 높이는 기록창에 배분해요.

## 랜덤 디펜스(웹, `public/defense`) 색: Color Hunt 「로열 블루 + 연청」 (2026-11-21)

출처: Color Hunt 팔레트 <https://colorhunt.co/palette/2936814274d995ccddd0e7e6> — `#293681` · `#4274D9` · `#95CCDD` · `#D0E7E6`.
처음엔 「남색 깃발 + 금테」(남색·금·크림)로 했지만 사용자가 **세 색이 서로 안 어울리고, 판 색과 버튼이 따로 논다**고 해서, Color Hunt에서 실제 팔레트 4개를 버튼·창·판 모형에 입혀 비교한 뒤 사용자가 이 조합을 골랐어요. 첫 화면 항구 그림의 하늘·바다 파랑과 같은 계열이라 배경 그림과도 어울려요.

**게임 전체**(첫 화면·대기실·판·판 안 모든 창·조합식 웹페이지 `recipes.css`)에 같은 규칙을 써요. 값은 `defense.js`의 `C`(공통)와 `BTN`(버튼) 두 곳에 모여 있고, 버튼·메뉴 버튼·탭은 모두 `btnFace`/`tabFace`로 그려요(손으로 색을 따로 칠하지 않기). `C.gold`·`C.goldEdge`는 예전 이름만 남은 강조색이에요(지금은 `#95CCDD`·`#D0E7E6`).

| 종류 | 바탕 | 테두리 | 글자 | 쓰는 곳 |
|---|---|---|---|---|
| 주요 `primary` | 파랑 그라데이션 `#4f82e0 → #3a63c4`(`#4274D9` 둘레) | 연청 `#95CCDD` | 흰, 부가 글 `#D0E7E6` | 그 화면의 실행(혼자 하기·고른 난이도·기술 쓰기·사기·상급 모집·증강체 「고르기」) |
| 보조 `normal` | 옅은 청록 `#D0E7E6` | 연청 `#95CCDD` | 로열 블루 `#293681` | 나머지 행동(메뉴·조합법·모으기 등) |
| 조용한 `quiet` | 반투명 로열 블루 `rgba(41,54,129,.66)` | 옅은 연청 | `#e8f3f3` | 닫기·뒤로 |
| 위험 `danger` | 붉은 그라데이션 `#c23a30 → #8e2620` | `#ffc2b0` | 흰 | 판매·정예 보내기(의미 색이라 팔레트 밖) |
| 못 누름 | 회색 `rgba(40,52,66,.78)` | 회색 | `#8d99a6` | 조건이 안 될 때·잠긴 칸 |

- **창(패널) 바탕**: 짙은 로열 블루 `rgba(30,40,100,.95)`·`rgba(24,32,78,…)`, 화면 바탕 `#10163a`. 테두리·제목 강조는 연청 `#95CCDD`.
- **판**: 바다 `#22307a → #2b3f96`, 적이 지나는 물길 `#4274D9 → #5a8ee0`, 섬 바닥은 푸른 회색 돌 `#7d889e → #8e99ae`(흰 갈매미가 보이게 한 톤 어둡게), 연석 `#D0E7E6`, 판 테두리 위·왼쪽 `#95CCDD`·아래·오른쪽 `#293681`. 상황판·띠·말뚝·표지판도 같은 네 색.
- 게임 안 바탕엔 그림을 깔지 않아요(2026-11-08 사용자: 뒤 배경이 보이면 눈이 아픔). 그림은 첫 화면·대기실에만.
- **탭·켜고 끄는 칩**: 켜짐 = 주요, 꺼짐 = 보조. 등급 색 글자를 쓰는 칸(선택 위습·꾸미기 등급 칸)은 꺼짐을 조용한으로 해서 등급 색이 읽히게 해요.
- **밝은 보조 버튼 위 부가 글**: 밝은 연두·하늘 글자는 안 읽혀서 `CREAM_SUB`로 짙은 같은 계열로 바꿔요.
- 의미 색(체력·등급·상성·물딜 주황/마딜 하늘·위험 빨강)은 팔레트와 별개로 그대로예요.
- 아이템 칸(위습 칸·조합법 카드·상점 물건 줄)은 정보 칸이라 등급 색 테두리를 유지해요.

이후 내용은 이전 웹·네이티브 디자인의 결정 기록이에요.

색은 `public/duel/index.html` 맨 아래 「색 규칙」 덩어리에 모여 있어요(`--accent` 등 변수). 이 문서는 **왜 그 색인지**를 적어요.

## 1. 출발점: 그림의 색을 쟀어요
대결 배경 9장 + 대표 그림을 k-means로 나눠 보니(채도 25% 이상인 픽셀의 색상각 분포):

| 색상각 | 비율 | 그림에서 |
|---|---|---|
| 0~30° (빨강·주황·갈색) | 67% | 흙·나무·돌 그림자·갈색 외곽선 |
| 30~60° (주황·노랑) | 18% | 크림 돌·금장식·노을 |
| 180~240° (청록·파랑) | 15% | 하늘·바다 |
| 60~180°, 240~330° | 거의 0% | — |

→ 그림은 **따뜻한 갈색·크림이 85%**. 이 계열 색으로 버튼을 칠하면 그림에 묻혀요.

## 3. 규칙 (색마다 역할 하나)
1. **바탕·칸 = 중립**: 크림 종이 `#fffaf0` + 갈색 테두리 `#7a4e2a`(그림의 외곽선 색). 글자는 짙은 갈색 `#3b2614`.
2. **주요 행동 = 연한 토피 `#dd9a58` + 짙은 갈색 글자 `#3b2614`(크게·두껍게), 화면마다 하나만**: 첫 화면 「이어하기」, 고르기 창 「확인」 버튼, 기술 배우기 「배우기」. 고른 카드의 테두리도 캐러멜(「이걸로 할게」가 같은 색).
   - 예외: **게임 첫 화면**의 「로그인/게임 시작」은 게임 이름과 한 세트인 크림·갈색 팻말(그림 위에 색 알약이 떠 보여서, v0.9.88).
3. **보조 행동 = 크림 종이 버튼**: 스토리·자유 대결·메뉴 아이콘·교체 등. 색을 칠하지 않아 주요 행동과 겨루지 않음.
4. **덜 중요한 행동 = 점선 테두리**: 도망치기·건너뛰기.
5. **금빛 = 진행·보상만**: 진행 막대, 별(승진).
6. **초록·빨강 = 정보만**: 유리·불리, 체력. 버튼에 쓰지 않음.
   - 예외: 설정의 「계정 탈퇴」 버튼만 빨강(되돌릴 수 없는 위험한 행동이라 일부러 눈에 띄게, v0.9.90). 펼쳐야 보이고 「탈퇴」를 입력해야 눌림.
7. **속성 색 = 속성만**: 속성 칩, 기술 카드 윗줄. 물리·마법은 색 대신 기호(⚔ 물리, ✦ 마법).

- 주요 행동 색만 바꾸려면 `--accent`(본색), `--accent-hi`(위쪽 밝은 색), `--accent-d`(테두리·그림자), `--accent-soft`(고른 카드 바탕) 네 개만 고치면 돼요.
