# 게임 화면 색 규칙 (갈매미맨 수비대)

색은 `public/duel/index.html` 맨 아래 「색 규칙」 덩어리에 모여 있어요(`--accent` 등 변수). 이 문서는 **왜 그 색인지**를 적어요.

## 1. 출발점: 그림의 색을 쟀어요
대결 배경 9장 + 대표 그림을 k-means로 나눠 보니(채도 25% 이상인 픽셀의 색상각 분포):

| 색상각 | 비율 | 그림에서 |
|---|---|---|
| 0~30° (빨강·주황·갈색) | 67% | 흙·나무·돌 그림자·갈색 외곽선 |
| 30~60° (주황·노랑) | 18% | 크림 돌·금장식·노을 |
| 180~240° (청록·파랑) | 15% | 하늘·바다 |
| 60~180°, 240~330° | 거의 0% | — |

→ 그림은 **따뜻한 갈색·크림이 85%**. 이 계열 색으로 버튼을 칠하면 그림에 묻혀요.

## 2. 버튼 색 고르기: 측정값
ΔE = 색 차이(CIE Lab). 「그림과 거리」는 그림 픽셀 중 가장 가까운 10%까지의 거리(클수록 그림 위에서 잘 보임). 흰 글자 대비는 WCAG 기준(일반 글자 4.5 이상, 큰 글자 3 이상).

| 후보 | 그림과 거리 | 흰 글자 대비 | 의미 색과 겹침(ΔE<25) |
|---|---|---|---|
| 산호 주황 #f0703a (v0.9.85) | 36 | 2.96 ✗ | 불리 빨강, 불 속성 |
| 청록 #1f8fa6 (v0.9.85) | 31 | 3.79 | – |
| 에메랄드 #13996b | 54 | 3.62 | 유리 초록 |
| 짙은 남색 #22385c | 26 | 11.74 | – |
| **보라 #6a46c8 (지금)** | **69** | **6.32 ✓** | – |
| 자주 #b03a8c | 54 | 5.48 | – |

→ 보라: 그림에 거의 없는 색이라 가장 눈에 띄고, 흰 글자가 기준을 넘고, 게임의 다른 의미 색과 안 겹쳐요.
(색이 감정에 주는 효과(색채심리)는 이 결정의 근거로 쓰지 않았어요. 측정할 수 있는 대비·구분만 썼어요.)

## 3. 규칙 (색마다 역할 하나)
1. **바탕·칸 = 중립**: 크림 종이 `#fffaf0` + 갈색 테두리 `#7a4e2a`(그림의 외곽선 색). 글자는 짙은 갈색 `#3b2614`.
2. **주요 행동 = 보라 `#6a46c8`, 화면마다 하나만**: 첫 화면 「이어하기」, 고르기 창 「확인」 버튼, 기술 배우기 「배우기」. 고른 카드의 테두리도 보라(「이걸로 할게」가 같은 색).
   - 예외: **게임 첫 화면**의 「로그인/게임 시작」은 게임 이름과 한 세트인 크림·갈색 팻말(그림 위에 보라 알약이 떠 보여서, v0.9.88).
3. **보조 행동 = 크림 종이 버튼**: 스토리·자유 대결·메뉴 아이콘·교체 등. 색을 칠하지 않아 주요 행동과 겨루지 않음.
4. **덜 중요한 행동 = 점선 테두리**: 도망치기·건너뛰기.
5. **금빛 = 진행·보상만**: 진행 막대, 별(승진).
6. **초록·빨강 = 정보만**: 유리·불리, 체력. 버튼에 쓰지 않음.
7. **속성 색 = 속성만**: 속성 칩, 기술 카드 윗줄. 물리·마법은 색 대신 기호(⚔ 물리, ✦ 마법).

## 4. 바꾸고 싶을 때
- 주요 행동 색만 바꾸려면 `--accent`(본색), `--accent-hi`(위쪽 밝은 색), `--accent-d`(테두리·그림자), `--accent-soft`(고른 카드 바탕) 네 개만 고치면 돼요.
- 바꿀 때도 2번 표처럼 「그림과 거리」와 흰 글자 대비 4.5 이상을 확인하는 걸 권해요.
