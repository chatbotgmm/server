# 이름 중심 화면 0.2.3 구현 기록

## 변경 범위

캐릭터 ID와 개체번호를 채팅 본문·도감·보유 목록·조합 목록·입력 예시에서 숨겼습니다. 이름, 등급, 필요한 수량을 중심으로 표시합니다. 캐릭터 75종의 이름·이미지·등급·성별·조합식 69개는 변경하지 않았습니다.

`src/presentation.ts`에서 전체 이름과 `갈매미맨`을 생략한 이름을 찾습니다. Unicode NFKC 정규화와 공백 제거로 띄어쓰기 차이를 허용합니다. 전체 이름 → 짧은 이름 → 부분 이름 순으로 찾으며, 후보가 여럿이면 목록을 반환합니다. 기존 ID 입력은 호환용으로만 허용합니다.

`내갈매미`는 DB의 개별 개체를 유지한 채 이름별 총수량/사용 가능 수량을 표시합니다. `잠금 이름`, `잠금해제 이름`, `땅콩떼기 이름`은 조건에 맞는 오래된 1마리를 사용합니다. 보유 수량이 많다는 이유로 한 번에 전부 처리하지 않습니다.

## 카카오 응답과 확인

[카카오 공식 응답 문서의 ListCard·ListItem·action.clientExtra](https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/answer_json_format)를 기준으로 구현했습니다. 리스트 항목은 최대 5개이고 `action: message`와 이름으로 된 `messageText`를 사용합니다.

조합/교환/표식 미리보기는 이미지(있을 때), 짧은 재료 안내, 진행/취소 목록으로 구성합니다. 확인 토큰은 항목의 `extra` 안에 앱이 정의한 `gmAction`, `gmToken`으로 넣고, 요청의 `action.clientExtra`에서 검증합니다. 이 두 키는 카카오 고정 필드가 아니라 문서가 허용하는 추가 데이터의 앱 자체 키입니다. 화면 발화는 `조합 확정`, `교환 확정`, `표식 전환 확정`, `취소`입니다.

이름 또는 추가 데이터 자체를 권한으로 신뢰하지 않습니다. 기존 플레이어/토큰 소유권·유효 시간·revision·재료 상태·완료 기록 검증과 DB 트랜잭션을 유지합니다. 토큰에 맞지 않는 발화는 거절합니다. 직접 `조합 확정`만 입력하면 소비하지 않습니다. 완료 요청을 재전송해도 다시 지급하지 않습니다.

기존 완료 응답에 코드명이 들어 있다면 저장 데이터는 유지하고 새 표시용 완료 안내를 반환합니다. 예전 메시지 자체를 카카오톡에서 수정하지는 않습니다.

## 관리자 설정

기존 스킬 URL과 헤더를 사용합니다. 게임 발화와 폴백 블록을 같은 스킬에 연결한 기존 설정이면 이름별 패턴을 추가할 필요가 없습니다. 다른 블록이 `조합 브라자 갈매미맨`, `조합 확정`, `교환 확정`, `취소` 등을 가로채면 해당 스킬로 요청이 전달되도록 조정해야 합니다.

테스트 요청에는 `action.clientExtra`를 실어 버튼 흐름을 검증했습니다. 실제 갤탭 ARM64 및 카카오 채널 렌더링은 이 작업 환경에서 직접 실행하지 않았습니다. 저장된 인증키·터널 주소·SQLite DB에는 패치가 접근하지 않습니다. 검증 결과는 TEST-RESULTS.md에 있습니다.
