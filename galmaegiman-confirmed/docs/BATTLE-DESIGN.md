# 수비대 대결 (/battle) — 포켓몬식 턴제 배틀 + 증강체 시험판

상태: **시험판(v0.9.45)**. 수치는 모두 가안이며 플레이해 보며 조정합니다.
코드: 규칙·화면 `public/battle/battle.js`, 유닛 능력치·타입 계산 `src/battle.ts`.

## 한 판의 흐름 (약 10~15분)
1. **팀 고르기**: 후보 8마리 중 3마리. (시험판. 정식판은 카톡에서 모은 내 갈매미 중에서 고름)
2. **대결 7번**: 3:3, 한 마리씩 나와 싸우는 턴제. 상대 팀은 갈수록 등급이 오름. 4번째는 팀장조, 7번째는 '섬의 전설'(전설 3마리).
3. 이길 때마다
   - 회복: 체력 50% 회복, 쓰러진 갈매미는 30%로 깨어남
   - **스카우트**: 이긴 상대 3마리 중 1마리를 데려와 내 팀 1마리와 바꿀 수 있음(포켓몬 잡기 느낌)
4. **증강체**: 1·3·5번째 대결 뒤 3개 중 1개(실버·골드·프리즘). 그 판이 끝날 때까지 계속 적용.
5. 모두 쓰러지면 끝. 7번 모두 이기면 클리어.

## 능력치 (src/battle.ts)
- 대상: 흔함~전설 90종. **히든·최상위·특수함은 넣지 않음**(공개 웹 데이터라 스포일러 방지).
- 동네별 기본(체력/공격/방어/속도): 기본 110/20/14/10, 황금 100/18/19/8, 암흑 86/22/9/16, 바다 118/19/12/9, 벚꽃 96/17/12/12, 우주 86/25/9/12, 의복 104/18/15/11
- 등급 배율(체력·공격·방어): 흔함 1.0, 안흔함 1.15, 특별 1.32, 희귀 1.52, 전설 1.75. 속도는 배율의 30%만.
- 같은 등급·동네끼리 똑같지 않도록 유닛 ID로 ±8% 흔들림(항상 같은 값).

## 타입(출신 동네) 정하는 법
- 지금 흔함~전설에는 동네 정보가 없어서, **조합 재료를 흔함까지 거슬러 올라가 가장 많이 들어간 출신 동네**를 타입으로 삼음.
  흔함 원형: 기본(C1)·거인(C7)·소인(C8)=기본, 황금(C2), 암흑(C3), 바다(C4), 벚꽃(C5), 우주(C6), 갈매미걸(C9)=의복.
- 기본·거인·소인은 거의 모든 조합에 섞여 있어 비중 0.3으로 낮춤.
- 둘째 동네가 30% 이상이면 **복합 타입**(22종).
- 이름과 안 맞으면 `src/battle.ts`의 `overrides`에서 직접 고침(현재: 빤스갈매미 → 의복+바다).
- 결과 분포(90종 첫째 타입): 바다 32, 우주 17, 벚꽃 13, 암흑 11, 황금 8, 기본 5, 의복 4 — 바다가 많아 이후 조정 필요.

## 상성 (공격 → 강한 상대 ×1.5, 거꾸로 ×0.67, 기본은 상성 없음)
| 공격 | 강한 상대 | 이유 |
|---|---|---|
| 바다 | 황금 | 무거운 금은 바다에 가라앉아요 |
| 황금 | 의복 | 금 장식 앞에서 옷이 초라해져요 |
| 의복 | 벚꽃 | 옷으로 꽃가루를 막아요 |
| 벚꽃 | 암흑 | 꽃이 피면 그늘이 밝아져요 |
| 암흑 | 우주 | 어둠이 별빛을 삼켜요 |
| 우주 | 바다 | 달이 바닷물을 끌어당겨요 |

## 기술
- 기본기: 타입마다 하나(위력 50). 복합 타입은 기본기 2개.
- 특기(첫째 타입):

| 동네 | 특기 | 효과 | 재사용 |
|---|---|---|---|
| 기본 | 갈매미 한 마리… | 상대가 세다가 잠들어 1턴 쉼 | 3턴 |
| 황금 | 도금 방패 | 2턴 동안 받는 피해 절반 | 3턴 |
| 암흑 | 그늘 기습 | 위력 85, 무조건 먼저 | 2턴 |
| 바다 | 해일 몸통박치기 | 위력 110 | 3턴 |
| 벚꽃 | 꽃잎 낮잠 | 체력 40% 회복 | 3턴 |
| 우주 | 운석 낙하 | 위력 150 | 4턴 |
| 의복 | 단단히 차려입기 | 3턴 동안 공격 +40% | 4턴 |

- 피해 = (공격 ÷ 방어 × 위력 × 0.5 + 2) × 상성 × 0.85~1.0 × 치명타(6.25%, ×1.5)
- 순서: 출근 도장(첫 턴) > 선공 기술 > 속도. 교체는 턴을 씀(인사 발령 증강체가 있으면 안 씀).

## 증강체 (16개)
| 등급 | 이름 | 효과 |
|---|---|---|
| 실버 | 새우gang 간식 | 대결 뒤 체력 25% 더 회복 |
| 실버 | 돌머리 | 모두 방어 +20% |
| 실버 | 출근 도장 | 대결 첫 턴은 무조건 내가 먼저 |
| 실버 | 금빛 시장 | 치명타 확률 +20% |
| 실버 | 바스락 소리 | 대결 시작 때 상대 선두 1턴 멈춤 |
| 실버 | 신입 연수 | 흔함·안흔함 모든 능력치 +30% |
| 실버 | 단체 사진 | 모두 최대 체력 +15% |
| 골드 | 야근 수당 | 체력 절반 이하일 때 공격 +35% |
| 골드 | 인사 발령 | 교체해도 턴을 쓰지 않음 |
| 골드 | 동네 친구 | 같은 첫째 타입 2마리 이상이면 그들 공격·방어 +20% |
| 골드 | 따개비 방패 | 대결마다 각자 처음 받는 공격 피해 0 |
| 골드 | 땅콩 떼기 | 특기 재사용 1턴 줄어듦 |
| 골드 | 이끼 간지럼 | 내 공격이 맞으면 20%로 상대 1턴 쉼 |
| 프리즘 | 큰 태풍 | 내 공격 피해 +30%, 받는 피해 +10% |
| 프리즘 | 다섯 번째 목소리 | 대결마다 다섯 번째 공격 위력 3배 |
| 프리즘 | 다시 출근 | 한 번, 쓰러진 갈매미가 체력 50%로 일어남 |

나오는 등급: 1번째 뒤 실버·실버·골드, 3번째 뒤 골드 3개, 5번째 뒤 골드·프리즘·프리즘.

## 난이도
- 상대 능력치 배율: 0.78 + 0.06 × (대결 번호 − 1) → 1번째 0.78, 7번째 1.14
- 상대는 특기가 준비되면 50% 확률로 사용(회복·방패는 체력이 낮을 때), 아니면 상성 좋은 기본기.
- 자동 봇 12판(상성만 따지고 교체 안 함): 클리어 2, 5번째까지 4, 4번째까지 2, 3번째까지 1, 2번째까지 3. 사람이 교체·증강체를 잘 쓰면 더 높을 것으로 예상(확인 필요).
