# 내 갈매미 · 보유 개체 상세 후속 패치

이 변경은 기준 `085f204b13429889c631994961433a0a1f0ffb25`의 긴급 스토리·편성·마을 수정과 분리한 후속 화면이다. APK106 작업의 임시 빌런 대응표를 중복 적용하는 패치가 아니다. APK·운영 서버 배포·버전코드 변경은 하지 않았다.

## 표시와 탐색

- 기존 내 정보 팝업의 큰 **내 갈매미** 버튼으로 연다. 도감은 종 정보 화면으로 유지한다.
- 서버 목록 순서대로 보유 개체를 한 마리씩 표시한다. 같은 `speciesId`라도 `ownedId`가 다르면 별개다. 실제 편성 순서를 바꾸지 않는다.
- 한 번의 좌우 스와이프는 한 개체만 이동한다. 큰 이전·다음 버튼과 접근성 이동도 제공한다. 수직 이동, 취소, 다중 터치는 개체를 넘기지 않는다.
- 기본 화면에는 큰 그림·이름/LV·최종 HP/MP·편성 위치와 큰 능력치/속성/기술 버튼이 있다. HP/MP는 현재 전투의 남은 값이 아닌 서버 최종 능력치다.
- 상세창에는 현재 개체 스냅샷을 고정한다. 능력치의 기본/성장/환생 보정, 자기 속성 내성·적합도, 현재 기술·MP·효과·다음 해금 정보를 묶는다. 기술은 사용자 확정대로 **유닛 레벨에 따라 해금**한다. 서버가 제공하는 기술별 `learnLevel`, 현재 사용 가능 여부와 `nextLearn.level`의 다음 해금 조건을 표시하며, 사용 횟수나 숙련도를 만들지 않는다. 별도 기술 강화 모델의 `DESIGN_NEEDED` 메타데이터는 이 레벨 해금 안내에 표시하지 않는다.
- 닫기와 시스템 Back은 개체 ID와 위치를 보존한다. 상세창 중에는 뒤 화면 이동을 막는다.

## 데이터와 경계

새 서버 읽기 API가 먼저 반영돼야 기능을 사용할 수 있다. 서버 소스/API 패치는 별도 검토 대상이며 운영 배포 승인은 포함하지 않는다.

| 읽기 | 용도 |
|---|---|
| `GET /my/api/native/roster60/owned` | 본인 보유 개체 목록·최종 HP/MP·레벨 |
| `POST /my/api/native/roster60/owned/read`, `{ownedId}` | 소유권을 확인한 단일 개체 상세. 읽기 전용이며 지급·편성·성장을 수행하지 않음 |

응답의 `flow=roster60-owned-v1`, 목록/상세의 동일 `catalogVersion`, 요청한 `ownedId`를 확인한 뒤 그림과 모든 상세 값을 함께 바인딩한다. 상세 정보가 준비되기 전에는 이전 개체의 그림·능력치를 지운다. 현재 개체와 양옆 개체의 상세만 보관하며 최대 3개다. 공개 이미지 캐시에는 개체 데이터가 들어가지 않는다.

계정·화면 epoch·읽기 generation이 바뀐 응답은 거절한다. 같은 종 사이를 이동해도 이미지 바인딩을 먼저 해제해 이전 비동기 콜백이 새 개체를 덮지 않게 한다. 목록 위치 저장도 서버·계정별로 분리한다. 화면 재진입·앱 복귀·기존 상태 갱신 뒤에는 최신 목록/상세를 다시 읽고, 상세창 중 갱신은 닫은 뒤 같은 개체로 1회 반영한다. 자동 폴링이나 새로운 지급 API는 없다.

- `git diff --check` 통과.
- `NativeOwnedGullsTest` 8개 작성: 개체 ID 분리·이웃 제한, 늦거나 잘못된 상세 응답, 모달/Back 보존, 한 번 스냅과 제스처 취소, 계정 교체, 성장/환생 이후 갱신, 실제 지연 이미지 콜백, 폰/태블릿 배치와 캡처.
- 기본 흐름의 Robolectric `NativeOwnedGullsTest` **8개 통과, 실패/오류/건너뜀 0**. 실제 이미지·폰트를 포함한 폰 915×412와 태블릿 1280×720 캡처를 직접 확인했다. 이후 확정된 레벨별 기술 해금 안내는 같은 시험의 모달 검증을 갱신했으며 부모의 클래스 재실행으로 확인한다.
- 검토에서 찾고 고친 것: 폰에서 기술 버튼 하단 1픽셀이 잘려, 세 큰 상세 버튼을 하단 공통 줄로 옮겼다. 닫기/시스템 Back은 명시적으로 같은 닫기 경로에 연결하고, 이전 대화상자의 늦은 닫기 알림이 새 창을 해제하지 않게 했다. 수직 드래그 후 원래 높이로 돌아오는 동작도 개체 이동으로 판정하지 않게 했다.
- APK·실기기 FPS·운영 서버 반영은 검증하지 않았다.
- 참고 이미지 원본 픽셀은 확인하지 못했으므로 정확한 스타일 재현을 주장하지 않는다. 기존 게임 자산과 남색 표면을 재사용한다.
