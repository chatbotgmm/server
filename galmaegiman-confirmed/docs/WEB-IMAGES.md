# 웹 대시보드(민트) 그림 목록 — ChatGPT 요청용

웹 대시보드(`/my`, v0.14.0)에서 **이미 자리를 만들어 둔** 그림만 적었어요. 파일을 `public/web/img/`에 같은 이름으로 넣으면 그림 자리가 바로 바뀌어요(코드 수정 없음).
없는 동안은 같은 크기의 점선 칸(파일 이름 표시)이 보여요.

## 받은 것(v0.14.2)
- `logo-mark.webp`(256², 투명), `draw-machine.webp`(1200×900, 투명), `char-<id>.webp` 최상위 33종(D1~D8·T1~T8·E1~E8·I1~I9, 1024², 불투명 파스텔 배경) → `public/web/img/`에 넣음.
- 아직 없는 것: 최상위가 아닌 갈매미의 `char-<id>.webp`(지금은 기존 카드 그림을 잘라 씀 — 말풍선 글자가 남아요).

## 공통 규칙
- 그림 안에 **글자·숫자·버튼·레벨·별·재화 표시를 넣지 않기.** 이름·레벨·수량·버튼은 모두 화면 코드(HTML)로 그려요.
- 그림체: 첨부 시안(민트 대시보드)처럼 파스텔·말랑한 3D 느낌, 짙은 갈색 외곽선 최소, 목재 장식은 넣지 않기.
- 파일 형식: WebP(투명이 필요하면 투명 WebP, 안 되면 투명 PNG로 보내 주면 변환함). 파일 이름은 아래 그대로(소문자, 갈매미 id만 대문자 그대로).
- 테두리·그림자 띠·액자 없이(카드 테두리는 화면이 그림).

|---|---|---|---|---|---|

### `char-<id>.webp` 자세히
- 지금은 기존 카드 그림(`public/images/<id>.png`)의 테두리·이름판을 화면에서 잘라 쓰고 있어요. 그런데 기존 그림에는 **말풍선 글자**가 그려져 있어서 잘라도 남아요. 그래서 새 그림이 필요해요.
- 새 그림이 있으면 그 갈매미만 새 그림으로 바뀌고, 없는 갈매미는 지금처럼 기존 그림을 잘라 써요(한 번에 다 안 해도 됨).
- 같은 갈매미의 생김새·색·상징물은 기존 카드 그림과 같게, **말풍선·글자·액자 없이**, 정면에서 약간 비스듬한 전신.
- 배경은 갈매미의 속성 색에 맞춘 단순한 파스텔 그라데이션(시안의 하늘색·분홍·초록·보라 카드처럼), 바닥 그림자 약하게.
- 우선순위: ① 최상위 33종(D1~D8, T1~T8, E1~E8, I1~I9: 레벨·특성이 보이는 갈매미) → ② 나머지 등급.
- id 목록과 각 갈매미 모습: 저장소 `data/units.json`(이름·등급), 기존 그림 `public/images/<id>.png`를 첨부로 쓰면 돼요.

## 그림을 넣은 뒤 확인할 것(Claude가 함)
- `node scripts/web-check.mjs <폴더>`: PC(1440×900)·모바일 세로(390×844)·가로(844×390)에서 홈·뽑기(실제 뽑기 1번)·조합·보관함·상세, 가로 넘침·버튼 화면 밖·누르는 곳 40px 이상·오류.
- 캡처를 눈으로: 그림이 칸에서 잘리지 않는지(특히 홈 「관리」 칸의 머리·발), 투명 가장자리 흰 테두리가 없는지, 작은 로고가 알아보이는지.
