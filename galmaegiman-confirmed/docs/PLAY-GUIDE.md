# 갈매미맨 이름으로 플레이하기

## 조합

1. 카카오톡에 **조합목록**을 입력합니다.
2. **안흔함 / 특별 / 희귀** 중 결과 등급을 선택합니다.
3. 만들고 싶은 갈매미의 이름을 누릅니다.
4. 재료 이름과 필요 수량, 사용할 수 있는 보유 수량을 확인합니다.
5. 준비가 됐으면 **조합하기**를 누릅니다. 재료가 사용되고 결과 1마리를 얻습니다.

예를 들어 **조합 브라자**를 직접 입력해도 같은 화면을 엽니다. 전체 이름인 **조합 브라자 갈매미맨**도 됩니다. 띄어쓰기는 달라도 되며, 여러 종류가 일치하는 이름은 후보 중에서 선택합니다.

브라자 갈매미맨에는 새우깡봉지 갈매미맨 1마리와 비닐봉지 갈매미맨 1마리가 필요합니다. 같은 재료가 2마리 필요한 조합은 한 마리로 대신할 수 없습니다. 보호하거나 표식을 전환한 개체는 일반 조합의 사용 가능 수량에서 빠집니다.

**조합가능**을 입력하고 등급을 고르면 지금 만들 수 있는 캐릭터만 보여줍니다. **조합목록 희귀**, **조합가능 특별**처럼 바로 입력해도 됩니다. **전체 보기**는 모든 등급을 함께 봅니다. 흔함은 조합식이 없는 기본 재료입니다. 목록은 한 화면에 최대 5종씩 표시하며 **다음 페이지**로 넘깁니다. 목록에 표시되는 번호는 페이지입니다. 캐릭터의 내부 번호를 외울 필요는 없습니다.

**조합식 브라자**는 확인 화면만 엽니다. **조합 준비**를 누르면 실제 진행 여부를 선택할 수 있습니다.

## 내 갈매미와 도감

- **내갈매미**: 같은 이름을 보유 수량으로 묶어 봅니다.
- **내갈매미 비닐봉지**: 비닐봉지 갈매미맨의 보유/사용 가능/보호/표식 전환 수량을 봅니다.
- **도감**: 전체 캐릭터와 수집 여부를 봅니다.
- **도감 비닐봉지**: 이름으로 바로 상세 내용을 봅니다.

목록은 이름과 수량만 표시합니다. 이름을 누르면 모든 등급의 이미지를 봅니다. 뽑기·조합·교환의 획득 결과에서는 **전 등급 첫 수집에만** 이미지가 자동으로 나옵니다. 수집 이력이 있으면 텍스트와 보상만 표시하며, **캐릭터 보기**로 이미지를 다시 열 수 있습니다. 조합 재료로 소비한 뒤 재획득해도 첫 수집으로 바뀌지 않습니다.

보유 목록의 이름을 누르면 **1마리 보호**, **1마리 보호 해제**를 선택할 수 있습니다. 같은 이름이 여러 마리면 조건에 맞는 가장 오래된 1마리에 적용합니다. 보호한 개체는 자동 조합 재료로 사용하지 않습니다.

## 재료 교환

**재료**, **교환**, **땅콩교환**을 입력하면 이름을 골라 교환할 수 있습니다.

| 입력 예 | 비용 | 결과 |
|---|---|---|
| 재료 도시락 | 획득권 1장 | 도시락 갈매미맨 1마리 |
| 교환 도시락 | 새우깡 30개 | 도시락 갈매미맨 1마리 |
| 땅콩교환 도시락 | 땅콩 1개 | 도시락 갈매미맨 1마리 |

미리보기 아래 **교환하기**를 눌러야 비용을 사용합니다. 일반 **뽑기**는 기존처럼 획득권 1장으로 즉시 랜덤 획득합니다.

## 확인과 취소

진행 또는 취소 항목을 직접 누르세요. 확인 정보를 따로 입력할 필요가 없습니다. **취소**는 해당 미완료 요청을 닫고 재료와 재화를 사용하지 않습니다.

진행 버튼은 10분간 유효합니다. 미리보기를 연 뒤 다른 조합/교환/잠금 등으로 보유 상태가 바뀌었다면 다시 미리보기를 열어 주세요. 같은 완료 버튼을 반복해 눌러도 추가 지급하지 않습니다.

이 업데이트를 설치해도 예전에 보낸 채팅 말풍선 자체는 바뀌지 않습니다. **조합목록**이나 **도감**을 새로 보내 새 화면을 확인하세요.

매일 한국 시간 09:00 / 12:00 / 18:00에 기본 10회씩 추가되고 미사용분은 누적됩니다. 첫 접속 지급은 3회입니다. **내정보**에서 남은 횟수와 다음 충전량을 확인하세요. 관리자가 충전량을 바꾸면 다음 충전부터 적용됩니다.
