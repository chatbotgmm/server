# 수비대 대결(모바일 턴제) 그림 요청문 — ChatGPT 이미지용

포켓몬 배틀처럼 **내 갈매미는 뒷모습**(화면 아래 왼쪽), **상대 갈매미는 앞모습**(화면 위 오른쪽)으로 나와요.
그래서 최상위 33종은 **앞모습 + 뒷모습**이 필요하고, 빌런은 상대로만 나오니 **앞모습만** 있으면 돼요.
기술 효과(번쩍임, 파도, 꽃잎 같은 입자)는 코드로 그려서 그림이 따로 필요 없어요.

## 필요한 그림 수
| 묶음 | 수 | 언제 |
|---|---|---|
| ① 최상위 33종 원형(진화 전) 앞+뒤 | 66장 (요청 33번) | **지금** |
| ② 빌런 17종 앞모습 + 보스 3종 큰 그림 | 20장 | 스토리 화면 만들 때 |
| ③ 진화 1·2·3단계 앞+뒤 | 33 × 3 × 2 = 198장 | 진화 기능 만들 때(진화 모습 설계 후) |

①부터 하고, **D1(태초의 갈매미맨)으로 먼저 1장 시험**해서 그림체를 확인한 뒤 나머지를 진행하는 걸 추천해요.

## 쓰는 방법
1. ChatGPT 새 대화에서 **그 유닛의 카드 그림**(`public/images/<ID>.png`)을 첨부해요.
2. 아래 [공통 요청문]을 붙이고, 맨 끝의 `<이름>`만 바꿔요.
3. 받은 그림(한 장에 앞·뒤 두 칸)을 이 대화에 **새 메시지로** 보내 주세요. 제가 칸을 잘라 크기와 발 위치를 맞추고 `public/battle/sprites/<ID>_s0_front.png`, `<ID>_s0_back.png`로 넣을게요.

## [공통 요청문] ① 최상위 원형 앞모습 + 뒷모습
```
첨부한 카드 속 갈매미 캐릭터를 그대로 그려 줘. 그림체·색·비율·외곽선·장식을 하나도 바꾸지 마.
카드 테두리·이름판·글자·배경은 빼고, 캐릭터만 투명 배경 PNG로.
투명이 안 되면 완전 단색 자홍색(#FF00FF) 배경.

한 장에 가로로 두 칸:
- 왼쪽 칸: 앞모습. 보는 사람 쪽을 보면서 몸을 살짝 왼쪽으로 튼 자세(대결 상대 쪽 모습). 당당한 대기 자세.
- 오른쪽 칸: 뒷모습. 뒤에서 본 모습으로, 몸을 살짝 오른쪽 위로 튼 자세(내가 지휘하는 쪽 모습).
  등의 날개·볏·장식이 뒤에서 보면 어떻게 생겼는지 자연스럽게.
두 칸의 캐릭터 크기·높이를 똑같이, 발바닥이 같은 높이에. 전신이 잘리지 않게.
두 칸은 같은 캐릭터여야 해(볏 모양, 날개 금, 색, 소품이 똑같이).
Avoid: card frame, name plate, text, letters, watermark, background scenery, extra characters, eagle, hawk, hooked beak

캐릭터: <이름>
```

## ③ 진화 1·2·3단계 (나중에)
진화하면 그림이 바뀌어요(증강체에 따라 달라지지는 않음).
유닛마다 어떤 모습으로 진화할지는 그림을 받기 전에 따로 정해요. 기본 방향은 이래요.
- **1단계**: 원형과 같은 모습에 직급 표식(작은 배지·견장) 하나와 속성 빛이 은은하게 추가
- **2단계**: 장식이 커지고(갑옷·망토·소품 강화) 몸 주위에 속성 기운이 흐름
- **3단계**: 몸집이 조금 커진 느낌, 등 뒤에 속성 문양 후광, 가장 화려한 마무리

## 확인할 것
- 테두리·이름판·글자가 들어가면: "테두리와 글자를 빼고 투명 배경으로 다시"
- 앞·뒤 생김새가 다르면: "왼쪽 칸과 똑같은 캐릭터로 오른쪽 칸을 다시"
- 좌우가 반대로 나와도 괜찮아요. 제가 뒤집어서 넣을 수 있어요.
