# 네이티브 전체 구성 복원 목록

기준은 기존 게임의 public/duel/duel.js와 public/my/my.js의 GAMEUI 화면이다.
사이트용 대시보드와 섞지 않는다. 캐릭터 원본은 변경하지 않는다.
2.0.2-native는 첫 화면·로그인·로비·대화·팝업만 복원한 상태다.
Android 화면 실행 통과는 기존 화면과 구성까지 같다는 검증이 아니었다.

| 공통 머리글 | 이미지 돌아가기, 재화 아이콘, 작은 제목 | 문자 뒤로 버튼, 재화 누락 |

빌드·배포는 요청사항을 모아 변경 내용을 제시한 뒤 사용자 승인 후 진행한다.
새 수정의 화면 검증은 아직 하지 않았으며, 이전 테스트 통과를 새 UI 검증으로 인용하지 않는다.

## 2.0.3-native 수정 묶음

사용자가 2026-10-13에 "그냥 바로 빌드하고 배포해"라고 승인했다.
기존 GAMEUI의 메뉴 구성을 네이티브 컨트롤러로 나누어 옮겼다.

- 화면별 원본 배경·돌아가기 그림·재화 아이콘과 Black Han Sans/Gowun Dodum 글꼴.
- 캠페인/PvP 모드 판, 스토리 수비대의 체력·경험치와 가로 챕터/전투 선택.
- 수비대 탭, 편성 단상·후보·고정 저장 영역, 개체의 성장·기술 4칸·승진 선택.
- 내 갈매미 검색·등급 필터·상세·길게 누르기와 보호/탐험/편성 작업.
- 뽑기 수량·확률·알 열기·결과 카드·지난 결과, 조합식 검색/가능 필터/수량,
  재료 선택 6칸·빼기·비우기와 조합 결과 연출.
- 상점 진열·가격 재화·수량/합계/한도, 탐험 이미지 편성·이전 편성·저장·진행률.
- 출석 7칸·미션 진행률, 순위표·연습 팀 선택, 설정·계정 연결/해제·안내.
- 기술 미리보기에 실제 전투 엔진의 역상성·무속성·약점 보호를 반영.
- 카카오 첫 연결은 기존 계정 코드 확인 후 연결하고, 로그인 상태에서 연결하면
  현재 계정을 유지한다. PKCE 교환 코드와 연결 시작 표는 한 번만 사용한다.
- 스토리 편성 저장이 PvP 편성을 덮어쓰지 않게 분리했다.

새 소스의 서버 테스트 133개와 TypeScript 검사가 통과했다.
원본 이미지 파일은 변경하지 않았다. 네이티브 실행·캡처 검토 결과는 아래에 기록한다.


## 실행·화면 검토 결과

- 서버: 격리 DB 테스트 133개, TypeScript 검사와 서버 빌드 통과.
- Android: 915×412 전체 화면·전투 1건, 챕터 그림 1건,
  1280×720 전체 화면·전투/챕터 그림 2건,
  Z플립 비율 1006×411 대화·전투 1건 통과.
- 마지막 로비 보완 후 915×412와 1280×720 로비·버튼·팝업 검사를 각각 재실행해 통과.
- 각 크기의 첫 화면·로그인·로비·19개 메뉴·대화·전투를 캡처하고 직접 확인했다.
  이미지 없는 챕터 카드, 배경에 묻히는 아이템 안내와 전투 메뉴 제목을 찾아 수정했다.
  물리/마법 능력치를 분리해 표시하고 전투 기술 이름의 크기·두께를 올렸다.
- 이미지 완성 콜백이 실행되기 전 LRU에서 그림이 빠져도 화면에 적용하도록 보완했다.
  로비는 표시 중인 원본 레이어를 유지해 배경 일부가 사라지는 현상도 막았다.
- 실제 글꼴의 웹 원본 검토에서도 915×412·1280×720 화면 넘침, 대화 내용 넘침,
  전투 그림/상태창 겹침과 JavaScript 오류가 없음을 확인했다.

Android 검토는 소프트웨어 에뮬레이터 기준이다. 실제 Galaxy 기기 검증은 포함하지 않는다.
에뮬레이터의 큰 배경 bilinear 재그리기 지연을 피하기 위해 캡처 순간에만 ImageView 필터를
끄고 즉시 복원했다. 제품 이미지·APK 렌더링 설정은 변경하지 않는다.
