# Android 개선판 2.0.4-native (67)

기준: PR #2의 `390bf88`, 2.0.3-native (66). 캐릭터 원본 33종 앞·뒤 이미지는 유지한다.

## 찾아 고친 원인

- 네이티브 이식 때 공통 버튼을 단색 베이지로 대체해 웹의 나무 테두리·파스텔·눌림 상태가 사라졌다. 공통 그라데이션·테두리·바닥 그림자를 적용했다. Canvas 테두리의 반투명 Paint가 다음 아이콘에 남던 문제도 초기화했다.
- 뽑기권을 받은 뒤 이전 native/state를 다시 그려 상단 수량이 그대로였다. 서버 상태를 다시 받고 상단을 갱신한 뒤 지급 창을 연다. 데이터 응답에 HTTP 캐시를 쓰지 않는다.
- 증강체 선택을 작은 우측 버튼으로 대체했었다. 상성 비교·첫 전투 안내·3장 카드·칸별 재추첨·선택 확인을 가진 전체 화면을 복원했다.
- 전투 응답 즉시 화면을 교체해 연출이 없었다. 새 기록만 순차 재생하고 돌진·속성 투사체·피격·피해 숫자·회복·교체·퇴장을 표시한다. 결과 창은 재생 후 열린다.
- 설정을 별도 페이지 및 첫 화면의 체크박스로 나눴었다. 웹처럼 소리/계정 두 칸 모달로 통일하고 전체 소리, 배경음악·효과음 슬라이더와 우측 음소거, 쿠폰, 튜토리얼, 계정 관리·탈퇴 진입점을 제공한다.
- 휴대폰 편성에서 큰 단상 때문에 이름·출전 순서가 아래로 밀렸다. 휴대폰 카드 크기를 줄이고 선봉부터 순서대로 배열했다. 선택 수·저장은 하단에 유지한다.
- 웹 큰 글자에서 상태 칸이 상대 그림에 닿고 스토리의 기술 배우기 글자가 세로로 쪼개졌다. 상태 칸 높이 제한과 스토리 카드 열 배치를 수정했다.

## 이번 요청 반영

1. 증강체 선택 30초: 서버 마감 시각을 사용하며 재추첨·재접속으로 연장하지 않는다. 만료 시 현재 제안 중 무작위 1개를 한 번 확정한다. 강제 교체가 함께 필요하면 생존 멤버도 선택한다. 앱은 남은 시간과 최종 서버 결과를 표시한다.
2. 중복된 긴 버튼 문구를 `스토리`, `모험 준비 중`, `선택 확정`, `출전 확정`, `재추첨 완료` 등으로 정리했다. 증강체 이름은 카드에서 확인한다.
3. 주요 실행·보조 조작·로비 파스텔·모드 종이판·팝업 조작부를 공통 게임 재질과 실제 글꼴로 맞췄다.
4. 합동기는 일반 기술과 분리한 넓은 금색 카드, 전용 문장, 빛이 합쳐지는 연출과 기술명으로 구분한다. 팀당 사용 횟수 등 판정은 공통 엔진을 유지한다.
5. 전투 편성의 선봉/후속 순서, 속성 표시, 선택 카드, 선택 수, 저장 조작을 개선했다.
6. 상성표는 공격→방어 방향, 유리 ×1.5/불리 ×0.67, 우리 팀 속성을 구분하는 카드로 표시한다.
7. 탐험 귀환·뽑기권 알림을 기기의 AlarmManager로 예약한다. 재부팅·앱 업데이트 후 복원하고 같은 보상을 중복 알리지 않는다. 알림에서 탐험/뽑기로 이동한다. 권한 거절·로그아웃·비활성 시 예약을 정리한다. FCM 원격 푸시는 사용하지 않으며, Android 절전 정책에 따라 전달 시각이 늦어질 수 있다.
8. 전투 보상창에서 서버에 저장된 갈매미별 경험치·레벨업·체력 회복·랭크를 구분한다. 연습에는 보상이 저장되지 않는다고 표시한다.

첫 화면·로그인 배경·로비·전투의 중앙 공간에서 드래그하면 배경/발판/캐릭터가 서로 다른 비율로 움직이고 버튼·상태창·기록은 고정된다. 손을 떼면 원위치로 돌아간다. 배경음악·효과음의 음소거 상태와 볼륨을 별도로 저장해 해제 시 각 볼륨을 복원한다.

## 검증

- 격리 DB 통합 테스트 135개 통과. 선택 제한 시간·재추첨 마감 유지·중복 확정 방지, 성장 저장, 기존/개선판 PKCE 계정 연결을 포함한다. 실제 사용자 DB를 테스트에 사용하지 않는다.
- 실제 게임 글꼴로 웹 원본 915×412·1280×720 캡처. 넘침·버튼 잘림·상대 그림의 불투명 영역/상태창 겹침 검사 통과.
- Android 35 native Skia/Robolectric로 실제 앱 View·원본 글꼴·그림을 렌더해 휴대폰·태블릿 주요 메뉴, 로그인, 대화, 증강체, 전투·합동기, 보상, 설정, 뽑기권 수량을 캡처한다. 터치 높이 48dp·스크롤 불가능한 버튼 잘림·전투 상태 겹침을 검사한다.
- 패럴랙스 중 조작 위치 고정과 원위치 복귀, 음소거/재시작/독립 볼륨 복원, 알림 재부팅 복원·중복 방지·해제, 뽑기권 수량 갱신 시점, 전투 연출 종료 시 상태 교체를 실행 검증한다.
- `BattleLogCursor`의 6개 JUnit 사례는 잘린 50줄 기록·중복 응답·반복 기록을 다룬다.

원자료: `/workspace/review-artifacts/pr-2/native-material/web-final/`, `native/`. Skia 캡처는 실제 기기나 설치된 APK의 화면 캡처가 아니다. 실제 Galaxy Z플립·갤럭시탭의 터치·음향·절전 상태 검증은 포함하지 않는다. 기술별 모든 연출이 웹과 완전히 같다는 검증도 하지 않았다.

## 별도 설치와 서명

기존 66 APK의 서명키는 Git 이력·Actions/Releases 및 지정 EC2 전체 디스크·빌드/백업 폴더에서 찾지 못했다. 사용자 승인에 따라 `org.dpdns.gmm.native.revised`의 「갈매미맨 수비대 개선판」으로 함께 설치한다. 기존 앱을 삭제하지 않으며 같은 서버 계정으로 진행한다. 개선판 카카오 반환 주소는 `gmmrevised://auth`, 기존 `gmmnative://auth`·`gmmapp://auth`는 유지한다.

새 배포키는 Git 밖에서 생성하고 EC2 공개 인증서로 암호화해 `/var/lib/gmm-signing/native-revised/`에 전송·보관했다(폴더 700, 키·암호 600). 로컬/원격 키 파일 SHA-256 일치를 확인했다. 다음 업데이트는 이 키와 같은 패키지를 사용해야 한다. 키·암호를 SSM 명령/결과 또는 Git에 평문으로 넣지 않는다.

공개 스크립트는 APK의 실제 패키지·버전·서명을 확인하고, 같은 패키지의 서명이 바뀌면 공개 전에 거절한다. 이번 명시적 패키지 전환에만 `--new-package`를 사용하고 이전 66 APK도 apk 브랜치에 보존한다. 공개 주소는 `/app/native`이다.
