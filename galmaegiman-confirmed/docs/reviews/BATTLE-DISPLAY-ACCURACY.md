# 전투 표시 정확도 개선 — Android 2.0.6-native (69)

기준: 개선판 68. 같은 캐릭터가 양쪽에 있을 때 이름만으로 공격자·피격 대상을 찾으면 상대의 공격·피해도 내 편에 붙을 수 있었다. 한국어 로그를 연출 판정에서 제거하고 서버의 구조화된 전투 이벤트를 사용한다.

## 변경

- 공통 엔진에서 진영(`side`), 편성 칸(`slot`), 기록 키(`rec.uid`), 종류 ID를 가진 공격자·대상을 기록한다. 기술 사용, 타격별 피해, 반사·가시·역습·화상, 흡혈·회복·재생·아이템·응급처치, 교체·전투불가·부활·상태 변경을 실제 발생 순서대로 내보낸다.
- 피해와 회복에는 실제 HP 전후 값과 변화량을 넣는다. 과잉 피해·회복 상한·버티기·방어로 계산량과 실제 변화가 다를 때도 표시 HP는 서버와 일치한다. 대기 멤버에게 적용되는 회복은 출전 캐릭터에 붙이지 않는다.
- native API는 `displayEventVersion: 1`, `displayEventSeq`, `displayEvents`, `displayLogStart`를 추가한다. 최근 200개를 보관하고 이벤트 번호는 계속 증가한다. 기존 한국어 `log`, 기존 API 필드는 유지한다.
- Android는 네 가지 식별자를 모두 확인하고 이벤트 번호로 중복을 제거한다. 누락·역순·식별자·HP 순서가 맞지 않거나 구버전 응답이면 추측 연출 없이 최종 스냅샷으로 동기화한다. 재접속할 때 과거 이벤트를 다시 재생하지 않는다.
- 재생 중 최신 확정 응답보다 오래된 응답을 거절한다. 화면 이탈 시 최신 확정 상태를 보존하고, 전투 화면을 떠난 뒤 늦은 응답이 강제로 전투로 복귀시키지 않도록 화면 세대·세션·액티비티 종료를 검사한다.
- 실패 검증 및 아이템 저장 전 임시 전투를 만들 때 이벤트 배열도 깊게 복사한다. 저장 실패의 임시 HP·연출 기록이 원래 전투에 남지 않는다.

전투 수치, 난수 소비, 승패·성장·재화 판정과 캐릭터 원본은 유지했다. 엔진의 표시 이벤트는 관측용이며 웹의 기존 한국어 로그 기반 흐름에 영향을 주지 않는다.

## 검증

- 격리 DB 포함 서버 테스트 146개 통과. native API의 동일 이름 전투·편성 칸·실제 HP·교체 상태, 중복/잘못된 요청 및 아이템 저장 실패 후 HP·이벤트 원복을 포함한다.
- 신규 엔진 회귀 9개: 동일 name/id/uid 양측, 다단·가시·반사·역습, 피해·회복 상한, 방어·버티기, 흡혈·대기 멤버 회복·부활·교체 인계, 상태 독립 복사, 최근 200개 제한을 검사한다.
- 이벤트만 적용한 표시 상태가 고정 시드 4개의 모든 단계에서 서버의 HP·출전 칸·상태·속성과 일치한다. 변경 전 고정 시드 7개의 로그·난수·전체 전투 상태 SHA-256 결과도 그대로다.
- Android 재생 Robolectric 14개와 이벤트 순서 JUnit 6개 통과. 동일 이름 공격·피격, 반사·다단·회복·부활·교체·대기 멤버, 위조된 로그 숫자 무시, 구버전·누락·중복·재접속·늦은 응답·화면 이탈을 검사한다.
- Android 35 native Skia 통합·화면 검토 8개 통과. 실제 격리 native API에서 양측 D1/D1 전투를 실행하고 내 편/상대 피격 이벤트의 대상 진영과 표시 HP를 확인하여 캡처했다. 캡처 중 자원 로딩으로 다음 이벤트에 넘어가지 않도록 프레임을 고정해 해당 효과·이벤트 번호가 유지되는지도 검사한다.
- 실제 글꼴의 웹 원본과 Android View를 휴대폰 915×412, 태블릿 1280×720에서 재캡처했다. 화면 넘침·스크롤할 수 없는 버튼 잘림·전투 상태창/상대 그림 불투명 영역 겹침 0을 확인했다. Z플립 모의 안전 영역 및 기존 패럴랙스·음소거·알림 테스트도 통과한다.

원자료: `/workspace/review-artifacts/pr-2/battle-accuracy69/`. 대표 화면: `native/phone-mirror-hit-own.png`, `native/phone-mirror-hit-foe.png`, `native/tablet-combo-animation.png`. 테스트 로그와 XML은 `test-reports/`에 있다. Android native Skia 캡처이며 실제 Galaxy 기기에서 설치한 APK의 프레임 캡처는 아니다. 웹 UI 95% 일치 판정이나 모든 기술의 연출 품질 개선을 이번 변경에 포함하지 않는다.
