# 모험 XP 적용 및 드롭·모집 경제 검토 — 2026-10-25

## 확정되어 코드에 적용한 XP

각 모험 전투의 기본 승리 XP를 B라고 할 때, 그 전투에서 한 번이라도 출전한 개체는 B, 편성됐지만 한 번도 출전하지 않은 예비는 floor(B / 2)를 받는다. 개체 수로 나누지 않는다. 시작 출전과 자발/강제 교체 모두 서버 participation에 ownedId·종류·턴을 기록한다. 같은 개체의 반복 출전은 추가 배율이 없다. 다음 전투에서 참여 이력은 새로 시작한다.

예: B=11, 4마리 중 3마리 출전 → 11/11/11/5. B=1의 미참전 예비는 0. 기절은 참여 이력을 지우지 않는다. 전멸은 전체 모험 보상 소실로 처리한다. 배분은 승리에만 발생하며 도주·무승부에서는 기존 누적만 유지한다.

XP는 각 ownedId별 pendingRewards.xp에 임시 적립한다. 정상 귀환 트랜잭션만 영구 totalXp를 변경한다. 전멸은 참가·예비 모두 임시 XP를 잃으며 원래 XP를 차감하지 않는다. 전투/귀환 receipt와 상태 전이로 중복 지급을 막는다. 새 API 입력으로 참여 ID를 받지 않는다. 이전 진행 중 전투는 최초 ownedId 및 서버에 저장된 switch/forced-switch 이벤트로 참여 이력을 복원한다.

정산 응답의 xpByOwnedId가 이번 전투의 실제 개체별 배분이다. 기존 xpEscrowed 필드는 호환을 위해 기본 전투 XP B를 유지하며 편성 전체 합계를 뜻하지 않는다. xpPolicy는 adventure-participation-100-reserve-50-v1이다.

## 승인된 드롭 종류와 아직 구현하지 않은 값

승인 종류는 새우깡(snack), HP 회복 아이템, MP 회복 아이템, 지원서(현재 credits 재화)이다. 땅콩은 새 모험 드롭 대상에서 제외한다. 여기서는 드롭 생성/확률/수량을 활성화하지 않았다. 기존 보상 저장 형식의 peanut 지원을 제거한 마이그레이션도 하지 않았다.

현재 HP 아이템은 potion(35%), big(75%), feather(부활50%)이며 clear는 상태이상 해제다. 상태이상 기술은 보류이며 clear는 새 전투에서 유효 효과가 없어 거부된다. HP 회복 아이템 승인이 부활 아이템의 모험 드롭까지 승인한 것은 아니다. 기존 itemDefinitions에 MP 회복 아이템은 없다.

미승인 검토 제안: MP 회복약은 최대 MP의 35%를 회복하는 소형 약부터 비교한다. 집중25%보다 회복량이 높지만 재고를 소모하는 선택지로 검토할 수 있다. 정수 내림·최대 MP 제한·행동 소비를 제안하며 최소1 보장은 별도 결정이다. 예: maxMP13이면 floor(4.55)=4. 현재 코드나 테스트 기본값에 35%를 넣지 않았다. 아이템 ID·가격·대상·배틀 밖 사용·드롭량·확률은 미정이다.

## 지원서 소단위 수급과 모집 7일 예산 — 제안만

고정 유지: 시간당 받기30(누적 없음), 신규 가입200, 기존 일회 쿠폰500. 이 수치는 변경하지 않는다. 첫 주 기존 출석 합계118도 비교 계산에만 사용하며 출석 개편 승인을 의미하지 않는다. 기존 미션·초대·도감·튜토리얼·탐험 등 추가 수급은 아래 계산에서 제외했다. 가입과 쿠폰은 매주 반복 지급이 아니다.

| 7일 수동 수령 가정 | 시간당 수령 합계 | 가입200+쿠폰500 포함 | 기존 출석118까지 포함 |
| --- | ---: | ---: | ---: |

| 하루4회 | 840 | 1,540 | 1,658 |
| 하루8회 | 1,680 | 2,380 | 2,498 |

모험 지원서는 큰 묶음보다 성공 드롭1장 같은 소단위부터 시뮬레이션하는 안을 추천한다. 1장은 승인 수량이 아니며 실제 적용하지 않았다. 하루 V승, 드롭 확률 p, 성공당 q장이면 7일 추가 기대 수급은 7×V×p×q. 예시 검토 범위 V=10~30, p=10~20%, q=1에서는 7~42장이다. 정상 귀환하지 못하면 지급되지 않으므로 실제 수급은 이 기대치보다 적다. 전투 횟수·귀환율 데이터로 재검토한다.

모집 원가 C, 한 차례 재추첨 비용 R, 재추첨 사용률 r일 때 확정 개체당 기대 비용은 C+rR이다. 7일 예산 T로 가능한 확정 수는 대략 floor(T/(C+rR))이다. 기존 가격2/3/5를 새 모집의 확정 가격으로 승계하지 않는다. 현재 새 모집 정책 파일 data/roster60-recruit-policy.json은 없으며, 가격·등급 확률·반값 소수점·천장 정책이 없으면 세션 모집은 활성화되지 않는다.

최소 다음 결정: (1) 난이도별 기본 XP/드롭량·확률, (2) MP 약35%안 및 가격/대상, (3) 지원서 일주일 목표 추가 수급, (4) 목표 모집 횟수에 맞춘 C·R·등급 확률과 천장. 기존30/h·가입200·쿠폰500을 줄이는 방식은 제안하지 않는다.
