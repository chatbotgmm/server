# UI 모션 검토 자료 격리

프레임별 모서리·장식 형상이 달라지는 생성 힌트 시트는 이 검토 디렉터리에만 보관한다. Android `src/main/assets`에 복사하거나 runtime.json에서 참조하지 않는다.

현재 GitHub로 전달된 입력은 버튼 상태 18개, 아이콘 6개, runtime.json, README다. 힌트 시트 원본은 전달되지 않았으므로 이 폴더에 이미지 파일을 만들거나 있다고 가정하지 않았다. 추후 실제 시트를 전달받으면 원본 그대로 이곳에서 검토한다.

현재 버튼 상태 이미지 12개는 기존 업로드의 visual_reference_only 분류를 유지했다. UiMotionAssets는 이들을 선택하지 않고 normal 6개만 로드한다. 24개 원본 PNG를 모두 회색 배경 위에 합성한 임시 연락 시트로 검토했으며 원본 PNG는 수정하지 않았다.
