# Android 개선판 2.0.5-native (68) 검토

기준은 기존 웹 GAMEUI(`/duel`, `/my?g=1`)와 개선판 67이다. Android 네이티브 View를 유지하며 캐릭터 33종 앞·뒤 그림을 바꾸지 않았다.

## 첨부 화면의 가장자리 문제

`1000003886.jpg`에서 왼쪽 약 45px가 흰 띠로 남는다. 컷아웃 여백을 루트에 적용하면서 배경도 같은 여백 안으로 축소한 것이 원인이다. 배경과 Canvas 장면은 전체 화면에 그리고 버튼·글자·상태창·대화 조작부에는 안전 영역을 따로 적용한다. 현재 보이는 시스템 바, 컷아웃, 둥근 모서리, 키보드 여백의 최대값을 사용한다. 숨겨진 시스템 바 크기는 불필요하게 예약하지 않는다.

첫 화면·로그인 배경·로비·전투·대화·일반 메뉴·증강체에 적용했다. 1006×411의 검토 화면에 좌36/상10/우8/하10px의 여백을 넣고 흰 띠가 사라졌는지, 버튼이 안전 영역에 남는지 자동 검사했다. 이는 실제 Z플립 캡처가 아닌 Android 35 native Skia 검토이며 실제 기기 컷아웃 수치는 시스템이 제공한다.

## 캡처에서 찾아 보완한 차이

- 일반 메뉴의 종이 머리글, 작은 재화 칸, 연한 크림 카드와 짧은 그림자, 배경 흐림·채도·밝기를 웹 기준으로 복원했다.
- 뽑기를 가로 3장으로 복원했다. 지급 안내·받기·수량·실행 버튼·확률·고급 보장 횟수를 함께 표시한다. 입력칸에 갈색 tint가 남던 문제를 제거했다.
- 수비대 목록은 휴대폰 7열/큰 화면 9열, 그림 위 보유 수, 이름·등급·속성을 표시한다. 분류 탭은 가운데, 필터는 왼쪽에 배치한다.
- 전투 편성은 2번·선봉·3번 순서의 단상, 가로 후보 목록, 좌우 종이판, 저장된/바뀐 편성 표시를 복원했다. 변경이 없으면 저장 버튼을 잠근다.
- 스토리에서 수비대 세 마리가 작은 가로 화면에 함께 보이도록 정리하고 경험치 표시를 유지했다. 챕터는 전체 높이 배경 그림·하단 설명과 진입 버튼으로 복원했다.
- 설정은 무늬 종이 위 좌측 소리/우측 계정의 두 칸, 우측 닫기, 가로 슬라이더·볼륨·스피커 버튼, 쿠폰·튜토리얼·접히는 계정 삭제를 표시한다. 두 음소거와 기존 볼륨 복원 동작은 유지한다. 알림 설정은 오른쪽 칸을 스크롤해 접근한다.
- 첫 화면의 서로 다른 반복 주기와 로비의 3.6초 숨쉬기 모션, 대사 28ms 타이핑을 복원했다. 타이핑 중 첫 터치는 줄을 완성하고 다음 터치는 다음 대사로 이동한다. 화면이 사라지면 반복 모션·타이핑을 정리한다. 패럴랙스 중 UI 고정도 유지한다.
- 전투 배경에 서버의 실제 스테이지 장면을 사용한다. 기술 카드는 크림 종이·속성 색 띠, 합동기는 금색으로 구분한다. 캡처에서 발견한 기술 카드의 그림자 alpha 잔류로 인한 투명 바탕도 수정했다.

67의 증강체 30초·무작위 확정, 기술 판정, 합동기 연출, 편성, 상성표, 보상·성장, 알림, 탐험 편성 보존, 뽑기권 상태 갱신은 유지한다.

## 검증 자료와 한계

원자료는 `/workspace/review-artifacts/pr-2/native-restoration68/`에 저장했다.

- 서버 build와 격리 DB 테스트 135개 통과.
- 실제 웹 글꼴로 915×412·1280×720 원본 화면 재캡처: 화면 넘침 없음, 전투 버튼 잘림 없음, 상태 칸/상대 불투명 그림 겹침 0px, pageerror 없음.
- Android native Skia: 주요 메뉴 20종과 로그인·대화·설정·증강체·전투·합동기·보상 및 Z플립 비율 캡처. 버튼 터치 높이 48dp, 스크롤할 수 없는 버튼 잘림, 전투 상태 겹침을 검사했다.
- Robolectric 7개 통합 사례와 안전 영역 JUnit 3개 통과. 신규 사례는 컷아웃/모서리 모의 여백, 배경 끝 채움, 반복 모션 시작/정리, 대사 타이핑·첫 터치 완성·다음 줄 이동을 실행한다. 패럴랙스·음소거/볼륨 복원·알림·뽑기권·전투 재생도 다시 검사했다.
- 기술 바탕 alpha 수정 후 전투/대사/첫 화면 캡처 사례를 다시 통과했다. 마지막 전체 검토 결과와 부분 재검사 결과를 각각 보존했다.

**95% 일치 달성으로 판정하지 않는다.** 같은 계정·장면·게임 상태와 로비 방·애니메이션 시점을 고정한 실기기 비교가 필요하다. 웹 DOM/CSS와 Android View의 글꼴 폭·터치 높이가 다르고, 출석/튜토리얼의 표시 방식, 첫 화면 계정 표시, 로비 알림 표시, 일부 기술별 세부 효과가 여전히 다르다. 48dp 조작 영역과 사용자 요청으로 추가한 경험치·알림·보상 정보도 픽셀 일치와 분리해서 평가해야 한다. 무작위 장면·다른 실제 게임 상태를 포함한 전체 스크린샷 유사도를 임의로 계산해 95%라고 보고하지 않는다.
