# 경험치 분배: 마무리 전액·나머지 절반 (2026-11-03)

사용자 결정(2026-11-03): 이긴 전투에서 **마무리한 유닛은 보상 전액, 편성된 나머지 유닛은 절반씩** 받는다. 진 전투는 모두 0이다. 스토리·일반전(사람·AI)·모험에 적용한다.

## 규칙

| | 이긴 전투 | 진 전투·항복·무승부·도주 |
|---|---|---|
| 마무리 유닛(이긴 순간 나와 있던 내 유닛) | 보상 W 전액 | 0 |
| 편성된 나머지 유닛(출전하지 않은 예비 포함) | 각 floor(W/2) | 0 |

- 나누는 계산은 `src/progression/finisher-split.ts` 한 곳에서 한다. 마무리 유닛이 편성에 없으면 지급하지 않고 거절한다.
- 각 개체의 60/99레벨 상한까지만 적용하고 넘친 양은 버린다(기존과 같음).
- 클라이언트가 보낸 값은 쓰지 않는다. 마무리 유닛은 서버 전투 상태의 현재 출전 개체(스토리·모험 `fighters[0]`, 실시간 대전 `parties[편][0]`)다.

## 최소 보상: 적정 레벨 승리 1.5번에 마무리 유닛 1레벨 (2026-11-03 추가 결정)

- W가 「마무리 유닛의 다음 레벨 필요 XP × 2/3(올림)」보다 작으면 그 값까지 올린다. 이미 크면 그대로 둔다(최소값).
- 기준 레벨은 마무리 유닛의 레벨이고, 적이 더 낮으면 적 레벨로 낮춘다(`owned-level-capped-by-enemy`). 낮은 적을 이겨서 빨리 키울 수 없다.
- 정책 파일 `unit-xp-pacing-policy.json`: `unit-xp-finisher-1_5-wins-20261103-v1`, `winsPerLevel: 1.5`, `distribution: finisher-full-rest-half`. 예전 판(`unit-xp-two-wins-20261030-v1`, 2승·균등)으로 고정된 전투는 예전대로 정산한다.
- 예(u01): Lv10 필요 632 → 최소 422(일반전 원천 600이 더 커서 600 유지), Lv40 필요 5,060 → 최소 3,374(원천 2,400을 3,374로 올림). 스토리 보상은 대부분 최소보다 커서 그대로다.
- 이 파일이 있으면 예전 단일 연습전(최초 개체 1마리 지급)에도 같은 최소값이 적용된다(분배 방식은 그대로).

## 모드별 보상 W와 정책 판

| 모드 | W | 새 판 | 예전 판(이미 고정된 전투는 이대로 정산) |
|---|---|---|---|
| 스토리(의뢰 전투, 모험형 의뢰 포함) | 정책 파일 `rewards[전투].winXp` | `story-unit-xp-campaign-test-v2`, `distribution: finisher-full-rest-half` | v1: 실제 출전 개체 균등 분배 |
| 일반전(사람·AI) | 실제 출전 개체 중 최고 시작 레벨에 가까운 duel winXp(기존과 같음) | `normal-xp-v3` (`normal-finisher-xp-test-v3`) | v2: 출전 개체 균등, 승리 100%·패배 50% |
| 독립 모험 | 조우의 winXp(기존과 같음) | 전투 스냅샷 `xpRecipient: adventure-finisher-100-rest-50-v1` | 출전 100%·예비 50% |

- 정책은 대기열 입장·의뢰 수락·전투 생성 때 고정한다. 배포 전에 이미 고정된 대기·방·전투는 예전 판으로 정산하고, 이미 확정된 원장·영수증은 다시 지급하지 않는다.
- 랭크전(0)과 예전 단일 연습전의 분배 방식(최초 개체 1마리에 winXp/lossXp)은 바꾸지 않았다.
