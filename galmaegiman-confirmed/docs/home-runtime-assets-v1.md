# 갈매미맨 홈 메뉴 런타임 이미지 소스 v1

승인된 홈 닫힘/펼침 시안을 바탕으로 제작한 **독립 런타임 이미지**입니다. 시안 전체를 화면 배경으로 붙이지 않습니다.

## 포함 및 구현 원칙
- `app/android/app/src/main/assets/native/home-menu-v1/`: 버튼/패널 4종, 재화 메달 3종, 메뉴 아이콘 7종.
- 버튼 이름, 재화 수량, 닉네임, 알림 점, 메뉴 열기/닫기 기호는 코드로 그립니다.
- 기존 항구 배경과 기존 캐릭터/애니메이션은 변경하지 않습니다.
- 플레이의 나침반은 `icon-explore.png`를 재사용할 수 있습니다.
- 런타임 폴더의 `surface-manifest.json`: 실제 픽셀 크기, 9-slice 원본 inset, 권장 출력 corner 크기.
- 표면 이미지는 전체를 단순 확대·축소하지 않고 9-slice로 렌더링합니다. 중심 및 직선 변만 늘리고 네 모서리는 고정합니다.
- 메뉴/타일은 원본 생성 비율을 유지해 저장했습니다. 고정 규격 강제 리사이즈로 테두리를 찌그러뜨리지 않았습니다.
- PNG는 straight-alpha RGBA. 캔버스/엔진 로더에서 통상적인 alpha blending을 사용합니다.

## QA
`nine-slice-qa.png`는 표면마다 3개 출력 크기를 보여줍니다. 아이콘은 각각 독립 RGBA이며 텍스트·숫자·빨간 알림 배지가 없습니다. 이는 에셋 검수이지 Android 실제 기기 렌더링 검증은 아닙니다.

## 출처와 이용
OpenAI 내장 image generation 도구로 이 프로젝트의 사용자 승인 시안을 참조하여 생성했습니다. 외부 유료 스톡이나 타사 아이콘 팩은 포함하지 않았습니다. 별도의 스톡 라이선스 문서가 존재하는 것으로 주장하지 않습니다. AI 생성 결과물의 권리/이용 조건은 적용되는 서비스 약관에 따릅니다. 참조 시안의 기존 배경/캐릭터는 이 팩에 새 런타임 이미지로 복제하지 않았습니다.

생성 원본은 제작 작업 폴더에 별도 보관했습니다. 저장소에는 최종 런타임 PNG와 해시/분할 메타데이터를 포함합니다. 최종 PNG는 투명 여백 crop 및 비율유지 Lanczos 축소만 적용했습니다. 생성 도구가 만든 불필요한 저알파 원거리 노이즈가 crop 밖에 있을 수 있으나 물체 윤곽의 alpha는 보존했습니다.
