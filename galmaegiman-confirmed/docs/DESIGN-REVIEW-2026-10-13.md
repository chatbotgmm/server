# PR #2 전체 디자인 검토

검토일: 2026-10-13 (한국 시간). 기준: PR #2의 `751f7b9`와 작은 가로 화면 편성 카드 보정.

후속 확인: 사용자가 연습 모드는 유지하고 버튼 모양만 바꾸며, 스토리 버튼을 챕터 선택으로 연결해 달라고 명확히 설명했다. 현재 동작과 새 뽑기 확률은 [모드·뽑기 업데이트](MODE-AND-GACHA-UPDATE.md)에 기록했다.

## 결론

크림 패널·나무색 테두리·토피색 주요 버튼과 로비의 파스텔 메뉴가 같은 세계관으로 이어진다. 제목과 주요 행동의 위계가 분명하며, 로비 → 모드 → 스토리/전투 흐름에서 핵심 조작을 찾을 수 있다. 배포를 막는 화면 잘림이나 실행 오류는 이번 검토에서 확인되지 않았다.

## 검토에서 찾아 고친 것

780×360의 전투 편성 목록에서 긴 이름을 가진 카드의 등급·속성이 아래로 밀려 세로 스크롤을 해야 보였다. 높이 380px 이하의 가로 화면에서 목록 카드 그림 높이를 64px로 제한하고 `object-fit: contain`으로 원본 비율을 유지했다. 이름·등급·속성이 카드 안에 함께 보이고, 단상과 저장 버튼은 기존 위치를 유지한다. 915×412와 1280×720은 기존 그림 크기를 유지한다.

## 확인한 범위와 근거

- 실제 Fastify 서버, 격리 SQLite DB, 저장소의 콘텐츠·그림을 사용했다. 운영 계정과 운영 DB는 디자인 검토에 사용하지 않았다.
- Black Han Sans, Gowun Dodum, Bagel Fat One의 실제 글꼴 파일을 로드해 시스템 Chromium/Playwright에서 캡처했다.
- 1006×411, 915×412, 780×360, 1280×720에서 로그인 전·후, 설정, 로비, 프로필 메뉴, 뽑기·결과, 수집·편성, 출석, 모드, 스토리, 대사, 증강체, 전투 화면을 캡처하고 직접 검토했다.
- 모든 크기에서 페이지 가로·세로 넘침 없음, 전투 패널 밖 버튼 0개, 전투 글자 130%에서도 패널 밖 버튼 0개, 브라우저 실행 오류 0개.
- 이미지 전체 사각형을 비교하는 기존 검사에서는 상대 그림과 내 상태창의 겹침이 보고됐다. 실제 불투명 픽셀로 재검사한 결과 상태창과 겹치는 그림 픽셀은 0개였다. 투명 이미지 여백에 따른 경고이며, 캡처에서도 캐릭터가 정보를 가리지 않는다.
- 작은 화면 보정 후 780×360, 915×412, 1280×720에서 편성 카드 전체가 목록 영역 안에 들어오고 아이템 iframe의 페이지 넘침이 없음을 다시 확인했다.
- 로컬과 EC2의 별도 작업 폴더에서 빌드·콘텐츠 검사·격리 DB 124개 테스트 통과. CSS 보정 후 빌드와 앱 웹 리소스 패키징 통과. APK 빌드는 이번 범위에 포함하지 않았다.

## 후속 개선 후보

1. 모드 선택의 준비 중인 모험 칸은 사용할 수 없는 기능인데 세로 공간을 많이 차지한다. 추후 짧은 안내 줄로 줄이면 실제 사용할 수 있는 스토리·성장 기능이 더 두드러진다.
2. 작은 화면의 뽑기 확률, 전투 기술 보조 설명은 주요 제목에 비해 작다. 실제 기기에서 읽기 평가 후 최소 글자 크기를 조정하는 것이 좋다. 이번 검토는 브라우저 기준이며 실제 Android 터치·텍스트 확대 환경까지 검증한 것은 아니다.
3. PDF 해석에 대한 후속 사용자 설명을 반영해 중급·고급의 낮은 등급 추첨, 연습 버튼 복원, 스토리 챕터 선택 경로를 정리했다. 변경 내용은 모드·뽑기 업데이트 문서를 참고한다.
