## 2. 공통 규칙(모든 그림)

1. **글자를 넣지 않는다.** 이름·숫자·버튼 글씨는 앱이 그린다. 간판·말풍선·로고도 글자 없이 그린다.
2. **UI를 그리지 않는다.** 버튼·패널·HP바·프레임·폰 테두리 없이 장면만 그린다.
3. 세계관: 밝은 석회암 항구, 청록 바다, 등대, 테라코타 지붕, 담쟁이. 수채·애니 느낌의 채색. **사람은 나오지 않는다.**
4. 갈매미맨은 기존 종의 정체성을 유지한다. 흰 깃털 몸 + 돌(사암) 날개·머리 장식, 노란 부리, 둥글고 귀여운 실루엣. 종마다 다른 재질(돌·광물·금속·천)은 살린다.
5. 끼룩단(적)은 실제 깃털, 쭈매미는 촉수·빨판, 랍매미는 갑각·집게 재질이다. 적을 돌몸으로 바꾸지 않는다.
6. 파일: PNG(sRGB). 장소 그림은 불투명, 아이콘·캐릭터는 투명 배경(가장자리 깨짐 없음).
7. 장마다 받을 것: 최종 PNG, 사용한 지시문(텍스트), 파일 크기와 SHA-256 목록.

## 6. 받는 방법과 검수

- ZIP 한 개당 20MB 이하로 나눠 받는다. 파일명은 위 표 그대로 쓴다.
- 받은 뒤 개발 쪽에서 하는 일:
  1. 해시 확인
  2. 글자·UI가 그려졌는지 눈으로 확인
  3. 실제 앱 칸(휴대폰 915×412·태블릿 1280×720)에 얹어 캡처
  4. 잘린 주인공이나 겹침이 있으면 해당 장만 다시 요청
