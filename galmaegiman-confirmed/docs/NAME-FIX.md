# 이름 표시 수정 0.2.2

기존 카탈로그에서 이름이 비어 있던 흔함 6종 + 안흔함 5종 = 11종에 아래 표시명을 적용했습니다. 과거 확정 이름 원문은 확인할 수 없습니다. 아래 이름은 현재 이미지 콘셉트에 맞춰 붙인 표시명이며, 원래 이름을 복원한 목록이 아닙니다. 이름이 이미 있는 64종은 그대로입니다.

뽑기 결과·내갈매미·도감·교환/조합 안내·이미지 대체 텍스트에 이름이 표시됩니다. 0.2.3부터 캐릭터 ID는 내부 기록 연결에만 사용하고, 사용자 화면에는 표시하지 않습니다. 이름으로 조회하고 조합합니다. 이미 발송한 채팅 말풍선과 완료된 확정 요청의 DB 저장 결과는 과거 기록이므로 다시 쓰지 않습니다. 0.2.3에서 예전 완료 요청을 다시 보내면 번호 없는 완료 안내만 반환하고 재지급하지 않습니다. 적용 후 새로 `내갈매미` 또는 `도감 비닐봉지`를 입력하면 새 표시명을 확인할 수 있습니다.

## 기존 데이터와 호환

표시명은 `data/display-names.yaml`에서 읽습니다. 이름이 비어 있는 ID에만 사용할 수 있고, 기존 이름을 덮어쓰거나 필요한 표시명이 빠지면 시작 단계의 검증에서 거절됩니다. 75종 = 기존 이름 64종 + 표시명 11종입니다.

DB·카탈로그·조합 데이터·확률 설정·이미지를 수정하지 않습니다. 기존 SQLite에 코드명이 저장되어 있어도 화면에는 ID로 조회한 최신 표시명을 사용합니다. 따라서 보유 개체번호·도감·재화·확정 요청 기록을 이전하거나 초기화할 필요가 없습니다. DB 콘텐츠 해시는 기존 카탈로그와 조합 데이터 기준을 유지합니다.

패치에는 DB, 인증키, 터널 주소, 이미지, node_modules가 없습니다. 설치 전에 게임 서버를 멈추세요. 패치는 원본 0.2.1 파일의 해시를 확인하고, 변경 파일과 dist를 백업한 뒤 빌드합니다. 빌드 실패 시 이전 코드와 dist를 복원합니다. 변경된 사용자 파일은 자동 덮어쓰지 않습니다. 이 패치에서 스키마 변경이나 seed는 실행하지 않습니다.

## 유지되는 규칙

- 무료 게임 내 획득권을 사용한 즉시 랜덤 뽑기.
- 흔함 40% + 안흔함 30% + 특별 20% + 희귀 10% = 100%.
- 같은 등급 안에서는 균등 추첨. 기존 보유 여부에 상관없이 중복 획득 가능.
- 0.2.2 당시 한국 시간 09·12·18시마다 획득권 3장 추가. 0.2.4부터는 기본 10장이며 관리자 설정으로 변경합니다. 미사용분은 누적합니다.
- 75종의 ID·성별·등급·이미지와 조합식 69개 유지.

설치 방법은 프로젝트 README와 패치의 README-UPDATE.md, 검증 결과는 TEST-RESULTS.md에 있습니다.
