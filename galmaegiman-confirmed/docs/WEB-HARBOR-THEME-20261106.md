# 공개 홈페이지 공통 테마 「항구」 (2026-11-06)

사용자 지적(2026-11-06): 첫 화면과 다른 화면의 테마가 서로 맞지 않는다.

## 바꾸기 전
- 첫 화면(`/`, home-v4): 남색 머리줄, 양피지 본문, 금색 선, 명조 제목.
- 다른 공개 페이지(게임 소개·세계관·캐릭터·공지·다운로드·도감·조합법·랭킹 등): 밝은 돌색 머리줄, 둥근 글꼴(Jua) 로고·제목, 둥근 카드.
- 마을 시각탐색(`/village`): 어두운 앱 화면 모양, 공통 머리줄 없음.

## 바꾼 것
- `public/site/harbor.css`(새 파일): `site.css`·`legacy.css` 뒤에 읽어 색·글꼴·모양만 첫 화면 값으로 덮는다. 내용·기능·주소는 그대로다.
- `src/site.ts` 공통 틀: 머리줄을 첫 화면과 같은 문장(✦ 갈매미맨 방범대)·메뉴 6개(마을 둘러보기 포함)·「로그인 + 게임 시작」으로, 바닥을 첫 화면과 같은 구성으로 바꿨다.
  좁은 화면(1000px·650px)도 첫 화면과 같은 방식(메뉴를 둘째 줄, 휴대폰은 3칸×2줄)으로 줄인다.
- 첫 화면: 머리줄에 「게임 시작」 추가(다른 페이지와 같게), 휴대폰에서 「날개로,커다란」 띄어쓰기 수정, 예전 홈에 있던 검색엔진용 사이트 정보(WebSite JSON-LD)를 다시 넣음.
- 마을 시각탐색: 같은 머리줄·바닥, 같은 남색·금색, 각진 버튼. 장면 보기 특성상 어두운 바탕은 유지(첫 화면의 남색 「플레이 안내」 띠와 같은 색).
- 예전 페이지의 장식 색(장 제목을 번갈아 칠하던 무지개색)은 남색·황동·청록·적갈로 바꿨다. 등급 의미 색과 카카오 노랑은 그대로다.

## 검토
- 17개 공개 페이지 × 4가지 크기(1280×720, 1024×700, 915×412, 390×844) 캡처, 가로 넘침·머리줄 겹침·화면 밖 버튼·깨진 그림 검사 통과.
- 검토에서 찾아 고친 것: 휴대폰에서 첫 화면만 메뉴가 펼쳐지고 다른 페이지는 서랍 메뉴였던 차이, 예전 페이지 제목 굵기, 무지개 장 제목 색, 짧은 페이지 바닥 아래 빈 바탕, 첫 화면 로그인 글씨 굵기, 마을 문장 크기.
