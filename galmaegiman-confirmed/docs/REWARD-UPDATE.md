# 갈매미맨 0.2.5 — 획득 소개와 보상

적용 대상: `~/galmaegiman-confirmed`에 설치된 **0.2.4**. 이번 파일은 기존 설치용 업데이트입니다.

## 변경 내용

75종에 별칭·등장 장면·도감 소개를 추가하고, 조합 결과에는 각 조합의 개연성을 담은 성공 문구를 표시합니다. 흔함은 짧게, 안흔함·특별은 별칭과 장면을, 희귀는 개별 도감 기록까지 보여줍니다. 별칭과 소개는 캐릭터 설정이며 새로운 전투 능력을 부여하지 않습니다.

첫 발견과 중복 획득을 구분하고 캐릭터와 함께 다음 새우깡을 지급합니다.

| 등급 | 첫 도감 등록 | 중복 획득 |
|---|---:|---:|
| 흔함 | 0 | 0 |
| 안흔함 | 10 | 3 |
| 특별 | 30 | 10 |
| 희귀 | 90 | 30 |

값의 원본은 `data/acquisition-rewards.yaml`입니다. 뽑기와 조합 모두 같은 표를 사용합니다. 캐릭터를 소비해도 도감 기록이 있으면 다음 획득은 중복 보상입니다. 중복 캐릭터도 그대로 보유합니다. 흔함 선택 교환에는 보너스를 지급하지 않습니다.

기존 교환 비용은 흔함 1마리당 새우깡 30개입니다. 희귀 첫 보상으로는 `90 ÷ 30 = 3마리`, 중복 보상으로는 `30 ÷ 30 = 1마리`를 교환할 수 있습니다. 게임 안에서 `보상`을 입력하거나 획득 화면의 **획득 보상**을 누르면 표를 확인합니다.

최초 여부는 지금 가지고 있는 수량이 아닌 누적 도감 이력으로 판정합니다. 이전 획득이나 이전 버전에서 이미 끝난 조합에는 보너스를 소급 지급하지 않습니다. 같은 조합 확인 버튼을 반복해도 새 보상은 추가되지 않습니다. 새 보너스로 인해 새우깡이 2,000,000,000개를 초과할 경우 남은 한도만 지급하고 실제 지급량을 안내합니다.

기존 캐릭터 이름·조합 재료·뽑기 확률·충전 설정·이미지 노출 규칙·DB 스키마는 유지합니다. DB 초기화나 seed를 실행하지 않습니다.

## 갤탭 적용

1. `galmaegiman-update-v0.2.5.zip`을 갤탭 Download 폴더에 저장합니다.
2. 게임 서버를 실행한 Ubuntu 창에서 `Ctrl+C`, 이어서 `exit`를 입력합니다. 터널 창은 켜 둡니다.
3. Termux에서 아래를 실행합니다.

```bash
cd "$HOME"
unzip -o storage/downloads/galmaegiman-update-v0.2.5.zip -d galmaegiman-update-v0.2.5
proot-distro login ubuntu --termux-home
```

4. Ubuntu에서 적용합니다.

```bash
cd ~/galmaegiman-confirmed
node ../galmaegiman-update-v0.2.5/apply.mjs
```

5. **갈매미맨 0.2.5 적용 완료**가 나온 뒤 실행합니다.

```bash
npm start
```

카카오톡에 `보상`, `뽑기`, `내갈매미`를 새로 입력해 확인합니다. 기존 말풍선은 바뀌지 않습니다. `보상`이 연결되지 않으면 기존 게임 스킬에 연결된 폴백 블록으로 해당 발화가 전달되는지 확인합니다. 스킬 URL과 인증 헤더는 그대로 사용합니다.

설치기는 수정할 파일의 기존 해시를 확인하고 코드와 dist를 `backups/update-v0.2.5-*`에 백업합니다. 사용자 수정 파일이 있으면 덮어쓰기 전에 중단하고, 빌드 실패 시 이전 코드와 dist를 복구합니다. 0.2.4가 아닌 버전은 이 패치를 바로 적용하지 않습니다.

## 수정·추가 파일

- `src/game.ts`: 획득 보상 트랜잭션과 화면 연결, 보상 안내.
- `src/content.ts`: 소개와 보상 설정 검증.
- `src/acquisition.ts`: 등급별 소개·첫 발견·중복 보상 표시.
- `data/flavor.yaml`: 기존 75종의 소개 문구.
- `data/acquisition-rewards.yaml`: 보상표.
- `test/acquisition.integration.test.ts`, `test/acquisition.test.ts`: 이번 기능 검증.
- `test/game.integration.test.ts`: 바뀐 결과 문구·버전 기대값 및 조합 소개 확인.
- `src/app.ts`, `package.json`, `package-lock.json`: 배포 버전 0.2.5.
- `README.md`, `docs/REWARD-UPDATE.md`, `docs/package-checksums.sha256`: 적용 안내와 파일 해시.

## 검증

- TypeScript 빌드 통과.
- 격리 SQLite에서 실제 보상 테스트 14개 + 소개·설정 테스트 12개 = **26개 통과**.
- 네 등급의 첫 발견·중복 보상, 동시 획득, 조합 확인 반복, 보상으로 실제 교환, 소비 후 재획득, 이전 기록의 소급 지급 방지 확인.
- 보상 로그에 강제로 오류를 발생시켜 캐릭터·재료·재화·도감·확인 결과가 함께 원복됨을 확인.
- 75종 획득 소개와 비흔함 69종 조합 소개의 이름·보상 표시 및 500자 이내 길이 확인.
- 잘못된 보상 값과 누락된 소개는 콘텐츠 로드 시 거절.
- 격리된 0.2.4 설치본에 ZIP을 실제 적용해 빌드와 새 데이터 로드를 확인했습니다. 설치 전후 DB·충전 설정·카탈로그·조합식·스키마 해시가 같습니다. 실행 기록은 ZIP의 `VERIFICATION.txt`에 있습니다.

Linux 환경에서 검증했습니다. 실제 갤탭과 카카오 채널에서의 동작은 원격으로 확인할 수 없습니다. 기기에는 위 설치 절차로 적용해야 합니다.
