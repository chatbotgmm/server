## 글꼴 증거
시안 renderer는 NotoSansCJK-Regular.ttc를 `Noto` 별칭으로 등록했다. 원본 TTC의 실제 기본 face는 **JP face0**이며 KR face1이라고 추정하지 않고 서로 다른 CJK 글리프 렌더로 확인했다. 시안 문구는 두 face에서 같지만 배포물은 정확한 face0에서 추출했다.

- 배포 정적 CFF OTF: `assets/fonts/workbench-noto-regular.otf`, 2,172,064 bytes
- SHA256: `615c5dde6d447d0d04833177702a09a93d120fa71eb940acc921bc4b2dfa5d35`
- 내부 패밀리 `GMM Workbench`; SIL OFL1.1 전문과 원저작권 동봉.
- 13,620 문자, 모든11,172 한글 완성형 및 자모·라틴·공통기호 포함. 선택 범위 밖 문자는 플랫폼 fallback에 의존할 수 있다.
- 원본과 모든 포함 글리프 윤곽/폭 동일. 시안17문구×6크기×400/700=204개 canvas 래스터 동일. 두 번 재생성해 바이너리 해시 동일.
- 시안은 Regular만 등록하고700을 요청하므로 Android에서도 같은 Regular를 로드해 굵기를 합성한다. OS rasterizer 차이까지 같다고 주장하지 않는다.
- API24에서 사용 가능한 `Typeface.createFromAsset`와 정적 OTF를 사용하며 API26 font resource/Builder에 의존하지 않는다. API24 실기기 로드는 아직 검증되지 않았다.
