# 홈 펼침 메뉴 · 구현 검토 (2026-10-21)

## 상태와 승인 범위
- 기존 리뷰 브랜치의 홈 화면만 변경한다. 운영 병합·배포·APK 빌드는 하지 않았다.
- 사용자 승인: 우측 하단 큰 플레이 고정, 옆 메뉴 토글, 나머지 7개 기능을 4+3으로 펼침. 추가 요청으로 조언 말풍선을 캐릭터 아래에 둔다.
- 기존 항구/캐릭터 원본, 물·배경 이펙트·호흡·드래그 애니메이션은 유지한다. 전체 시안 이미지를 앱 화면으로 붙이지 않는다.
- 홈 외의 조합/상점/전투 UI를 다시 테마화하지 않는다. MainActivity 변경은 홈 Back 처리, NativeTutorialController 변경은 숨겨진 홈 목표 펼침 연결에 한정한다.
- 실제 Android 빌드·렌더·실기기 입력 검증은 미완료. 승인된 시안을 기반으로 한 **소스 초안**이며, 빌드/배포 전 기존 CLAUDE.md 네이티브 디자인 검토 게이트를 수행해야 한다.

## 분리 원화 적용
- assets/native/home-menu-v1에 글자 없는play/menu/tile/panel4종, 투명재화3종, 메뉴아이콘7종을 별도 배치한다.
- HomeMenuArt가 실제 각PNG를 로드한다. 표면은source64px(패널52px)9slice로 모서리를 보존한다. targetcorner는플레이·큰타일16dp/작은타일·메뉴12dp/패널16dp/재화배경8dp이며 작은표면에서는1/3이하로제한한다.
- 화면의 글자·실제재화숫자·상태별알림점은코드가그린다. 아이콘은별도투명contain, 배경/캐릭터는기존HomeArt와애니메이션이그린다.
- 런타임면적별로플레이원화/작은메뉴원화/정사각타일원화를구별한다. 눌림은명도필터, 비활성은단일alpha, 키보드초점은내부하이라이트로표시한다.
- 홈제목/버튼은승인시안과맞춘기존scoped Noto원본폰트를홈에서만사용한다. 조언은기존본문서체를유지한다.

## 동작
- 기본은 메뉴 닫힘. 모집 / 방범대 / 조합 / 탐험 / 상점 / 전투 편성 / 출석·미션 순서.
- 토글·바깥 탭·Android 뒤로가기로 닫힌다. 닫는 바깥 탭은 아래 조작부로 관통하지 않는다.
- 플레이는 기존 modes 진입이며 진행 중 전투 복귀 버튼의 native/battle/current 흐름도 그대로 유지한다.
- 알림점은 기존 모집·탐험·출석 등 실제 eligibility를 집계한다. 임의 보상·가짜 잔액을 넣지 않는다.
- 실제 잔액을 사용한다. 좁은 화면에서 긴 잔액은 만/억 단축표시하고 접근성 설명에는 정확한 전체 값이 남는다.
- 메뉴의 숨김은 GONE, 열 때 키보드 초점과 탐색 순서를 제공하며, 닫을 때 토글로 돌아간다.
- 첫 튜토리얼의 출석/모집/편성 안내는 실제 홈 메뉴를 먼저 펼쳐 기존 버튼을 가리킨다. 진행/보상 API를 새로 실행하지 않는다.
- 말풍선은 캐릭터 아래 예약 영역 안에서 실제 TextView로 측정한다. 큰 글꼴/짧은 화면은 글씨를 잘라내지 않고 기존 줄 단위 페이지 기능을 이용한다.

## 검토에서 찾아 고친 것
1. 작은 화면의 헤더·진행 전투 복귀와 캐릭터 겹침: 실제 헤더 하단 입력 및 최소 공간 예약.
2. 캐릭터가 작아졌을 때 터치영역 48dp 미달: 그림과 별도로 최소48dp 타겟 보장.
3. 긴 재화 숫자 과도한 축소: 작은 화면 헤더 폭 확보 및 단축표시/전체 접근성 값.
4. 눌림 양피지 위 흰 글자 대비: 눌림에도 진한 잉크 유지.
5. 복귀 버튼 측정폭/배치폭 불일치: 실제 영역으로 EXACT 재측정.
6. 접힌 메뉴로 첫 튜토리얼 대상이 사라짐: 홈 전용 실제 목표 펼침 연동.
7. 분리 원화를 실제 코드 좌표로 렌더링하자 작은 타일의 하단 장식과 글자가 겹침: 원화 코너 출력12/16dp로 축소, 라벨4dp상향, 글자/아이콘 안전 여백 확대.

## 검증
- HomeMenuLayout 독립 JVM: 7개 크기(568×280~1280×720), 4개 밀도, 4개 글꼴 배율, 전투 여부, 3개 헤더 입력 = 672개 조합. 93,408개 기하 검증 통과.
- Java AST 구문 검사: 생산5파일, 네이티브테스트5파일, 순수JVM테스트1파일 총11파일 통과. 이는 Android 타입 검사나 빌드 통과가 아니다.
- 네이티브 Robolectric 회귀 테스트는 소스만 갱신했다. 새 메뉴 양상태, 기존 목적지, 바깥 탭 관통 방지, Back, 알림, 튜토리얼 목표, 글꼴2배, 작은 화면, 페이지별 글자/종이 잘림 및 전체 조언 보존을 검사하도록 작성했다.
- SDK/Gradle 실행 환경 부재로 네이티브 테스트 및 앱 빌드는 실행하지 못했다.
- 코드 배치 미리보기는 실제 Java 좌표 기반 보조 자료이며 네이티브 캡처가 아니다. 원본 캐릭터/아이콘이 없는 자료는 영역 표시로 명시한다.
