# 실제 마을·주민·장식 연결과 전체화면 검증

최신 상태는 전체화면 마을, 건물 위 이름, 실제 그림 터치, 주민 4명과 장식 8곳을 연결한 로컬 검토본이다. 이전 151시험·고정 헤더/하단 바 APK와 구분한다. 최신 Android 단일 실행은 25모음 160시험 모두 통과했고, 대표 시장 캡처 보정 후 별도 2시험도 통과했다. 시각 검토와 새 APK 정보는 아래에 기록한다.

## 정확한 기준과 보존

소스 기준은 `manual/home-assembly-20261019@c37c24ecb9399abf0cb438b25412924ffbe921db`다. 이전 버그·스토리·일반전 XP·마을 통합 tree `5b18756652507125b8db72bc59bd0734fbb1c08d`의 86파일을 보존했다. 이전 ZIP SHA256은 `25977a84f6274dd27c804a8f9f5a3faa1ca0a35f4c213d3d081b3db8bbcbfae4`다.

원화는 불변 커밋 `2f1890e1df37b426cbfa27ccce8cd293186ad512`의 기존 13 PNG와 `78660ff70397434751a4aaa1b4fce85b10cc72ab`의 추가 장식 3 PNG다. 두 커밋 사이에 추가된 것은 `decor/cottage.png`, `decor/warehouse.png`, `decor/closed_shop.png`뿐이며 기존13의 크기·Git blob·SHA256은 동일하다. 브랜치 전체를 checkout/reset하지 않고 지정한 파일 blob만 읽었다.

16개 모두 PNG 형식·치수·알파·Git blob·SHA256을 확인하고 실제 픽셀을 직접 열었다. 총 원본 크기는 32,348,091 bytes다. 원본 PNG 바이트는 변경하지 않았다. manifest의 확인된16개만 `verified:true`로 고정하고 출처 커밋·경로·해시·표시영역을 기록했다. 빌드에서 파일명 별칭을 붙인 장식도 바이트는 동일하다. 런타임은 번들 자산을 읽으며 개인 GitHub 인증이나 Library 다운로드에 의존하지 않는다.

이 16개에 석상 시트는 없다. 스토리의 1→5단계 저장과 실제 석상 복원 이미지 연출을 구분하며, 후자는 여전히 미연결이다.

## 사용자 피드백으로 바뀐 실제 UI

상하 여백의 원인은 고정 마을 제목·개발 안내줄, 하단 건물 설명판과 구역/화살표 바로가기였다. 모두 제거했다. 배경은 View 전체 `(0,0,width,height)`를 덮고, OS 안전 영역은 작은 출석·메뉴 아이콘과 터치에만 적용한다. 화면 이동은 좌우 드래그와 관성으로 한다.

건물 아래 이름·설명판과 부제는 표시하지 않는다. 건물 위에 이름만 실제 게임 글꼴의 UI 텍스트로 표시한다. 이름뿐 아니라 건물 그림 자체가 클릭 대상이다. 투명 여백과 비율 맞춤으로 남은 빈 영역은 알파32 기준으로 터치에서 제외해 옆 건물·주민 오선택을 막는다. 주요 건물6개·주민4개·아이콘2개로 View 대상 수는12개이며 장식 때문에 늘어나지 않는다.

방범대원은 지원소와 아지트 사이 x=.84에 한 명만 둔다. 사서·상인·대장장이도 개별 투명 PNG를 사용한다. 주민은 조건 미달에도 보이며 서버 상태가 AVAILABLE일 때만 `!`를 표시한다. 주민 터치는 제안 열기이며 수락과 분리한다. 진행·보고·완료 상태도 구별한다.

장식은 별도 불변 목록으로 분리했다. 크기 `.16~.24U`, baseline `.70~.73`의 작은 후경8곳이며 주요 그림 실루엣을 복제하지 않는다. 바다 다음, 전경 산책로 이전에 그려 바닥 일부가 담장 뒤에 자연스럽게 가려진다. 구역마다 두 곳을 두고 걸을 여백은 남겼다. 장식 메타데이터에 메뉴·이름·의뢰·터치 필드를 넣으면 파서가 거절한다.

카메라는 연속 값을 유지하고 화면 투영만 modulo 처리한다. 원경·바다·지형은 원본 비율과 월드 주기에 맞는 짝수 반사 타일을 사용해 한 바퀴 뒤 배치·방향이 일치한다. 소수점 경계의 얇은 선은 양쪽0.5px 여유 그리기로, 태블릿의 빈 하늘 띠는 비율 유지 center crop으로 해결했다.

## 검토에서 찾아 고친 것과 시험

최초 실제 원화 시험은 51개 중50통과·1실패였다. 기존 전투 툴바의 baseline 정렬이 안내 글을12px 밀어 잘리게 했으며 `setBaselineAligned(false)`로 고쳤다. 같은51개가 통과한 뒤 직접 픽셀 검토에서 타일선과 태블릿 하늘 빈 띠를 발견해 추가 보정했다. 그 당시151개 모두 통과했으나 상하 고정 패널이 남았던 이전 UI 결과다. 로그·JUnit과 이전 APK 해시는 역사 기록으로 보존한다.

전체화면 첫 시험은2개 중1개 실패했다. 짧은 이름인 ‘시장’의 이름표 폭에 불필요한48dp 하한이 있어 이름 폭 검사와 맞지 않았다. 이름표는 실제 글자폭으로, 그림 클릭 대상은 별도로 최소48dp를 유지하도록 수정했다. 실패 원문도 `fullscreen-first`에 보존했다.

최신 단일 실행 `fullscreen-decor-final`은 **25모음·160시험 통과, 실패·오류·건너뜀0**이다(5분1초). 전체화면과 안전영역, 건물 위 이름·부제 제거, 실제 불투명 그림 DOWN/UP 선택, 투명 모서리 무반응, 이웃 불투명 영역 겹침0, 장식 파서, 한 바퀴 경계, 빠른 탭 정지/느린 탭 선택, 역방향 드래그, 뒤로가기·재진입·회전·로그인 복귀·계정교체·401·이전 응답·자산 지연·주민 상태를 포함한다. 기존 스토리·모집·조합·대전·일반전 XP 표시 회귀도 함께 실행했다.

시장 대표 컷에서 대장장이가 화면 가장자리에 조금 잘려 보여 캡처 카메라만6.077→6.05로 조정했다. 생산 배치는 바꾸지 않았다. 두 주민의 완전 가시성 assert를 추가한 별도 `fullscreen-decor-representative` **2시험 모두 통과**다. 이를162개 단일 실행으로 합산하지 않는다. 변경한 소스는 이 캡처 시험1파일뿐이며, 재생성한24개 위치 PNG는 이전160시험의24장과 바이트까지 같다.

16개 실제 디코딩 allocation은25,156,012 bytes다. 세 규격×8위치24개의 한 바퀴 전후 픽셀은 모두 동일하고 차이0, 빈 가로띠0이다. 배경·바다·지형·장식·주요 건물·주민·배가 함께 검사된다. 작은640×320과 안전영역 입력도 별도 시험에 포함한다.

최신 마을24위치+4대표 구역과 로그인 전/로그인/로그인 후/마을/전투15장, 총43장을 각각 직접 열어 검토했다. 남은 시각 차단 문제는 발견하지 못했다. 주요 시설과 주민을 장식이 가리지 않으며 큰 고정 바·부제판 없이 이름이 위에 읽힌다. 전투 안내줄 보정도 유지되고 세 규격의 HUD 불투명 그림 겹침은 양측0픽셀이다. 큰 글꼴 로그인 본문에 단어 줄바꿈은 있으나 누락·잘림은 없다. 픽셀 검토 파일별해시와 한계도 기록했다.

Robolectric SDK35의 실제 native View/Canvas·앱 글꼴·번들 PNG를 사용했고 API는 통제된 fixture다. 실계정 로그인·운영 지급·DB 변경 증거가 아니다. `CLAUDE.md`의 빌드 전 실제 글꼴·가로 화면·숫자·직접 픽셀 검토를 native 화면으로 수행했다. 옛 `scripts/design-review.mjs`는 웹 화면 및 심사 로그인·모집 쓰기라 사용하지 않았다.

서버 소스와 XP 정책은 이전 통합본을 보존했고 이번 UI 변경 뒤 다시 실행하지 않았다. 이전 단일206시험 중186통과·20개 기준 동일 모집 cleanup FK 실패와 별도 카탈로그 경계1통과를 구분해 보존한다. c37 대조에서도 같은20실패가 재현됐으며 이미지 연결로 해결된 것이 아니다.

## 최신 산출물과 운영 경계

새 검토 APK `gmm-village-fullscreen-decor-localdebug-20261027.apk`는26초에 빌드 성공했다. 크기249,570,446 bytes, SHA256 `9e1c4f319a6906d3577020921f9aa9913a7ae3df185b8ca808855b0a73a18b54`다. 디버그서명과 패키지/버전, 번들16PNG의 원본 바이트·SHA256 및 manifest16verified를 확인했다. 이전 고정 패널 APK `gmm-village-localdebug-20261027.apk`와 구분한다. 이전 offline 빌드의 desugar2.1.5 캐시 누락 실패도 보존했으며, 이번 최신 빌드는 이미 받은 고정 의존성으로 offline 성공했다. 새 APK Library ID는 `libfile_4ec09de414248191afca8e56f1acb3f9`(버전0)다.

검토 APK는 `org.gmm.producttest`, versionCode78, versionName2.2.4-native의 로컬 디버그서명 빌드다. 대상은 **에뮬레이터의 로컬 시험 서버 http://10.0.2.2:3999**다. 실제 휴대폰의 운영 접속용 배포 APK가 아니며 설치·서버 실행·접속·운영 반영을 하지 않는다. 운영 서명 환경도 빌드에서 제외한다.

사용자용 PNG는 실제 native 렌더를 그대로 사용한다. 첫 화면과 네 구역은915×412, 전체8U 파노라마는7320×412다. 이미지 안에 개발 안내문이나 바깥 여백을 추가하지 않는다. 파노라마만 작은 고정 아이콘을 숨긴 연속8화면을 수평으로 잇고, 다른 그림 생성·원본 아트 편집은 하지 않았다. Library의 이전 두 프리뷰는 같은 파일 ID의 버전1로 갱신했다. 첫 화면/동료 구역은 `libfile_787b1493c22481919dec44643d6c2b60`, 파노라마는 `libfile_987231e88c8081918d500e46a5bca706`이다. 기록소는 `libfile_755016df7bd08191a36acdf2ddbd3f27`, 바닷가는 `libfile_6fb6c26976e4819186d970ba4c5b9cbe`, 시장은 `libfile_51a560b1a5a88191a0ca4fd484c2ffa1`의 버전0이다. 옛 고정 패널 화면은 이전 버전으로 보존된다.

완전 통합 패치는 깨끗한 c37c24e에 한 번 적용한다. 정확한 이전 통합 tree5b187566에 적용하는 후속 패치는 대안이며 두 패치를 중복 적용하지 않는다. 소스 원본·보고서·실패 포함 증거와 적용/역적용·정확한 Git blob 검증을 ZIP에 넣고 APK는 별도 파일로 둔다.
