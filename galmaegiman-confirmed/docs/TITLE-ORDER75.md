# 선봉 드래그와 첫 화면 시안 검토

## 실제 앱 변경

스토리 수비대의 오른쪽 48dp 손잡이를 위아래로 끌면 출전 순서를 바로 저장한다. 전투 편성은 단상 카드·이미지·손잡이를 좌우로 끌어 임시 순서를 바꾸고 기존 저장 버튼으로 확정한다. Story/PvP의 서로 다른 저장 경로는 유지한다.

오래 잡는 동작은 카드를 들어 올리며 드래그를 계속할 수 있다. 긴 누르기 타이머가 순서 선택창을 먼저 열던 동작을 없앴다. 손잡이 탭과 접근성의 긴 누르기는 순서 메뉴 대안이다. 카드 본문의 상세/제외 동작과 스크롤, 영역 밖 놓기·취소·다중 터치·저장 거절 처리를 구분한다.

주요 변경 파일은 `NativeTeamReorder.java`, `NativeTeamPodiumReorder.java`, `NativeGrowthGuidance.java`, `NativeMenus.java`다. 서버 API·게임 규칙·원본 캐릭터·배경·음악·글꼴은 유지한다.

## 첫 화면 네 방향

현재 첫 화면은 큰 소개 패널과 중복 제목이 시선을 분산시키고, 작은 가로 화면에서는 소개 문구가 일부만 보인다. 이를 개선할 방향을 선택할 수 있도록 테스트 전용 Native View/Canvas 장면 네 개를 만들었다. 제품 `TitleView`에는 연결하지 않았다.

| 안 | 구성 | 강조점 |
| --- | --- | --- |
| A 영웅 타이틀 | 원래 이미지 로고·원본 대표 캐릭터·큰 시작 버튼 | 밝고 친숙한 게임의 첫인상 |
| B 수비대 출항 | 항구 깃발·원본 등장 캐릭터 3종·황동/청록 | 등장 캐릭터와 함께 출항하는 분위기 |
| C 전설 도감 | 펼친 모험일지·실제 수집 카드·대표 캐릭터 | 수집·조합과 C 모험일지 테마 |
| D 보스 대치 | 원본 아군 뒷모습·원본 보스·밤 항구 | 턴제 전투의 긴장감 |

모든 시안은 APK의 실제 이미지와 Jua/Gowun Dodum을 쓴다. 캐릭터를 다시 그리지 않았고 임의 재화·기술 수치를 넣지 않았다. 시안은 정지 프레임이다. 시안의 빛·입자는 애니메이션 구현 완료를 뜻하지 않는다. 선택 후 제품에 적용할 때 기존 현지 시간별 배경·고정 UI·감소 모션·안전영역 동작에 통합한다.

`TitleConceptReviewTest.java`는 테스트 소스에만 포함하며 로그인·실제 게임 시작을 수행하는 제품 화면이 아니다. 출력은 `/workspace/review-artifacts/pr-2/title-and-order75/native/title-concepts/`의 915×412·1280×720 전체 화면이다.

### 전투 원본으로 수정한 A·B·C

A·B·C 구도는 유지하고 캐릭터 재질이 달라 보인다는 사용자 검토를 반영했다. 타이틀용 입체 일러스트 대신 실제 전투의 `D1_s0_front.webp`(태초의 갈매미맨)를 사용한다. B의 동료도 전투 원본 `T6_s0_front.webp`(천체 갈매미맨), `I9_s0_front.webp`(갈슬리퍼)로 맞췄다. 원본 이미지·비율·색은 보존하고, 강한 후광을 줄이고 발 위치에 환경 그림자와 접촉 그림자를 나누어 배치했다. C는 종이 위 도해에 맞춰 그림자를 약하게 처리했다. D 시안의 렌더링은 유지한다.

수정본은 `/workspace/review-artifacts/pr-2/title-battle-original/native/title-concepts/`에 별도로 보존한다. 폰·태블릿 6장을 직접 검토했고, 기존 네이티브 렌더링 검사 1개가 8개 화면의 48dp 터치·설정/시작 버튼 분리·글자 넘침 검사를 통과했다. 이 수정은 선택을 위한 테스트 전용 시안이며 배포된 APK 75의 첫 화면에는 아직 연결하지 않았다.

### 추가 E·F·G

E 출항 지도는 왼쪽 전투 원본 D1과 오른쪽 양피지 항로·타이틀을 나눈다. F 조합의 연대기는 실제 서버 정의의 쌍패성왕(L2) 1 + 거울떼갈매미(H6) 1 → 태초의 갈매미맨(D1) 1을 원본 카드와 황동 화살표로 표현한다. G 달빛의 수호자는 밤 항구에서 큰 D1과 오른쪽 제목·시작 버튼을 달빛과 등불로 분리한다. 가짜 챕터·재화·진행률은 넣지 않았다.

검토에서 F의 연결선 대비를 올리고 등급 혼동을 피하도록 문구를 ‘하나의 수호자로’로 다듬었다. G의 상단 문구는 달과 겹치지 않게 이동했다. 현재 캡처 검사는 7방향×2해상도 14장을 출력하고, 추가안의 캐릭터·CTA 비겹침도 확인한다. 출력은 `/workspace/review-artifacts/pr-2/harbor-immersion/native/title-concepts/`다. A·B·C·D 렌더링은 이전 수정본과 동일하게 보존한다.

사용자가 G 진행을 선택한 뒤 제품 첫 화면에 원본 D1·오른쪽 타이틀·황동 CTA를 적용했다. 이 문서의 ‘제품에 연결하지 않음’은 75판의 비교 시안 단계를 뜻한다. 76판 적용 결과와 시간대·로그인·안전 영역 검증은 `TITLE-G76.md`를 참조한다.

## 검증 기록

최종 집중 검사 18개가 모두 통과했다(실패·오류·제외 0). `NativeTeamDragTest` 6개는 실제 View 루트의 이벤트 전달, 빠른 드래그·긴 홀드, 일반 탭과 손잡이 분리, Story/PvP 저장 요청과 재진입, 취소·영역 밖 놓기·교차 스크롤·저장 거절을 확인한다. 915/1006 가로 화면과 글꼴130%의 긴 이름에서도 48dp 손잡이와 카드 전체 표시를 확인했다.

`NativeTeamDragReviewTest`는 격리된 로컬 서버에 저장·재조회하고 원래 편성을 복원한다. 폰·태블릿 각각 스토리/편성의 전·드래그 중·후 12장을 확보했다. 전체 실제 Native View/Canvas 캡처는 85장이며, 로그인 전·후 시작·로비·전투의 필수8화면과 PvP 카드도 직접 검토했다. 운영 계정이나 운영 DB는 검토에 사용하지 않는다.

검토에서 드래그 안내가 화면 아래로 밀리는 것을 고쳐 카드 위에 배치했다. PvP의 추가 탭 때문에 작은 화면 카드가 잘리는 문제도 발견해 compact PvP에서 초상과48dp 손잡이를 나란히 놓았다. 시안은 B 문구 대비·C 카드 아래 여백·D 캐릭터와 시작 버튼의 겹침 및 보스 비중을 보완했다.

기존 전투 연출 검사의 무작위 수면 효과가 합동기 시나리오를 막는 경우를 확인했다. 격리127.0.0.1:4002 서버의 전투 seed만1로 고정해 실제 규칙의 학습 선택100가지 모두 해당 시나리오가 성립함을 검사했다. 인증 난수·학습 선택 난수·제품 서버와 게임 규칙은 그대로다. 전투 검사에는 실패해도 최신 서버revision으로 세션을 정리하는 finally를 추가했고, 편성 준비·복구 요청의 오류는 즉시 표시하도록 했다.

시안과 실제 앱 캡처는 `/workspace/review-artifacts/pr-2/title-and-order75/native/`, 최종 검사 XML은 `final-results/`, 검증 요약은 `final-verification.json`이다. 실기기에서의 드래그 감각·접근성 제스처와 최종 선택한 첫 화면의 시간대·컷아웃·큰 글자 통합 검수는 별도로 수행한다.
