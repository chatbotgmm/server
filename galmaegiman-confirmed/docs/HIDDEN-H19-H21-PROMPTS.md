# 새 히든 3종 그림 요청문 (H19~H21) — 관리자 전용(히든 정답 포함)

사용법: ChatGPT 이미지 생성. 메시지마다 **첨부 1 = 기존 히든 그림 하나(예: public/images/H16.png, 보라 테두리 카드 스타일 기준)**, **첨부 2 = public/images/N1.png(중성 갈매미)**.
완성본은 정사각형 PNG로 저장해 `public/images/H19.png`, `H20.png`, `H21.png`로 넣고 업데이트하면 바로 보여요(카드용 작은 그림은 서버가 원본으로 대신 보여 줌).

공통 머리말(세 메시지 모두 맨 앞에 붙이기):
```
첨부 1과 같은 카드 스타일(보라색 히든 테두리, 아래쪽 이름판, 배경이 있는 장면, 귀여운 3D 비닐 토이 느낌)로
갈매미 캐릭터 카드 그림을 1장 그려 줘. 갈매미는 돌로 된 작은 갈매기 수호자 석상이야(첨부 2의 중성 갈매미가 기본 모습).
정사각형 1:1. 이름판 글자만 한글로 정확히 쓰고, 그 밖에는 글자를 넣지 마.
Avoid: eagle, hawk, hooked beak, scary, realistic gore, extra text, watermark
```

## H19 인사팀장 갈매미
```
이름판: 인사팀장 갈매미
장면: 수비대 인사팀 사무실. 평온한 표정의 중성 갈매미가 책상에 앉아 있다.
한 손에는 항구 모양 큰 회중시계(조석시계), 다른 손에는 강철 바늘과 실로 명찰을 꿰매는 중.
책상 위에 '같은 자리' 발령장 종이 더미(글자 없이 도장 자국만), 벽에 자리 배치표(글자 없이 칸만).
분위기: 차분하고 사무적인데 살짝 웃긴, 따뜻한 형광등 조명.
```

## H20 바스락상회 사장
```
이름판: 바스락상회 사장
장면: 작은 새우깡 가게 카운터(봉지에는 글자·상표 없이 새우 그림만). 평온한 중성 갈매미가 금빛 앞치마를 두르고
새우깡 봉지를 아주 조심스럽게 소리 없이 여는 중. 옆에 금빛 갑옷 장식(금갑)과 황금 깃털 장식.
뒤편 창밖으로 돌 갈매미 수비대원들이 멈추지 않고 지나가는 모습.
분위기: 아늑한 가게, 노란 조명, 조용함을 강조(입에 손가락 '쉿').
```

## H21 회의 중 갈매미
```
이름판: 회의 중 갈매미
장면: 마을 회관 회의실. 똑같이 생긴 평온한 중성 갈매미 셋과 기본 갈매미맨 하나가 동그랗게 붙어서 한 몸처럼 뭉쳐 있다.
가운데 탁자 위에 땅콩 한 알이 덩그러니. 화이트보드에는 땅콩 그림과 물음표만(글자 없음).
분위기: 끝나지 않는 회의의 피곤함과 귀여움, 창밖은 밤.
```

확인: 이름판 글자가 정확한지, 다른 글자가 없는지, 보라 테두리인지. 틀리면 "이름판 글자를 정확히 다시" 라고 고쳐 달라고 하세요.
