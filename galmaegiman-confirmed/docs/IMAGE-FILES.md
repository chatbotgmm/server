# 118종 이미지 파일명

이미지는 `public/images/<ID>.png` 로 넣습니다. 파일명은 아래 표의 ID와 **정확히 같아야** 합니다(대문자, 숫자 앞 0 없음).

- 형식: PNG
- 이미지가 없는 유닛은 이미지 없이 텍스트로만 응답합니다. 파일을 추가하면 서버 재시작 없이 다음 응답부터 표시됩니다(카카오 쪽 캐시 1시간).
- 미발견 히든은 이미지도 보내지 않습니다.
- 점검: `npm run data:check` 가 있는 이미지/없는 이미지 수를 알려 줍니다.
- 카드용 작은 그림: `public/thumbs/<ID>.jpg` (480×480 JPEG). 없으면 원본 PNG를 대신 보냅니다(느릴 뿐 동작은 같음).
- 미발견 실루엣: `public/images/unknown.png`, `public/thumbs/unknown.jpg`
