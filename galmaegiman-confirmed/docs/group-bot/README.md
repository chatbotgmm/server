# 단체방(그룹) 챗봇 운영 안내

카카오톡 그룹 챗봇(beta)용 스킬 서버입니다. 게임 서버(`galmaegiman-confirmed`) 안에 함께 들어 있고, 게임 규칙·DB는 앱·웹과 같습니다.
코드: `src/group/` · 설정: `data/group-bot.yaml` · 확인할 것: [open-questions.md](open-questions.md)

## 1. 켜기 전에 꼭 할 일 (운영 DB)

이 버전부터 서버가 **단체방 표 6개가 없으면 시작하지 않습니다**(계정 삭제가 이 표도 지우기 때문).

새 코드를 받은 폴더에서(`npm ci` 후), 서버를 멈춘 다음 차례로:

```bash
node scripts/manual/schema-rehearsal.mjs storage/confirmed.db
npm run backup
node --env-file=.env node_modules/prisma/build/index.js db execute --file prisma/manual/20261103_group_bot_additive.sql --schema prisma/schema.prisma
npm run db:generate
```

1번(복사본 예행)에서 ✅가 나와야 3번을 합니다. SQL은 표 추가만 하고 기존 표·값은 바꾸지 않습니다. 적용 전에 내용을 직접 검토하세요.
(검증: 예전 스키마 DB에 이 SQL을 적용한 뒤 `prisma migrate diff`로 새 스키마와 비교 → 차이 없음, 2026-11-03)

## 2. `.env` (선택: 넣으면 단체방 주소가 켜짐)

| 이름 | 값 |
|---|---|
| `GROUP_SKILL_SECRET` | 32자 이상. 1:1 챗봇 `SKILL_SECRET`과 다른 값 |
| `BOT_ENV` | 개발채널 봇 = `dev`, 운영채널 봇 = `prod`. 없으면 서버가 시작하지 않음 |
| `GROUP_BOT_ID` | (선택) 넣으면 다른 봇의 요청을 거절 |
| `PROACTIVE_MSG_ENABLED` | 선톡. 카카오 심사 전에는 `false` |

개발채널과 운영채널은 서로 다른 채널입니다(가이드 덱 5·14·21·35). `dev`와 `prod`는 키 공간이 나뉘어, 같은 사람도 다른 계정으로 잡힙니다.

## 3. 챗봇 관리자센터 연결

모든 스킬의 헤더에 `X-Skill-Secret: <GROUP_SKILL_SECRET>`를 넣습니다. 공개 HTTPS 주소(지금 `https://gmm.dpdns.org`)가 필요합니다.

| 블록 | 스킬 URL |
|---|---|
| 봇 입장 블록 | `https://gmm.dpdns.org/kakao/group/welcome` |
| 도움말 블록 | `https://gmm.dpdns.org/kakao/group/help` |
| 폴백 블록(그 밖의 모든 명령) | `https://gmm.dpdns.org/kakao/group/skill` |

`BOT_ENV=dev`이면 서버 기록에 요청의 **키 이름 모양**(값·발화 없음)이 남습니다. 개발 테스트방에서 한 번 불러 보고 `journalctl -u gmm-server | grep "request shape"`로 실제 구조가 덱 28번과 같은지 확인하세요.

⚠ 채널 연결을 해제하면 팀채팅방의 챗봇이 모두 강제 퇴장됩니다(덱 37).

## 4. 명령어

| 명령 | 하는 일 |
|---|---|
| 도움말 | 명령어 목록 |
| 모집 하급·중급·고급 (횟수) | 모집(한 번에 1~10회). 방에서 아무도 없던 갈매미면 「우리 방 첫 발견」 |
| 모집권 받기 | 모집권 받기(1시간마다) |
| 조합가능 / 조합 이름 | 지금 만들 수 있는 조합 / 조합하기(전설 이상·히든은 「확정」을 한 번 더) |
| 도감 · 내정보 | 내 도감·우리 방 도감·모집권 |
| 방도감 | 우리 방 공동 도감과 최근 첫 발견 |
| 방순위 | 이번 주 방 순위(새 발견 → 조합 → 모집) |
| 닉네임 이름 | 순위에 나올 이름 |

방 단위 기능(심사 항목 덱 39 「그룹 사용성」): 방 공동 도감, 우리 방 첫 발견, 방 주간 순위.

## 5. 관리자센터 입력 문구 (안)

- **봇 설명**(14자 이내, 덱 22): `갈매미 같이 모으기` (9자)
- **도움말 블록**: 위 `/kakao/group/help` 응답이 그대로 나갑니다(기능·사용법·문의 홈페이지). 발화를 저장하지 않으므로 저장 고지는 없습니다.
- **봇 입장 블록**: `/kakao/group/welcome` 응답(3줄) + 관리자센터에서 '챗봇 멘션하기' 버튼 설정(덱 24)
- **대표 명령어**: 도움말 · 모집 · 조합가능 · 방도감 · 방순위
- **버튼 사용 설명**(파라미터가 필요한 것만, 덱 25·46): `조합` → "만들 갈매미 이름을 입력해 주세요. 예) 조합 심해수호자" · `닉네임` → "2~10자 이름을 입력해 주세요. 예) 닉네임 갈매미왕"

## 6. 정한 것

- 발화를 저장하지 않습니다(서버 기록에는 명령어 첫 낱말만). AI를 쓰지 않습니다.
- 금지어 검사는 두지 않고, 광고·구매 유도·대화 열람 오해 표현이 들어간 응답을 만들지 않습니다.
- 게임 재화는 단체방에서 '모집권'이라고 부릅니다(앱 화면은 아직 '뽑기권').
- 한 사람당 1분에 20번까지 받습니다.
