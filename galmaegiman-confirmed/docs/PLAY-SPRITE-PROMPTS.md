# 횡스크롤 시험판(/play) 그림 요청문 — ChatGPT 이미지용

카드 그림(정사각형, 테두리·이름판·배경 있음)은 게임 화면에 그대로 쓸 수 없어서, **같은 그림체로 "동작 그림"을 새로** 받아야 해요.
그림이 하나도 없어도 게임은 임시 도형으로 돌아가고, 그림이 들어오는 대로 하나씩 바뀝니다.

## 쓰는 방법
1. ChatGPT 새 대화에서 **매 메시지마다 `public/images/C1.png`(기본 갈매미맨 카드)를 첨부**하고, 아래 [공통 머리말] + 시트 요청문을 붙여 넣어요.
   - 끼룩단(적)은 아직 카드가 없어서, ②-1을 먼저 만든 뒤 **그 결과 그림도 같이 첨부**해서 ②-2·②-3을 요청하면 생김새가 덜 바뀝니다.
2. 한 장에 여러 동작을 **가로 한 줄로** 그리게 해요. 같은 그림 안에서 그리면 동작끼리 생김새가 덜 달라지는 편이에요(완전히 같다는 보장은 없어요).
3. 받은 그림을 이 대화에 그대로 보내 주세요. 제가 칸별로 잘라 크기·바닥선을 맞추고 `public/play/sprites/<이름>.png`로 넣을게요.
4. **①-1(기본 동작 시트)을 먼저** 받아 그림체가 카드와 같은지 확인한 뒤 나머지를 진행하는 걸 추천해요.

## 공통 머리말 (모든 요청 맨 앞에 붙이기)
```
첨부한 카드 그림과 완전히 같은 그림체로 그려 줘. 그림체·색감·비율·외곽선 굵기를 바꾸지 마.
(부드러운 채색 일러스트, 갈색 외곽선, 따뜻한 햇빛 느낌. 갈매미맨: 둥글고 통통한 흰 털 몸, 머리 위 베이지색 돌 볏 3개,
등에 금이 간 큰 베이지 돌 날개 하나와 작은 흰 날개, 까만 점 눈, 분홍 볼, 작은 금색 부리, 짧은 다리와 작은 발톱)

이번에는 카드가 아니라 2D 횡스크롤 게임용 캐릭터 동작 그림이야.
- 테두리·이름판·글자·배경 없음. 배경은 투명(PNG). 투명이 안 되면 완전 단색 자홍색(#FF00FF) 배경.
- 모든 동작은 오른쪽을 보는 옆모습(약간 3/4도 괜찮음), 전신, 잘린 곳 없이.
- 한 장 안에 동작들을 가로 한 줄로, 칸 간격을 똑같이, 캐릭터 크기를 똑같이, 발바닥이 같은 높이에 오게.
- 동작끼리 생김새(볏 모양, 날개 금, 색)가 똑같아야 해.
Avoid: card frame, name plate, text, letters, watermark, background scenery, eagle, hawk, hooked beak, realistic, scary
```

## ① 갈매미맨 (주인공)
### ①-1 기본 동작 시트 — 4칸 → `player_idle_1`, `player_idle_2`, `player_jump`, `player_hurt`
```
갈매미맨 동작 4칸, 왼쪽부터:
1) 서 있기(대기): 차렷 자세, 살짝 뿌듯한 표정
2) 서 있기 숨쉬기: 1번과 같은데 몸이 아주 살짝 내려가고 눈을 감음
3) 점프: 몸이 무거워서 힘겹게 뛰어오른 모습, 두 날개를 퍼덕, 다리는 웅크림
4) 맞음: 뒤로 휘청, 눈은 X 모양, 작은 돌 부스러기가 튐
```
### ①-2 걷기 시트 — 4칸 → `player_walk_1`~`player_walk_4`
```
갈매미맨 걷기 동작 4칸(반복하면 자연스럽게 이어지는 뒤뚱뒤뚱 걸음), 왼쪽부터:
1) 왼발 앞으로 2) 두 발 모음, 몸 살짝 위로 3) 오른발 앞으로 4) 두 발 모음, 몸 살짝 위로
몸이 돌이라 무겁게 뒤뚱거리는 느낌. 큰 돌 날개는 등에 붙인 채.
```
### ①-3 공격 시트 — 3칸 → `player_attack_1`~`player_attack_3`
```
갈매미맨 공격 동작 3칸(등의 큰 돌 날개를 앞으로 크게 휘둘러 후려치기), 왼쪽부터:
1) 준비: 돌 날개를 뒤로 크게 젖힘, 결연한 표정
2) 휘두름: 돌 날개가 몸 앞쪽(오른쪽)으로 쭉 뻗음, 날개 끝에 짧은 바람 선
3) 마무리: 날개가 앞에서 멈추고 몸이 살짝 앞으로 기욺
```

## ② 끼룩단 (적: 진짜로 하늘을 나는 갈매기 깡패)
공통 설정(②의 모든 요청에 같이 붙이기):
```
끼룩단: 돌이 아니라 진짜 깃털 갈매기. 갈매미맨과 같은 그림체지만 몸이 더 날씬하고,
흰 머리·연회색 날개·검은 날개 끝, 머리에 빨간 두건, 심술궂은 눈썹, 노란 부리(갈고리 아님), 주황색 다리.
무섭지 않고 얄밉고 귀여운 악당 느낌.
```
### ②-1 보병 — 3칸 → `kkiruk_walk_1`, `kkiruk_walk_2`, `kkiruk_hurt`
```
끼룩단 보병 동작 3칸, 왼쪽부터:
1) 걷기: 왼발 앞, 날개를 접고 건들건들
2) 걷기: 오른발 앞, 날개를 살짝 들어 올림
3) 맞음: 눈은 X 모양, 깃털 몇 개가 날림
```
### ②-2 급강하병 — 4칸 → `diver_fly_1`, `diver_fly_2`, `diver_dive`, `diver_hurt`
```
(②-1 결과 그림도 첨부) 같은 끼룩단이 하늘을 나는 동작 4칸, 왼쪽부터:
1) 날기: 두 날개를 위로 활짝 2) 날기: 두 날개를 아래로 내림
3) 급강하: 날개를 몸에 붙이고 부리부터 앞아래로 내리꽂음
4) 맞음: 공중에서 눈은 X 모양, 깃털이 날림
```
### ②-3 행동대장(보스) — 5칸 → `boss_idle_1`, `boss_idle_2`, `boss_dash`, `boss_throw`, `boss_hurt`
```
(②-1 결과 그림도 첨부) 끼룩단 행동대장: 보병보다 크고 통통함, 빨간 두건에 한쪽 눈 안대, 목에 금색 메달.
동작 5칸, 왼쪽부터:
1) 대기: 가슴을 쭉 내밀고 거만한 자세 2) 대기: 1번에서 날개를 살짝 들썩
3) 돌진: 몸을 앞으로 숙이고 날개를 뒤로 젖혀 달려드는 모습
4) 깃털 던지기: 한쪽 날개를 앞으로 휘둘러 깃털을 던지는 모습
5) 맞음: 눈은 X 모양, 두건이 삐뚤어짐
```

## ③ 소품 — 3칸 → `item_snack`, `fx_feather`, `fx_hit`
```
게임 소품 3칸(캐릭터 없이), 왼쪽부터:
1) 과자 봉지(회복 아이템): 작은 새우 그림만 있는 둥근 봉지, 글자·상표 없음
2) 깃털: 끝이 살짝 회색인 흰 깃털 하나, 가로로 눕힘
3) 타격 효과: 노란 별 모양 번쩍임(만화 효과)
```

## ④ 배경 (정문 부두) — 가로로 긴 그림 3장
배경은 첨부 카드의 **배경 부분 그림체**(돌로 된 성, 푸른 바다, 흰 구름)에 맞춰요. 좌우 끝이 자연스럽게 이어져야(반복 배치) 해요.
- `bg_far` (먼 배경, 투명 아님)
```
첨부 카드 배경과 같은 그림체의 2D 횡스크롤 게임 먼 배경. 가로로 긴 그림(가로 2 : 세로 1).
위쪽 3분의 2는 맑은 하늘과 흰 구름, 멀리 섬 위에 돌로 된 성과 탑, 아래쪽 3분의 1은 푸른 바다.
캐릭터·글자 없음. 왼쪽 끝과 오른쪽 끝이 이어 붙여도 티 나지 않게(가로 타일링).
```
- `bg_mid` (중간, 투명 배경)
```
같은 그림체. 가로 2 : 세로 1, 배경 투명(안 되면 #FF00FF). 그림 아래쪽 절반에만 항구의 오래된 돌 아치와 돌 기둥,
가로등 몇 개를 띄엄띄엄. 위쪽 절반은 비워 둠. 캐릭터·글자 없음. 좌우 끝이 이어지게.
```
- `bg_near` (가까운, 투명 배경)
```
같은 그림체. 가로 2 : 세로 1, 배경 투명(안 되면 #FF00FF). 그림 맨 아래 4분의 1에만 부두의 나무 상자, 나무통,
밧줄 더미를 띄엄띄엄. 나머지는 비워 둠. 캐릭터·글자 없음. 좌우 끝이 이어지게.
```

## ⑤ 바닥 — 2칸 → `tile_ground`, `tile_platform`
```
같은 그림체의 2D 게임 바닥 타일 2개(배경 투명), 왼쪽부터:
1) 돌 부두 바닥 정사각형 타일: 윗면에 이끼 약간, 아래는 돌 벽돌. 좌우로 이어 붙여도 티 나지 않게
2) 나무 발판: 가로로 긴 나무 판자(가로 3 : 세로 1), 좌우로 이어 붙일 수 있게
```

## 받은 뒤 확인할 것
- 테두리·이름판·글자가 들어갔으면: "테두리와 글자를 빼고 투명 배경으로 다시"라고 요청
- 동작마다 볏·날개 모양이 다르면: "1번 칸과 생김새를 똑같이 맞춰서 다시"라고 요청
- 왼쪽을 보고 있으면: 괜찮아요. 제가 뒤집어서 넣을 수 있어요.
