# 모바일 전투 시안 반영

첨부 시안을 Z플립 가로 화면에 맞춰 재검토하고, 실제 게임 상태와 캐릭터를 유지한 채 UI·배경 이미지 소스를 교체했다. 기존 33종 앞·뒷모습, 보스·도감 원화, 체력·기술·아이템·증강체·전투 규칙은 변경하지 않는다.

## 이미지와 표시 방식

- `b5_command_buttons.webp`: 피치·크림·민트·라일락 패널, 차분한 샌드 색 목재와 브론즈 테두리의 공통 버튼 시트. 아이콘 아래 글자 영역이 비어 있다. 한 파일을 공유해 네 개의 개별 그림 요청을 줄인다.
- 버튼은 원본 시트의 고정 영역을 CSS로 표시한다. 위(아이콘·윗모서리)와 아래(조개·아랫모서리)는 같은 배율을 유지하고, 가운데 빈 영역만 조정해 가로 화면에 맞춘다. 전체 이미지를 눌러 늘리던 112% 보정을 제거했다.
- 버튼 제목은 실제 `Black Han Sans` 글꼴로 표시한다. 사용자의 요청대로 공격·아이템·교체·도망가기(대전은 나가기) 큰 제목만 남기고 작은 안내 문구는 제거했다. 행동 가능 여부와 API, 클릭 동작은 기존 규칙을 유지한다.
- `b5_log_frame.svg`와 `b5_status_frame.svg`: 생성한 피치·샌드 색 목재와 조개·산호 질감의 래스터 이미지를 WebP로 인코딩해 SVG에 포함했다. SVG viewBox로 투명 여백을 정리하며 외부 이미지 요청은 없다. 모서리와 테두리는 원본 비율대로 표시하고 가운데만 늘린다. 프레임 안 이름·숫자·기록은 HTML로 그린다.
- `deepbattleb.webp`: 시안의 바닥 물결광·따뜻한 햇빛을 반영한 해저 배경. 캐릭터나 UI를 넣지 않은 배경 전용 소스다. 기존 원화에 접지감을 더하는 그림자만 표시한다.
- 새 파일 이름으로 PWA의 이전 이미지 캐시와 구분한다. 웹과 Android 앱 패키징이 같은 UI 리소스를 사용한다.

## 모바일·태블릿 배치

전투와 명령판은 64.5:35.5 비율, 명령은 2×2 배치를 유지한다. 휴대폰은 얇은 기록창, 갤탭 등 큰 가로 화면은 남는 공간을 채우는 큰 기록창을 사용한다. 버튼의 비율에 맞춰 갤탭의 명령판 높이도 계산한다. 기록이 길면 프레임은 고정하고 안쪽 글 영역만 스크롤한다. 긴 글자가 테두리 위로 그려지던 부분을 안쪽 스크롤 영역으로 분리했다. 기술·교체·아이템 화면은 실제 데이터와 기존 동작을 유지한다.

## 검토에서 고친 것

처음 준비한 버튼은 너무 넓어 휴대폰 명령판에 빈 공간이 남고 아이콘과 제목이 가까웠다. 아이콘 아래 여백을 확보한 모바일용 시트를 다시 제작했다. 금빛 광택을 줄이고 시안의 피치 목재색을 맞췄다. 원본 그림 전체를 압축하지 않도록 위·가운데·아래 영역을 나눠 표시했다. 상태창·기록창 모서리의 가로·세로 배율도 통일했다.

## 검증 기준

실제 글꼴·Fastify API·격리 SQLite로 Z플립용 880×360·840×360, 작은 휴대폰 780×360, 일반 휴대폰 915×412, 갤탭 1280×720·1280×800을 검토했다. 로그인 전·후·로비·전투·기술·교체·아이템에서 화면 넘침·버튼 잘림·캐릭터와 상태창 불투명 픽셀 겹침·브라우저 오류를 검사했고 모두 통과했다. 별도 긴 기록과 안전 영역 조건에서 큰 기록창 스크롤과 제목 잘림·48px 이상 터치 영역·작은 문구 제거를 확인했고 통과했다. 실기기 화면은 별도 확인 대상이며 캡처는 브라우저에서 수행한다.

Android는 공식 SDK·JDK 21·프로젝트 Gradle Wrapper로 빌드한다. Android Studio도 같은 Gradle 프로젝트를 사용한다. 검증 APK는 현재 환경에서 생성한 디버그 서명이며, 기존 배포 앱의 업데이트 서명과 일치한다고 가정하지 않는다.
