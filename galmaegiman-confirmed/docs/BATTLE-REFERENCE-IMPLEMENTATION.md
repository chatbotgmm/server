# 첨부 전투 시안 반영

사용자가 제공한 `1000003778.jpg`의 해저 전투 배치를 기준으로 실제 전투 화면을 비교했다. 해저 배경, 조개 상태창, 공격·아이템·교체·도망 버튼은 저장소의 기존 그림을 사용한다. 명령판은 시안과 기존 명령판을 참고해 나무 선반·조개·산호 장식을 보강한 프레임을 생성했다. 이름·레벨·체력·남은 팀·증강체·아이템 수는 실제 게임 상태로 표시한다.

사용자가 캐릭터 작업은 별도로 하도록 지정했으므로 33종의 앞·뒷모습과 보스·도감 그림은 유지한다. 변경은 UI 명령판 그림과 그 배치에만 적용한다.

## 구현

- 상태창은 상대 왼쪽 위, 내 팀 아래 가운데에 두고 기존 그림 프레임을 유지한다. 아군 그림의 발 위치를 조금 올려 아래 여백을 시안에 맞췄다. 투명 여백을 제외한 그림 크기와 실제 상태창 위치에 맞춰 배치한다.
- 행동 버튼 그림을 112%로 그려 원본의 투명 여백을 보정했다. 2×2 버튼의 그림이 칸을 채우고 버튼 사이 간격이 시안에 가까워진다. 제목·안내를 조정하고 도망 버튼은 갈매기 그림과 글자가 겹치지 않도록 별도 위치를 둔다.
- 상대 정보의 「1턴 뒤」 안내는 시안의 크림색 팻말로 표시한다. 사용 가능한 시점과 기존 정보 조회 동작은 유지한다.
- 상태창 증강체는 시안처럼 아이콘·글자로 표시하며 누르면 기존 상세 설명을 연다. 분류에 따른 증강체 선택 카드 색과 키보드 포커스 표시도 유지한다.
- 해저는 전투 전용 해저 그림을 사용한다. 다른 장면도 제공된 챕터 일러스트를 명령판 뒤까지 연결하며, 그림이 없는 장면은 기존 배경을 사용한다.
- 새 명령판 `public/duel/intro/b4_command_panel.webp`는 시안의 피치·샌드 색 목재, 조개·산호 장식, 투명 배경을 반영한 생성 이미지다. 배포용으로 WebP(약 187KB) 인코딩하고, 장식이 늘어나지 않도록 가장자리와 가운데를 나눠 표시한다. 상단 선반 장식과 기록창 사이 간격도 맞췄다. 파일 이름을 새로 사용해 기존 PWA 그림 캐시와 구분한다.
- 갤탭 등 너비 1000px·높이 600px 이상인 가로 화면에서는 2×2 행동 버튼 위 공간을 기록창으로 채운다. 직전 기록과 현재 기록을 함께 표시하고 글자를 키운다. 긴 기록은 기록창 안에서 스크롤하며 첫 줄부터 읽을 수 있다. 기술 선택 등 하위 메뉴는 기존 배치를 유지한다.

## 검토에서 찾아 고친 것

기존 버튼의 투명 여백이 버튼 사이를 넓어 보이게 하고, 안내가 프레임 아래에 몰렸다. 그림 크기와 글자 위치를 보정했다. 큰 화면은 두 줄을 가운데 모아 버튼 사이가 과하게 벌어지지 않도록 했다. 도망 버튼은 갈매기 발과 글자가 가까워 추가 조정했다. 갤탭에서 버튼 위 빈 공간을 기록창으로 채웠으며, 긴 기록의 flex 축소 때문에 첫 줄이 가려지는 문제도 고쳤다. 상대 정보의 비활성 표시가 파란 배경처럼 보이던 부분은 크림색 팻말로 정리했다.

## 검증

- 실제 글꼴·Fastify API·격리 SQLite를 사용해 1280×523(시안 크기), 780×360, 915×412, 1280×720의 로그인 전·후, 로비, 해저 전투·기술·교체·아이템을 캡처했다. 915×412의 항구 전투도 확인했다. 추가로 1280×800의 갤탭 배치와 긴 기록을 확인했다(기록창 약 272px, 글자 25.6px, 첫 줄 표시·내부 스크롤 확인).
- 해저와 항구에서 행동 버튼·기술 버튼의 패널 밖 잘림 0개, 패널 세로 스크롤 없음, 상대 그림의 불투명 픽셀과 상태창 겹침 0개, 브라우저 실행 오류 0개.
- 격리 DB 8개 파일·124개 테스트, 빌드와 앱 웹 리소스 패키징 통과. DB 구조·경제·전투 규칙은 바꾸지 않았다. APK 파일 빌드는 포함하지 않았다.
