## 이번 변경 확인

- 조합목록의 안흔함 9종, 특별 20종, 희귀 40종과 등급을 유지하는 페이지 이동.
- 네 등급 중 희귀 뽑기에만 이미지 URL 포함. 모든 등급은 내갈매미 이름 선택으로 이미지 조회.
- 한국 시간 09/12/18시 기본 10회 충전, 재요청·재시작 중복 지급 방지, 누적 상한.
- 실행 중 설정 변경 반영, 이전 슬롯은 당시 충전량으로 정산, 정각/직후 변경과 0회 중지.
- 관리자 명령 조회·변경, 잘못된 값 거절, 변경 잠금, 손상된 설정 오류. 일반 채팅으로 설정 변경 불가.


- 75종 전체 이름·짧은 이름·띄어쓰기 차이가 같은 캐릭터로 연결됨.
- 여러 캐릭터와 일치하는 이름은 후보 목록만 반환하고 조합/지급하지 않음.
- 전체 도감 75종과 조합목록 69종을 페이지마다 검사: 이름 누락/중복 없이 모두 접근 가능.
- 표시 텍스트·목록 제목·설명·버튼이 보내는 발화에 캐릭터 ID/개체번호/긴 확인 코드가 없음. 페이지 숫자와 수량은 표시.
- 목록당 5종 이하, 확인 응답의 이미지+본문+목록은 outputs 3개 이하.
- 이름 조합 미리보기에서 필요/사용 가능 수량을 표시하고 확정 전에 재료 소비 없음.
- 조합가능은 동일 재료의 복수 수량·잠금·표식 전환 상태를 반영함.
- 내갈매미는 중복을 수량으로 표시하며 이름으로 보호/해제 시 한 마리씩 처리함.
- HTTP 요청으로 재료 선택→이름 목록→조합 미리보기→ListItem.extra/action.clientExtra 확인 흐름 검증.
- 다른 사용자 확인 토큰은 거절하고 동일 버튼 재전송은 추가 지급하지 않음.
- 확인 정보 없이 조합 확정만 입력하거나 토큰과 다른 발화를 전송하면 소비하지 않음.
- 취소한 미완료 요청은 재사용할 수 없고 재화/개체 상태가 유지됨.
- 기존 완료 요청의 저장 결과에 ID가 있어도 번호 없는 안내를 반환하고 추가 지급하지 않음. 저장 결과 자체는 보존.
- 기존 DB에 저장된 코드명도 현재 표시명으로 조회하며 보유 기록/재화/도감은 유지됨.

## 설치 패치 검증

- 0.2.2와 0.2.3의 격리 설치본에 누적 ZIP을 각각 적용하고 빌드 성공.
- 같은 ZIP을 재적용해도 빌드 성공. 관리자 조회 명령도 실행 성공.
- 설치 전후 DB·인증 설정·공개 주소·기존 충전 설정·카탈로그·레시피·확률·표시명·Prisma 스키마 SHA-256 동일.
- 설정 파일이 없는 설치에서는 기본 10회, 기존 설정이 있는 설치에서는 해당 값 유지.
- 이전 코드와 dist의 상대 경로 백업 및 원본 바이트 일치 확인.
- 의도적으로 TypeScript 오류를 넣었을 때 이전 코드·문서·dist 복구, 새 파일 제거, DB·설정 보존 확인.
- 사용자 수정 코드가 있으면 파일 변경 전에 설치를 중단함.
- 패치된 dist 앱에서 이전 DB의 콘텐츠 해시 검사 통과. 실제 HTTP 응답으로 등급 선택·이름 이미지 조회·설정 변경 즉시 반영 확인.
- ZIP CRC와 변경 파일 SHA-256 검사. 이미지·DB·인증키·node_modules는 ZIP에서 제외.

충전 설정의 정리 처리 수정 후 해당 테스트 7개를 다시 실행해 통과했습니다. 설치·복구 검증은 실제 갤탭을 조작한 결과가 아니라 격리된 Linux 설치본의 결과입니다.

## 확인 범위

실행 환경은 Linux x86_64의 Node.js입니다. 실제 갤탭 ARM64 및 카카오 채널의 렌더링에는 원격 접속하지 않았습니다. 사용자 기기에 적용했다고 주장하지 않습니다. ListCard 및 추가 데이터 필드는 카카오 공식 문서를 확인하고 HTTP 요청/응답 테스트로 검증했습니다. 화면에서 실제로 항목을 누르는 확인은 설치 후 채널에서 진행해야 합니다.

캐릭터 이름·카탈로그·조합 데이터·이미지·뽑기 확률·DB 스키마는 그대로이며, 이미지의 한글 오탈자 수정이나 신규 캐릭터 제작은 이번 업데이트에 포함하지 않습니다.
