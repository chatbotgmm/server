# GPT에게 보낼 메시지 (작게 나눈 판)

ChatGPT가 한 번에 많이 하다 끊기는 일이 잦아서, **한 메시지 = 그림 1장(3~4마리)**, **올리기는 따로**로 나눴어요.
메시지마다 필요한 내용이 다 들어 있어서 GPT가 저장소 문서를 읽을 필요가 없어요.

## 쓰는 법
1. 아래 「그리기」 메시지를 복사해 보내고, 같이 적힌 **카드 그림 1장을 첨부**해요(저장소 `galmaegiman-confirmed/art/ref/` 안).
2. 그림이 마음에 들면 바로 아래 「올리기」 메시지를 보내요. 마음에 안 들면 고칠 점만 말해 다시 그리게 해요.
3. 올리기가 계속 끊기면: ChatGPT에서 그림을 내려받아 **Claude 대화에 첨부**해 주세요. Claude가 넣어요.

순서: 앞모습 9장(1~9) → 뒷모습 9장(10~18). 뒷모습은 그 그룹의 앞모습 결과 그림을 첨부해요.

첨부: `art/ref/cards_D_a.jpg`

**그리기**
```
첨부한 카드 4장과 같은 캐릭터로, 게임 전투용 원형 그림 1장을 그려 줘.
- 한 장에 4마리를 가로 한 줄로, 왼쪽부터 D1 D2 D3 D4. 칸끼리 떨어지게, 모두 같은 크기로.
- 배경은 투명(안 되면 완전 단색 자홍색 #FF00FF). 글자·번호·이름·그림자·빛 번짐 없이.
- 앞모습, 보는 사람 기준 화면 왼쪽을 향해 살짝 튼 서 있는 대기 자세, 발끝까지 전신. 걷기·공격 동작 말고 1마리에 1자세.
- 그림체는 첨부한 카드와 같게(부드러운 채색, 갈색 외곽선, 귀엽지만 얄미운 느낌). 얼굴·포인트 색·소품은 카드 그대로.
- 같은 종족 표시(새 부리, 볏, 작은 새 발, 귀여운 눈)는 지키고, 아래 **체형·자세·상징물**로 서로 확실히 다르게. 상징물은 몸만큼 크게.
- 그림만 보여 주고, 아직 어디에도 올리지 마.
- D1 태초의 갈매미맨: 가장 크고 넓적, 낮게 버틴 자세. 상징물: 등 뒤로 날개처럼 펼친 대방패 두 장(몸보다 큼).

- D3 첫밤의 갈매미맨: 졸린 듯 몸 기울이고 눈 감은 둥근 자세. 상징물: 머리 위 거울 원반(일식) + 잠옷 모자.
- D4 원해 갈매미맨: 머리 위에 물 고리가 뜬 키 큰 실루엣. 상징물: 머리 위 뒤집힌 바다(물 고리) + 가슴 바다 구슬.
```
