# v0.3.0 개편판 배포 (EC2)

118종 구성, 3단 뽑기, 뽑기권 받기, 탐험·시너지, 히든 비공개를 적용합니다. 명세: `design/SYSTEM-SPEC.md`

## 새 명령
- `뽑기권 받기` / `받기`

- `탐험` · `탐험보내기 이름, 이름 ×3` · `탐험보내기 자동` · `탐험 보상 받기` · `시너지`

## EC2에서 배포 (Session Manager 또는 SSH, 한 줄씩)
```bash
sudo -iu ubuntu
```
```bash
sudo systemctl stop gmm-server
```
```bash
cd ~/gmm && git fetch origin main-oz3tvo && git checkout main-oz3tvo && git pull origin main-oz3tvo
```
```bash
cd ~/gmm/galmaegiman-confirmed && npm run reset-data -- --confirm
```
마지막에 `초기화 완료`가 나오면:
```bash
sudo systemctl start gmm-server
```
```bash
sleep 5; curl -fsS http://127.0.0.1:3000/health; echo
```
`"edition":"GALMAEMI_118","version":"0.3.0"`이 나오면 완료입니다. **터널(gmm-tunnel)은 건드리지 않으므로 카카오 URL은 그대로**입니다.

## 되돌리기
```bash
sudo systemctl stop gmm-server
cd ~/gmm && git checkout main
cd galmaegiman-confirmed && ls backups/
```
`backups/reset-날짜/confirmed.db`를 `storage/confirmed.db`로 되돌려 놓고, `npm ci && npm run build` 후 `sudo systemctl start gmm-server`.

`docs/IMAGE-FILES.md`의 파일명대로 `public/images/`에 넣으면 됩니다.

## v0.3.1 업데이트 (데이터 유지)
결과 화면 개선(한 줄 소개·대사·중복 결과 축약·전설 연출·다음 행동 안내), 오늘의 미션, 등급 도감 완성 칭호를 추가했습니다. DB에 표 2개(칭호·미션)가 **추가만** 되므로 유저 데이터는 그대로입니다. **reset-data를 실행하지 마세요.**

```bash
sudo -iu ubuntu
```
```bash
sudo systemctl stop gmm-server
```
```bash
cd ~/gmm && git pull origin main-oz3tvo
```
```bash
cd ~/gmm/galmaegiman-confirmed && bash scripts/setup.sh
```
마지막에 `설치 완료`가 나오면:
```bash
sudo systemctl start gmm-server
```
```bash
sleep 5; curl -fsS http://127.0.0.1:3000/health; echo
```
`"version":"0.3.1"`이 나오면 완료입니다.

새 명령: `미션`, `칭호` (내정보에도 표시)

## v0.3.2 업데이트 (문구 정리, 데이터 유지)
