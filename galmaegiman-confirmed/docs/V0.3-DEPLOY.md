# v0.3.0 개편판 배포 (EC2)

118종 구성, 3단 뽑기, 뽑기권 받기, 탐험·시너지, 히든 비공개를 적용합니다. 명세: `design/SYSTEM-SPEC.md`

**이 배포는 유저 데이터를 모두 초기화합니다.** 기존 DB는 무결성 검사를 거친 백업과 원본 파일 모두 `backups/` 아래에 보관되고 삭제되지 않습니다.

## EC2에서 배포 (Session Manager 또는 SSH, 한 줄씩)
```bash
sudo -iu ubuntu
```
```bash
sudo systemctl stop gmm-server
```
```bash
cd ~/gmm && git fetch origin main-oz3tvo && git checkout main-oz3tvo && git pull origin main-oz3tvo
```
```bash
cd ~/gmm/galmaegiman-confirmed && npm run reset-data -- --confirm
```
마지막에 `초기화 완료`가 나오면:
```bash

```
```bash
sleep 5; curl -fsS http://127.0.0.1:3000/health; echo
```
`"edition":"GALMAEMI_118","version":"0.3.0"`이 나오면 완료입니다. **터널(gmm-tunnel)은 건드리지 않으므로 카카오 URL은 그대로**입니다.

## v0.3.3 관리자 모드 (테스트용 무제한 뽑기)
관리자 계정은 뽑기에 뽑기권을 쓰지 않습니다. DB에 칸 1개(관리자 여부)가 **추가만** 됩니다(데이터 유지).

배포: `git pull` → `bash scripts/setup.sh` → 아래 → 서버 시작
```bash
cd ~/gmm/galmaegiman-confirmed && npm run admin-code
```
화면의 `관리자 xxxxxxxx…` 를 카카오 채팅에 그대로 보내면 그 계정이 관리자가 됩니다. 끄기: `관리자 해제`
- 봇테스트 계정과 실제 채널 계정은 서로 다른 계정이라 각각 등록해야 합니다.
- 코드는 비밀번호처럼 다루세요. 바꾸려면 .env의 ADMIN_CODE 줄을 지우고 다시 `npm run admin-code` 후 서버 재시작.

배포 순서는 v0.3.1과 같습니다(`git pull` → `bash scripts/setup.sh` → 서버 시작). `"version":"0.3.4"` 확인.

## v0.3.5 관리자 모드 켜기·끄기 (데이터 유지)
관리자로 등록된 계정도 **관리자 모드를 켰을 때만** 뽑기권이 무제한이고, 평소(모드 꺼짐)에는 일반 유저와 똑같이 뽑기권이 줄어듭니다. DB에 칸 1개(관리자 모드)가 **추가만** 됩니다.

- `관리자 <코드>`: 관리자 등록 + 모드 켜짐 (처음 한 번)
- `관리자 켜기` / `관리자 끄기`: 등록된 관리자만, 코드 없이 전환
- `관리자`: 지금 모드 확인 · `관리자 해제`: 등록 자체를 해제
- 업데이트 직후 기존 관리자 계정은 **모드 꺼짐**으로 시작합니다. 테스트할 때 `관리자 켜기`를 보내세요.

배포 순서는 v0.3.1과 같습니다(`git pull` → `bash scripts/setup.sh` → 서버 시작). `"version":"0.3.5"` 확인.

## v0.3.6 관리자 모드 원상복구 (데이터 유지)
관리자 모드를 켜는 순간의 계정 상태(뽑기권·새우깡·뽑기권 받기 시각·보유 유닛·도감·탐험·칭호·오늘의 미션)를 저장해 두고, `관리자 끄기` 또는 `관리자 해제` 때 그 상태로 되돌립니다. 모드 동안 뽑은 유닛, 조합 결과, 받은 보상은 모두 사라집니다. 기록 로그(AuditEvent)는 남깁니다. DB에 표 1개(AdminSnapshot)가 **추가만** 됩니다.

## v0.5.0 천장·조합 직전 알림·랭킹·목록 카드·자동 백업 (데이터 유지)
DB에 칸 2개(고급 뽑기 천장 카운트 `highPity`, 닉네임 `nickname`)가 **추가만** 됩니다. 기존 데이터는 그대로입니다.

- **고급 뽑기 천장**: 고급 뽑기 100회 안에 전설이 안 나오면 100회째에 전설 확정. 전설이 나오면 0부터 다시 셉니다. 뽑기 메뉴 고급 카드와 결과에 "전설 보장까지 N회" 표시. 수치는 `data/economy.yaml`의 `HIGH.pity`.
- **조합 직전 알림**: 결과 화면 아래에 재료가 1마리만 모자란 조합을 1개 안내(`🔜 ✦ 유성대장장이까지 운석 1마리!`)와 바로가기 버튼.
- **랭킹**: `랭킹` = 도감 수집 수 순위(1~5위 그림 목록, 6~10위·내 순위). 관리자 모드를 켠 계정은 제외. `닉네임 이름`으로 표시 이름 설정(2~10자, 중복 불가).
- **목록 카드**: 조합목록·교환 목록도 카드 넘기기(한 쪽 10장). 조합목록 카드에 재료 진행·모자란 재료·`만들기`/`재료 보기` 버튼.
- **자동 백업**: 매일 한국 시간 04:30에 DB 백업, 최근 7개만 보관(`backups/current-*`).

배포: `git pull` → `bash scripts/setup.sh` → 서버 시작 → **자동 백업 설치(처음 한 번)**:
```bash
cd ~/gmm/galmaegiman-confirmed && sudo bash scripts/install-backup-timer.sh
```
마지막에 `백업 및 무결성 확인 완료`와 다음 실행 시각이 나오면 설치된 것입니다. `"version":"0.5.0"` 확인.
