# 홈 시안 일치·조합 뷰포트·공통 제목 여백 검토

기준: `25e3481160656a437fb7a5c074c04a45d62c94f4`, review branch only.
이 문서는 실제 Android 화면 검증 완료나 APK 빌드 완료를 뜻하지 않는다.
수정은 이 커밋 소스로 제공하며 Claude의 역할은 빌드·테스트·실제 화면 결과 보고다.
운영 병합/배포, 릴리스 생성, 워크플로 수동 실행은 하지 않았다.

## 홈
- 메뉴 원본 PNG의 투명 여백을 제외한 알파 경계로 그려 가시 아이콘 높이를 카드의 약 55–60%로 복구했다. 별도 새 아이콘 생성이나 작은 래스터 확대가 아니다.
- 홈 제목은 MainActivity가 로드하는 번들 Jua를 명시 사용한다. Jua에 없는 가운데점은 작은 벡터 점으로 그려 시스템 폰트 대체/빈 글리프를 피한다. 본문 폰트는 그대로다.
- 플레이에는 기존 원본 장식 프레임의 중앙 문양과 더 큰 나침반을 사용한다. 7개 기능, 4+3 배치, 우하단 플레이, 접기·펼치기, 튜토리얼, 알림 자격 조건은 유지한다.
- 프로필 폭은 안전 영역의 약 17.5%, 재화는 약 58% 지점부터 배치한다. 최소 재화 폭 88dp는 기존 아이콘 및 최대 축약 수량 글자 공간을 보존한다. 루트 시스템 인셋 처리는 변경하지 않는다.
- 영웅 중심은 전체 가로의 약 23%, 발은 안전 영역 높이의 75% 이내로 두되 아래 말풍선 영역을 예약한다. 이미지 비율/크기는 유지한다.
- 말풍선은 원래대로 영웅 탭 시 표시하고 바깥 탭 시 닫는다. 항상 표시되는 것으로 바꾸지 않았다.
- 실제 영웅 알파 실루엣을 지면 기준으로 투영하는 왼쪽 아래 방향 그림자와 발밑 접촉 그림자를 분리했다. 이미지 캔버스 중앙이나 idle 움직임을 따라 지면 그림자가 떠다니지 않는다.
- 알림 점은 작고 밝은 빨강, 가는 테두리와 작은 하이라이트로 조정했다.

## 배경 광원
`native/release-v1/backgrounds/bg-home.png`를 동일한 1870×841 크기로 교체한다.
깨끗한 원본에 image_gen 편집을 적용했으며 영웅/글자/UI/영웅 그림자는 배경에 굽지 않았다.
우상단 주광, 좌하단 투사 방향 약 (-0.92,+0.39). 배/등대/아치/볼라드 5개 표본의 ±5px 정합 최적 이동은 모두 (0,0), 상관계수 .944–.969다.
새 배경 SHA256: `c6a3c3b3b09f13b8659fad7e69c15e913242c022b6111fa6eb34702f5bc1a492`.
생성 편집으로 바닥 밖 질감도 일부 변했으므로 픽셀 보존 편집이라고 주장하지 않는다. 기존 centerCrop/수면 애니메이션과의 실제 합성 확인이 남아 있다.

## 조합 화면
- 바깥 중첩 ScrollView가 720dp 최소 폭과 320dp(+fontScale) 최소 높이를 강제해 실제 짧은 가로 화면 밖으로 늘어나는 원인을 제거했다. 유한 뷰포트 안에서 헤더·내용·하단 액션을 나눈다. 이전 테스트처럼 스크롤 후 버튼 도달만 확인하지 않는다.
- 재료/결과 탭은 제목의 남은 공간을 이용해 우상단에 고정하며 탭 자체를 스크롤 영역에 넣지 않는다.
- 재료 선택은 원본 카드 한 장을 좌우 스와이프하고 카드 탭으로 소유한 1개를 추가한다. 선택 재료 셀 탭은 1개 제거다. 별도 화살표/추가 버튼은 없다.
- 결과 선택도 한 장 카드 스와이프가 즉시 해당 조합식을 선택한다. 결과 검색창·준비됨 필터·결과 격자·화살표를 제거했다. 조합식 상세와 재료 정보는 유지한다.
- 카드 페이징 전에 허용 등급을 필터링한다. 서버 경계상 LEGEND/HIDDEN은 동급 결과 경계이고 NEUTRAL은 재료로 허용하며 미지 등급은 제외한다. 서버 비공개 결과 노출 규칙, 확률, 소유 수량, maxMaterials 계산은 바꾸지 않는다.
- 수량 라벨은 실제 텍스트 측정 폭을 사용해 고정 236dp 공간의 최대 수량 말줄림을 피한다. 좁은 폭/큰 글꼴에서는 액션 문구를 간결하게 바꿔 두 줄로 높이를 넘지 않게 하며 전체 의미는 접근성 이름으로 유지한다. 540×222dp/글꼴 200% 예산 테스트를 추가했다.
- 화면 전체 스크롤은 없다. 다만 48dp 터치 셀이 수용되지 않는 선택 재료 영역, 큰 글꼴 빈 결과 설명, 3종 이상 조합식 재료 띠에는 제한된 내부 스크롤을 허용한다.

## 다른 메뉴 제목
MenuKit 공통 배경 적용 함수는 좌우 최소 12dp(짧은 화면)/16dp를 보장하며 기존 더 큰 여백과 세로 여백을 보존한다. 여러 번 호출해도 누적하지 않는다.
도감 섹션/기술명/아이템 제목과 대전 편성 소제목에만 적용한다. 전역 navyLabel, 행 높이, 글꼴, 줄 수는 바꾸지 않는다. 기술명은 기존 1줄 말줄임 및 전체 접근성 이름을 유지한다.

## 검증과 한계
- 실행 통과: 독립 JVM HomeMenuLayoutTest 93,408 기하 검증.
- 실행 통과: 통합 Java 11파일 구문 검사와 실제 CraftTierPolicy의 14개 경계 검사. parser 검사는 Android 심볼 컴파일을 대신하지 않는다.
- ReleaseHomeLayoutTest, MenuHeadingPaddingTest, NativeCombinationWorkbenchTest 회귀 검사를 추가/보강했다.
- Android SDK/전체 Gradle 체크아웃이 없는 scratch 환경이므로 Android 컴파일, Robolectric 실행, 기기 실행·캡처는 하지 않았다.
- 데스크톱 미리보기는 실제 메뉴/영웅/배경/번들 폰트와 소스 기하를 사용한 Pillow 근사 렌더다. 네이티브 스크린샷이 아니다. 네 장은 zero-insets 스트레스 조건, 두 장은 제공 캡처에서 추정한 인셋 조건이다. APK 자산/레포에는 이 미리보기를 포함하지 않는다.

## Claude: 지금은 테스트 APK만 빌드
기존 빌드 절차로 이 review 커밋의 테스트 APK만 빌드하고 결과를 보고한다. 현재 AAB 생성·Play 업로드는 하지 않는다. APK 실기기 피드백은 우리가 소스를 수정하는 반복 검증으로 처리하며, 통과한 동일 소스의 AAB는 이후 사용자 확인 뒤 별도로 진행한다. 미리보기를 실제 캡처로 대체하지 않는다.

기존 applicationId와 서명을 유지하고 설치된 앱과 비교한다. 앱 삭제/데이터 초기화/새 키 생성은 하지 않는다. Play 설치 앱 서명과 APK 서명이 다르면 업로드 키로 서명한 APK가 덮어쓸 수 있다고 주장하지 말고 정확한 불일치를 보고한다. 별도 테스트 applicationId 변경 역시 이후 명시적 승인 없이 하지 않는다.
HomeMenuLayoutTest, ReleaseHomeLayoutTest, MenuHeadingPaddingTest 및 기존 NativeMenus/NativeRealtime 테마 회귀 검사를 실행한다.
915×412와 2048×838 계열에서 실제 safe-area/density와 글꼴 100/130%, 홈 열림/닫힘/영웅 탭 말풍선/최대 재화 수량을 캡처한다.
배경 수면 오버레이 정합, 발 접촉·좌하단 그림자 방향, 메뉴 글리프/가시 아이콘 크기, 7개 기능과 알림 상태를 확인한다.

조합은 NativeCombinationWorkbenchTest를 실행하고 같은 실제 viewport/fontScale에서 바깥 스크롤 없이 탭·카드·수량·조합 버튼이 보이는지 확인한다. 양쪽 모드 스와이프, 재료 탭 추가/선택 셀 제거, 결과 검색 부재, 페이지 경계·멀티터치 취소·접근성 이전/다음, 비공개 결과·등급 필터를 확인한다. 조합 데스크톱 미리보기는 번들 OTF 대신 Noto CJK를 쓴 근사이며 네이티브 폰트 일치 증거가 아니다.

극단 조건 주의: 540×222dp/글꼴 200%에서 조합 화면의 결과 본문 영역은 정적 예산상 높이가 약 8dp까지 줄어든다. 실제 번들 Noto 폰트·인셋에서 읽기/조작이 가능한지 테스트 APK로 확인해야 한다. 모든 글꼴 크기에서 실기기 검증됐다는 뜻이 아니며, 이 조건은 추가 화면 피드백 및 수정 판단 대상으로 남긴다.
