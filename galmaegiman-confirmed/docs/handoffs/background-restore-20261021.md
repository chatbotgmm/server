# 81버전 계열 배경 애니메이션 복원

## 원인과 기준

현재 수동 통합 소스 `ea8ccd18cd77e92e1c6092eb1064c17ddde3fb9f`의 재귀 파일 목록에는 `background-motion-v1`, `BackgroundMotion*`, `HarborBoat*`가 없다. 별도 작업 브랜치의 `0bf7846214951f8b97a010b7cad851c89056dd84`에 있던 이미지와 화면 연결이 이 통합본에 들어오지 않은 것을 확인했다. 기존 `HomeWater` 등 일부 이전 효과는 있으므로 모든 화면이 완전히 정적이라고 단정하지 않는다.

81은 사용자와 심사 로그인 인계 문서에서 확인한 사용 버전이다. 설치된 81 APK/AAB의 정확한 소스 커밋과 서명은 이번 작업에서 검증하지 못했다. 이번 복원은 최신 수동 통합 소스 위에서 진행하며 버전 설정, 패키지, 인증을 변경하지 않는다.

## 변경 범위

- 이전에 공개된 원본 8종 효과 시트와 runtime.json, 재생기 6개 클래스를 그대로 복원한다. 기존 Git blob SHA를 재사용하며 새로 그리지 않는다.
- 원본 배경 8개는 현재 통합본에서도 SHA가 일치한다. 원본 그림과 가림 마스크 기준을 유지한다.
- ThemeArt: 도감, 조합/탐험, 모집, 설정 사무실, 상점, 편성 배경 draw 직후 효과를 합성한다.
- HomeArt/LobbyView: 로비 홈 수면 효과를 실제 소유 View 무효화에 연결한다.
- BattleView: 항구 수면과 오른쪽 작은 배 한 척의 미세 mesh 움직임을 합성한다. 그 외 전투 배경은 정적 원본을 유지한다.
- MainActivity/GameRootLayout: 시작·일시 정지·복귀·포커스·화면 교체·메모리 경고·종료를 연결한다.
- 별도 터치 View를 추가하지 않고 기존 배경 Canvas에 그린다. 모션 끄기, 디코드 실패, 모달, 비활성 화면에서는 원본 정적 배경을 유지한다.

## 정확한 효과 범위

이 자료는 전체 풍경을 다시 그린 애니메이션이 아니라 물빛, 등불, 먼지, 잎의 국소 투명 오버레이다. 배 흔들림은 항구 배 한 척 주변의 작은 원본 패치를 부드럽게 변형하는 방식이다. 진짜 독립 선박 레이어나 모든 배의 움직임이 아니다. 로그인 첫 화면의 시간대별 JournalAmbient 그림은 별도 원본이므로 이 8종 시트를 잘못 겹치지 않는다.

## 실행한 검사

- `check-background-motion.py`: 시트 8개·64개 프레임, 원본/시트 해시, 좌표, alpha 외곽 검사 통과.
- `test-background-motion.py`: 손상 검출 9개 검사 통과.
- `test-background-motion-timeline.sh`: 실제 Java 재생기 핑퐁·정지/재개 및 항구 mesh 97시점 검사 통과.
- `check-background-restore-integration.py`: 모든 소유자 패치 통합 후 실행해야 하는 렌더링 연결/생명주기 정적 계약 검사.

## 미실행 및 빌드 전 필수 확인

Android SDK/Gradle 컴파일, 실제 Jua 글꼴의 네이티브 실행 캡처, 기기 터치/성능/GPU 합성 검증은 아직 완료하지 않았다. 정적 검사를 실제 화면 정상 동작의 증거로 해석하지 않는다. 저장소 CLAUDE.md의 디자인 검토 절차에 따라 780×360, 915×412, 1280×720에서 원본과 효과 정렬, 건물·배·문구 가림 없음, 화면 전환/복귀/모달/모션 끄기 동작을 확인한 뒤 APK를 빌드해야 한다. 특히 항구 배 가장자리 왜곡이나 이중 윤곽이 보이면 해당 mesh 호출을 끄고 원본을 유지한다.

이번 작업은 운영 서버, EC2, DB, Play 업로드, 배포를 수행하지 않는다.

## 최종 통합 부모 갱신
통합 게시 대기 중 수동 브랜치의 직접 후속 커밋 `f77cf92d0f08e914148e7b63c6ebbc4cdcee0bd6`가 확인되어 최종 부모를 갱신했다. 해당 후속 변경은 히든 단서 테두리 및 조합 테스트이며, 이 문서의 애니메이션 구현 기준은 그대로 보존한다. 설치된81 바이너리와의 정확한 SHA 대응은 여전히 미확정이다.
