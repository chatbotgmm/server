# 기술 설명 길게 누르기 — 검토용 후속 변경

기준은 닉네임·튜토리얼·조합·배경·상위33종 연결을 저장한 `0c475b560a5094d2e167d60a7d8d43f151ab757f`다. 이 문서를 포함한 후속 커밋이 기술 길게 누르기를 추가하며, 최신 결과는 `feature/review-onboarding-motion-20261021` 브랜치에서 확인한다. 앞선 커밋만을 최종 통합본으로 안내하지 않는다.

## 동작
- 짧은 탭: 기존 기술 사용·속성 아이콘 처리 유지.
- 길게 누르기: 시스템 길게 누르기 시간/터치 이동 허용값 사용. 누르는 동안 이름·속성·기술 설명·사용 불가 이유 표시.
- 손 떼기: 설명 닫기. 긴 누름을 공격 클릭으로 전달하지 않는다.
- 드래그, 취소, 두 번째 손가락, 포커스 상실, 숨김/분리: 설명과 예약 콜백을 정리하고 공격하지 않는다.
- 버튼 위 설명은 원래 손 떼기 이벤트를 빼앗지 않는 비접촉·비포커스 PopupWindow다. 주 전투판과 대체 기술 선택창 모두 입력 취소 경계를 둔다.
- 서버가 실제로 제공한 기술 데이터만 사용하고 명중률 기본값을 만들지 않는다.
- 첫 통합 커밋의 배경·33종 렌더/로더는 유지하며 BattleView에는 입력 제어만 추가한다.

## 검토에서 고친 것
최소 Android API24에서 동작하도록 설명 글자 자동크기를 AppCompat 경로로 처리한다. 현재 창/다이얼로그 가시 영역과 게임 루트의 컷아웃·둥근 모서리·키보드 안전 영역을 함께 적용한다. 실제 폰트 화면은 아직 찍지 않았으므로 좁은 화면이나 극단적인 글꼴 확대에서 설명의 완전한 가독성을 확정하지 않는다.

## 검증 및 남은 사항
`sh scripts/test-skill-hold.sh`에서 순수 Java 제스처 assertion21개, Android 파일5개의 구문 검사, API24/안전영역/공통종이테마 정적 회귀검사가 통과했다. 통합 후 배경 연결 정적계약 및 전체 Android 소스123개 구문 검사도 통과했다. 이는 Android 타입검사·Robolectric·앱 빌드·실기기 결과가 아니다.
반영 전 짧은 탭, 활성/비활성/합동 기술 긴 누름, 손 떼기, 두 손가락, 드래그/취소, 백그라운드 복귀, 화면 이동, 가로 소형 폰·큰 글꼴·실제 Jua/GowunDodum 캡처를 확인해야 한다. 긴 누름 뒤 `battleTurnFrom` 호출이 없어야 한다.

사용자가 요청한 별도 검토 브랜치 저장만 수행하며 운영 병합·배포는 하지 않는다. CLAUDE.md 실제 글꼴 캡처 선행 규칙의 이번 검토 초안 저장 예외를 적용한다. 최종 설치본81의 정확한 소스SHA 대응과 실제 APK/AAB는 확인하지 않았다.
