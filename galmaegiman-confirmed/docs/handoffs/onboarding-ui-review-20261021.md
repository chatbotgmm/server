## 변경
1. 조합 재료 왼쪽: 큰 FULL 등록증 한 장, 좌우 스와이프/이전·다음, 검색 제거. 탐색과 재료 추가를 구분한다. 기존 사용 가능 수량·보호·재료 한도와 실제 확정 요청은 유지한다.
2. 닉네임: 서버가 새 사용자(튜토리얼1단계, 아직 tut 표시 없음, 닉네임 없음)에 `nicknameRequired`를 반환한다. 해당 사용자는 전용 스크롤 화면에서 저장한 뒤 튜토리얼로 간다. 이미 이름이 있거나 기존/진행 중 사용자는 강제로 재설정하지 않는다.
3. 인증·rate limit·기존 요청 guard를 사용하는 POST `/my/api/nickname` 추가. 기존 챗봇과 정규화/형식/운영자 사칭 차단 규칙을 공유하며 DB unique 제약이 최종 중복 판단을 한다. 동일 요청 재시도는 성공, 다른 기존 이름은 덮어쓰지 않는다. 스키마 변경·튜토리얼 보상 변경 없음.
4. 튜토리얼: 구형 이미지/장식 패널을 공통 paper/navy 디자인으로 바꾸고 진행·건너뛰기를 카드 내부에 배치한다. 좁은 영역/큰 글꼴에서 세로 헤더 및 전체 내용 스크롤, 대상과 충돌하지 않는 안전 영역 배치, 대상이 너무 크면 명시적인 대상 보기 경로를 제공한다. 방범대 명칭으로 안내 문구를 맞춘다.
5. 배경/상위33종 애니메이션은 각각 별도 handoff의 원본·최적화·fallback 범위를 따른다.

## 실제 제보와 검증 한계
사용자가 보낸 1080×444 이미지에서 상단 진행 표시/건너뛰기 잘림, 과도하게 빈 구형 안내판, 이전 수호자 이미지 및 '수비대' 문구를 직접 확인했다. 해당 비율/좌표 경계 회귀 검사를 추가한다. 기기 모델, 디스플레이 배율, 실제 inset 원인은 이미지 하나로 확정할 수 없다. 수정된 앱에서 같은 화면을 다시 찍어 잘림이 사라졌다는 검증은 아직 하지 않았다.
