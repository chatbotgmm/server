# 충전량 변경 · 0.2.4

처음 적용하면 한국 시간 오전 9시, 낮 12시, 오후 6시마다 10회씩 충전됩니다. 하루 세 번을 모두 맞이하면 10×3=30회입니다. 첫 접속 지급은 기존 3회입니다. 미사용분은 누적됩니다.

## 관리자가 충전량 바꾸기

게임 서버와 터널을 켜 둔 채 Termux에서 새 세션을 엽니다. 새 세션의 Termux에서:

```bash
proot-distro login ubuntu --termux-home
```

Ubuntu에서:

```bash
cd ~/galmaegiman-confirmed
npm run refill -- 20
```

다음 충전 시점부터 매번 20회가 됩니다. 패치·빌드·서버 재시작이 필요 없습니다. 20 대신 원하는 숫자를 넣습니다. 0~1000의 정수를 받으며, 0은 정기 충전을 중지합니다. 0으로 해도 이미 보유한 횟수는 사라지지 않습니다.

현재 설정만 확인:

```bash
npm run refill
```

다시 10회로 설정:

```bash
npm run refill -- 10
```

이 명령은 갤탭의 Ubuntu에서 실행합니다. 일반 사용자가 카카오톡에 입력해서 설정을 바꿀 수는 없습니다. 사용자에게는 `내정보`의 다음 충전량 안내가 자동으로 갱신됩니다.

## 변경 시점과 누적

- 횟수를 바꾼 순간 보너스가 지급되는 것은 아닙니다. 다음 09/12/18시부터 바뀝니다.
- 오전 9시에는 10회였고 오전 10시에 20회로 바꾸면, 그날 정산은 10+20+20=50회입니다. 저녁에 처음 접속한 기존 사용자도 같은 계산을 받습니다.
- 같은 시간대에 여러 번 요청하거나 서버를 재시작해도 지나간 충전분은 두 번 지급하지 않습니다.
- 이 업데이트를 처음 적용하기 전에 아직 정산하지 않은 슬롯은 기본값 10회로 계산합니다. 이후 관리 명령으로 바꾼 이력부터는 각 슬롯 당시 설정값을 적용합니다. 첫 접속 이전 슬롯은 지급하지 않습니다.
- 서버는 요청마다 설정을 읽고, DB 트랜잭션 안에서 지나간 슬롯을 정산합니다. 상주 타이머나 별도 스케줄러를 설치할 필요가 없습니다.

변경값과 이력은 `config/refill-settings.json`에 저장합니다. 직접 편집하거나 지우지 마세요. 서버를 옮길 때 DB, 인증 설정, 공개 주소와 함께 복사하세요. `npm run backup`에도 포함됩니다. 깨진 설정을 기본값으로 임의 처리하지 않고 오류를 알리므로, 잘못된 입력 때문에 충전량이 조용히 바뀌지 않습니다.

## 이미지와 속도

뽑기 결과는 흔함·안흔함·특별이 텍스트, 희귀가 이미지+텍스트입니다. 현재 75종에 전설 이상은 없습니다. 모든 등급에서 결과의 `캐릭터 보기`, 또는 `내갈매미` → 이름 선택으로 이미지를 봅니다. 보유·도감·조합·교환 목록에는 작은 이미지도 자동으로 불러오지 않습니다. 상세·조합 확인·조합 결과의 이미지는 유지됩니다.

스킬 응답에는 이미지 파일 자체 대신 URL이 들어갑니다. 카카오는 그 주소의 이미지를 가져와 표시합니다. 현재 코드도 스킬 응답을 만들 때 PNG를 읽지 않고, 별도 이미지 요청에서만 읽습니다. 이미지 생략은 다운로드·표시 부담을 줄이지만, 갤탭과 터널의 실제 지연이나 개선 시간은 이 환경에서 측정하지 않았습니다. 이미지 생략만으로 모든 응답 지연을 해결한다고 보장하지 않습니다.
