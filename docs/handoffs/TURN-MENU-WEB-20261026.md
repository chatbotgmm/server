# 전투·메뉴·웹 점검·최초 로딩 통합 인계

기준: `manual/home-assembly-20261019`, `32da6c2b97aba22f582cb88e5ab9782b7e4e8913`.
소스/자산 50개와 이 문서 1개를 함께 반영한다.

## 변경 내용
- 서버 확정 전투 이벤트 순차 재생, Canvas 효과, 재접속·중복/늦은 응답·중도 이탈 처리.
- 서버가 공개한 상대 정보만 별도 창에 표시. 최초 방어상성 2개, 완료턴마다 2개 추가, 첫 완료턴 후 스탯 공개. 인간 PvP를 AI로 바꾸지 않는다.
- 허용 AI 후보에서 서버 seed로 선택. 튜토리얼/스토리/고정 적과 보상·레벨 유지. 튜토리얼은 특정 종 대신 실제 보유/사용 가능한 출전 개체를 검사한다.
- 기술 성공 응답 후 6개 기본 명령 복귀. 전투 조건 오류를 한국어로 표시하고 실패 후 재조회가 안내를 즉시 지우지 않도록 처리.
- 테스트 메뉴 기본값과 기존 계정 개방 도구. 실제 API 인증·권한·재화·개체조건은 유지한다.
- 웹게임 진입과 구형 웹 전용 행동만 점검 응답. 앱/native API·로그인·홈페이지·공용 기능은 유지한다.
- 최초 로딩에 선택한 원본 그림 전체 contain. 로그인/OS splash/로비 원본 배경은 변경하지 않는다.
- 로비 수면 좌우 변위 제거. 5.6초 공통 위상으로 수면/전경 배 bob 최대3.3원본px, roll0.75도. 배 미세 세부는 원본 참조 재구성이며 완전 동일 추출이 아니다.

## Claude 테스트 빌드 옵션
**APK/AAB 빌드는 Claude가 담당한다. 이 변경에서 앱 패키지 빌드는 수행하지 않았다.**

모든 variant의 `BuildConfig.GMM_LEGACY_MENU_TEST_COMPAT` 기본값은 false다.
이번 승인된 테스트용 패키지를 빌드할 때 기존 Gradle task에 정확히
`-PgmmLegacyMenuCompat=true`를 추가한다. 실제 task/variant는 저장소 설정으로 확인한다.
일반 정식 release에서는 옵션을 생략해 기본 false를 유지한다.
기존 자동 CI/workflow는 변경하지 않았으므로 옵션 없는 자동 빌드는 호환 개방을 적용하지 않는다.

true여도 로그인 세션 및 허용 앱 ID에서 정확한 메뉴 endpoint HTTP404/501일 때만 UI 진입을 허용한다.
401/403/429/5xx/네트워크 실패, 정상 서버의 `enabled:false`·`force_lock`은 열지 않는다.
명시 잠금 기억은 서버+계정 세션 범위다. 동일 계정 재로그인으로 token이 바뀌고 메뉴 API가 없는 경우
기존 잠금 기억을 이어받을 수 없는 한계가 있다. 실제 기능 API의 권한 검사는 계속 적용된다.

## 운영 반영은 별도
서버 배포·서비스 재시작·DB 변경·메뉴 실제 개방·웹 운영 중지는 수행하지 않았다.
현재 구 서버의 `MENU_API_MISSING` 상태에서는 앱 메뉴 진입 호환과 전투 FX의 보수적 fallback만 가능하다.
상대정보 순차 공개와 AI 무작위는 신규 backend 및 테스트프로필 정책 반영이 필요하다.
앱만 빌드해서 모든 기능이 활성화됐다고 보고하지 않는다.

- 신규/auto 메뉴 기본 개방에는 확인된 테스트 환경의 `GMM_TEST_MENU_DEFAULT=open`과
  `ROSTER60_PROFILE=five-stat-device-test-v1`이 필요하다. 기존 force_lock은 계정 목록/관리자/대상 DB를
  검증하는 별도 개방 절차로 처리한다. 권한 승격이나 추측 계정 선택은 하지 않는다.
- 웹 운영 기본 `GMM_WEB_GAME_MAINTENANCE=true`; 복구는 실제 서비스 환경의 false와
  승인된 재시작 절차가 필요하다. 변수 삭제는 복구가 아니다.
- 이미 열린/캐시된 웹이 앱과 공유하는 native/실시간 PvP API까지 완전히 종료하지 않는다.
  이 공유 API를 일괄 차단하면 Android도 손상되므로 별도 세션 권한 분리가 필요하다.
- 배포 시 기존 .env/DB/검증된 정적 자산 보존, 변경 소스·data/test 좁은 staging,
  새 버전 격리 검증, 원자적 서비스 전환 및 실패 rollback을 준비한다. 공유 서비스를 웹 중지 목적으로 stop하지 않는다.
- 반영 후 웹 전용 경로503/no-store, 홈·health 정상, 앱 로그인/모집/조합/전투/우편,
  실제 메뉴 상태와 점검 off 복구를 확인한다. 임의 운영 hotfix는 포함하지 않는다.
