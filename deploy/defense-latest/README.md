## 지금 최신 판에 든 것

- 이번 추가: 갈매미는 **끌어서만** 옮김(빈 곳을 누르면 고르기 풀림, 고른 무리는 하나를 끌면 함께), **소리 설정 창**(♪: 배경음악 켜기·끄기, 음량 막대·−/+, 기기에 기억)
- **선택 위습**(커먼·언커먼·레어·에픽): 원하는 갈매미를 골라 소환. 처음 커먼 1개 + 보스 보상(10웨이브 언커먼·20웨이브 레어·30웨이브 에픽 선택 위습). 아래 판 「선택 위습」 버튼 → 등급 칸 → 갈매미 누르기
- **난이도 다시 맞춤**(사용자 요청): 3웨이브쯤부터 커먼 풀강이 아니면 적이 쌓이고, 5~6웨이브부터는 커먼만으로는 못 버팀. 등급마다 공격력 약 4배, 적 체력은 웨이브별 기준점(등급별로 조합하는 봇이 버티는 한계를 재서 정함)
- **새우는 갈수록 많이**(처치 1마리당 1 + 웨이브×0.5), **강화는 칸마다 10단계까지(풀강)**, 비용은 등급이 높을수록 훨씬 비쌈(커먼·언커먼 5에서 시작 ~ 영원 5000에서 시작, 단계마다 1.25배)
- **유틸은 에픽부터 의미 있게**(커먼 그림자 마방깍 2·증폭 2%, 에픽 미노타우로스 방깍 20·스턴 18%, 전설 거장 방깍 35·스턴 21%)
- **강화 창을 열어도 게임이 멈추지 않음**, **조합 결과는 판 가운데(소환되는 곳)에 나옴**
- 외부탐사 1장 대장 체력이 보스 체력×25로 계산되던 오류 고침(보스 배수를 쓰지 않음)
- **창고**: 갈매미를 창고에 넣으면 판에서 빠져 싸우지 않지만 조합 재료로는 쓰임. 창고 창에서 꺼내기·팔기, **커먼 자동 창고**(켜면 판의 커먼과 새로 부른 커먼이 바로 창고로)
- **모으기**: 고른 갈매미와 같은 종류를 판에서 한 자리로 모으고 함께 고름
- 외부탐사·선택 위습·조합법·창고·소리 창도 게임이 멈추지 않음(일시정지 Ⅱ·결과 창만 멈춤). 창은 위 정보 줄 아래에
- **공격 대상: 사거리 안에서 가장 가까운 적 먼저**(전에는 길을 가장 많이 간 적 먼저)
- **위습**: 처음 커먼 위습 6개, 웨이브마다 2개. 선택 위습은 처음 0개, **스토리(외부탐사)를 깰 때마다**(1장 커먼·2~3장 언커먼·4~5장 레어·6~7장 에픽 선택 위습 1개, 랜덤 위습 보상은 그대로). 보스는 랜덤 위습만
- 위습이 늘어난 만큼 적 체력을 다시 맞춤(봇 40판: 커먼 풀강 6~7웨이브에 끝, 잘하는 봇 클리어 10%)
- **60웨이브까지**(50·60웨이브 보스, 60웨이브 보스를 잡으면 클리어)
- **스토리(외부탐사)**: 1장 선택 위습을 언커먼으로(레어 하나에 빠진 언커먼을 골라 에픽), 장별 대장 체력 2만·15만·50만·100만·300만·500만·1,500만(2장은 10웨이브쯤 에픽 1마리, 3·4장은 에픽으로 3웨이브쯤, 5·6장은 전설이 있어야, 7장은 상위가 있어야), **깨면 새우**(150·400·800·1,500·3,000·5,000·9,000)
- **스토리에 보낸 갈매미도 조합 재료**(판 것을 먼저 씀)
- **새우 수입 늘림**(처치 1마리당 1 + 0.6×웨이브 + 0.02×웨이브²), **강화 비용 낮춤**(첫 단계 5·20·60·150, 제한·초월·불멸·영원은 모두 600, 단계마다 1.2배), **전설·히든 강화 한 칸**(8칸)
- **전설 이상 보조(고체력)에 범위 스턴**: 공격마다 확률로 맞은 적 둘레 모두 스턴(전설 12%·히든 14%·제한 16%·초월 이상 20%)
- 봇 30판: 커먼만 6~7웨이브에 끝, 스토리 안 하는 봇 클리어 0판, 스토리 하는 봇 클리어 17%
- **PC·태블릿 가로 화면**: 왼쪽 게임, 오른쪽 창(강화·외부탐사·선택 위습·창고·조합법 …). 창이 열려도 판을 만질 수 있고, 창이 없으면 오른쪽에 조합법이 늘 떠 있음. 세로 화면(휴대폰·태블릿 세로)은 그대로
- **시작 새우 40**(커먼·언커먼 강화 5단계까지 바로), **시작 언커먼 위습 1개**
- **초반 완화**: 1~10웨이브 적 체력 ×0.7(봇 30판: 잘하는 봇은 17웨이브 전에 끝나는 판 없음, 클리어 10%)

  서버는 방·판 모습을 메모리에만 잠깐 들고 전달만 함(DB 안 씀, 서버 재시작 시 방 사라짐). 한 사람당 0.25초마다 요청 1번(주소 /defense/room/sync, IP당 분당 900번 한도)

  (봇 30판: 커먼만 5~7웨이브에 끝으로 같음, 잘하는 봇은 27웨이브 전에 끝나는 판 없음·클리어 10%로 같음)
- **가로 화면에서 닫기를 누르면 오른쪽 창도 빔**(전에는 조합법이 늘 떠 있어 닫히지 않는 것처럼 보였음)

- **재료 나무로 개편**(사용자 요청: 피라미드 화면이 별로): 맨 위에 만들 것, 각 재료가 자기 바로 아래에 선으로 이어짐. 동그란 그림에 ✓ 가진 것 · ! 위습으로 소환 · + 더 아래 있음. 넓으면 단 수를 자동으로 줄이고, 재료를 누르면 그 재료 기준으로 펼침(← 뒤로)
- **위습 찾기는 최상위(제한·초월·불멸·영원)만**(사용자 요청: 금각이 너무 쉽게 만들어짐): 거장(전설)·금각(히든)에서 뺌, 가루다·리치·여명만(봇 30판: 잘하는 봇 클리어 3판→2판)
