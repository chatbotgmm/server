## 게임 규칙(요약, 2판: 사용자와 정한 규칙 2026-11-08)
- 위습: 처음 커먼 랜덤 위습 5개 + 웨이브마다 1개. 위습 하나로 그 등급 갈매미 1마리를 무작위 소환. 위습 등급은 커먼·언커먼·레어·에픽, 전설 위습은 「위습 찾기」 재주가 있는 갈매미(황금·드워프·룬장인·거장·금각)가 적을 쓰러뜨릴 때 확률로만.
- 타격수 = 물딜, 술사 = 마딜. 고체력·기습은 딜이 낮은 보조(방깍·스턴·이속감소 / 마방깍·마딜증폭). 적은 방어력·마법방어가 따로 있고 웨이브가 일반·갑옷·결계로 바뀐다.
- 갈매미는 판 어디에나 두고 겹쳐도 됨(수 제한 없음). 끌어서 옮기기, 빈 곳을 끌면 여러 마리 고르기, 고른 채 빈 곳을 누르면 그리로 걸어감.
- 조합법 52개 전부(히든 6개 포함). ☆ 조합 목표(최대 3개) → 판의 재료에 같은 색 테두리.
- 웨이브마다 35마리. 길 위의 적이 70마리를 넘은 동안 1초마다 경고 1회(누적), 20회를 넘으면 패배.
- 10웨이브마다 보스, 그 라운드 안에 못 잡으면 바로 패배. 보스 보상은 위습(10: 레어, 20: 에픽, 30: 에픽 2).
- 외부탐사(8웨이브부터): 갈매미맨 메인 스토리 7장 지역에 갈매미를 보내 그림자 대장을 쓰러뜨리면 보상 위습(언커먼 → 레어 → 에픽으로 점점 높게). 보낸 동안은 수비에서 빠짐.
- 새우(처치 보상)로 물딜·마딜 강화를 따로 한다.
- 난이도: 자동 봇 300판 기준 클리어 12%, 경고 패배 13%, 나머지는 10·20·30·40웨이브 보스에서(2%·23%·34%·16%).
